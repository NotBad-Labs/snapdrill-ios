# 样张收集说明（给提供卷子的人）

SnapDrill 要做「拍照整理错题」。我们在**自己手机上**测试去笔迹效果，**不上传云端、不用姓名**。

## 请拍什么样的图

- 作业、试卷、练习册的**一页**（或一题区域）  
- 最好带有：**学生手写** 或 **老师红笔批改**  
- 光线尽量均匀；允许真实场景下的阴影、皱褶（我们也需要困难样张）

## 请不要拍

- 带 **学生姓名、学号、学校名牌** 的封面（先遮住或只拍题目区）  
- 与题目无关的截图（会降低数据集质量）

## 怎么交给你自己（PO）

1. AirDrop / 相册导入到 Mac  
2. 重命名为 `S005-简短描述.jpg`  
3. 放入仓库目录：`Samples/stage0/raw/`  
4. 在 `Docs/STAGE0_SAMPLES.md` 表格加一行  

## 语言分布（最终希望）

| 语言 | 至少张数 |
|---|---|
| 简体中文 | 40+ |
| 繁体中文 | 10+ |
| 日语 | 15+ |
| 韩语 | 15+ |
| 英语 | 20+ |

一时凑不齐外语卷 **可以延后**；W1 先以中文卷把流程跑通即可。
