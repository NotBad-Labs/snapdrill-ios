## 2. 评估单位、Hold-out 隔离与分层底线

| 约束维度 | 强制标准（消除单位错位与数据泄露） |
|---|---|
| **统一评估单位** | **单题裁剪块（Question Crop）**——Q1 盲评与 Q2 测速**必须使用同一粒度的单题裁剪块**；若原始照片为整页多题，须按题框切分并登记于 [`STAGE0_SAMPLES.md`](STAGE0_SAMPLES.md) 单题子表入池计分。 |
| **只读 Hold-out 隔离** | `Samples/stage0/` 全部样本**严格锁定为只读 Hold-out 测试集**；**严禁用于模型训练、微调、LoRA 或超参/阈值拟合**（模型训练与调优须使用独立外部训练集或合成数据）。 |
| **独立性限制** | **同一本作业/试卷或同一人字迹合计最多贡献 ≤ 5 道单题裁剪块**入分母（含跨卷同书写人合并限额）；**最终 §5/§6 报告须同步披露实际来源的「有效独立母页 / 作业本数」与独立书写人数**。 |
| **五语分层底线** | 正式冻结门（≥ 80 题）**每种首发语言（简中 / 繁中 / 日 / 韩 / 英）至少 10 道有效单题**，**且每语言 10 题子切片内至少包含 2 道红笔批改或困难样本（二者合计 ≥ 2）**（严禁用全清晰印刷体凑单切片；总库最终目标 ≥ 100 题）。 |
| **笔迹与困难底线** | 总体须包含铅笔、黑/蓝笔及**红笔批改占比 ≥ 18.75%（精确比值单一门槛，`N = 80` 时即 ≥ 15 题）**；含阴影、折痕、模糊或几何图覆盖印刷体的**困难样张占比 ≥ 20.0%（精确比值单一门槛，`N = 80` 时即 ≥ 16 题）**。**上述配额在任何有效分母 $N \ge 80$ 下均以精确有理数比值比较（严禁先四舍五入成整数百分比：例如 `15 / 80 = 18.75% < 20.0%` 不满足困难构成，`16 / 80 = 20.0%` 满足）**。 |
| **隐私与安全** | 入库前按 [`STAGE0_COLLECTION.md`](STAGE0_COLLECTION.md) 彻底剥离 EXIF GPS；仅本地/内部分享，绝不上传商业云服务；已脱敏单题裁剪块保留至复核归档期结束。 |

## 4. PO 确认通过标准（2026-11-27 拍板生效）

### 4.1 趋势门与效果冻结门（Q1）

**① 趋势门（≥ 10 道单题裁剪块）**
- 覆盖至少 **2 种语言 + 红笔批改**；
- 要求 **≥ 7/10（70%）** 评为可重做，方可继续投入当前端侧模型方案并与 MVP Pipeline 对接；若 < 7/10，立即停止原方案加码，评估切换模型架构或提前准备 B/C 档 `F-12` 退路。

**② 正式冻结门（以届时符合 §2 分层底线的全池有效样本 $N \ge 80$ 为分母；按目标收集至 100 题时，全池全部合格样本悉数计入分母，严禁人为截取前 80 题）**

> **精确比值铁律**：所有可重做率、子切片比例与 §2 样本构成配额（含困难占比 ≥ 20%）一律采用 **`分子 / 分母` 的精确有理数比值** 直接与阈值比较（例如 `55 / 80 = 68.75% < 70%` 严判 C 档、`15 / 80 = 18.75% < 20%` 不满足困难构成、`16 / 80 = 20.0%` 满足），**严禁先四舍五入成整数百分比再判定**。

| 档位 | 总体可重做率（精确比值闭环区间） | 子切片底线（硬约束） | 裁决动作 |
|---|---|---|---|
| **通过 A** | **≥ 85%** | 五语（每语 ≥ 10 且含红笔或困难合计 ≥ 2）与红笔子切片**均 ≥ 60%**（**任一切片 < 60% 严禁签 A**） | `F-10` 维持 **P0**，结合 Q2 结果按 `AC-04`（或 `AC-04-B`）验收 |
| **有条件通过 B** | **70% ≤ x < 85%**（或总体 ≥ 85% 但有切片在 50%–<60%） | 各语种与红笔子切片均 **≥ 50%** | `F-10` 仍上首包，但 **`PRD.md` §8.7 `F-12 手动橡皮擦` 自动升格 P0 纳入首包**；商店文案定调为“辅助去手写” |
| **不通过 C** | **< 70%**（或**任一语种/红笔子切片 < 50%**） | — | 触发 `PRD.md` §8.7 退路：**首版暂缓自动去手写**，仅增强原图 + **`F-12 手动橡皮擦`（P0）**，`F-10` 移入 v1.1/v1.x，并同步更新 `PRD.md` §6.2 免费版文案 |

> **双人盲评与唯一仲裁规则**：
> - **对照组**：评审员同时查看同一题的「图像增强原图」与「模型去手写图」（随机乱序盲评，遮蔽来源标签）。
> - **合格定义**：印刷体题干可读、公式/图表/标点无关键缺失、手写残留不阻碍独立重做。
> - **双人独立评价与唯一仲裁口径**：由 PO 与第二位独立评审员（设计或团队内非本模型研发成员）分别打 Y/N；两人均判 Y 计为通过，**凡意见分歧（一 Y 一 N）一律按保守口径计 N**（严禁事后临时改规则重评）。

### 4.2 性能与内存门禁（Q2 · 完整互斥划分 + App 内统一会话口径）

在 **iPhone 17 标准版**（飞行模式/常温状态）的 **App 内测试会话** 上分别测量：
- **冷加载测试（独立 1 次，不计入 30 题稳态集）**：首次触发 Core ML 模型懒加载编译 + 完成首张单题推理的端到端总耗时（严禁放入冷启动 1.0s 路径）。
- **稳态连续推理测试（预锁定 30 题，测后严禁重抽换样）**：在正式测速前先将随机抽取的 30 个单题裁剪块 ID 锁定写入 [`STAGE0_SAMPLES.md`](STAGE0_SAMPLES.md) 台账；百分位采用 **`nearest-rank` 算法**（有序 30 题数组中，**P50 = 第 15 位**、**P95 = 第 29 位**（$\lceil 0.95 \times 30 \rceil$））。
- **峰值内存增量唯一测量口径**：使用 Xcode Instruments Allocations / `task_vm_info.phys_footprint`，**唯一以「App 内已打开采集步骤 2 页面但尚未触发模型首次懒加载前」的 `phys_footprint` 读数为基线，测算整段 30 题连续会话期间的最大 `phys_footprint` 增量**（CLI 输出仅作研发对照，不参与过门判定）。

| 档位 | 严格互斥数学划分（覆盖全体非负样本，无落空区） | 与 `PRD.md` 对齐结论 |
|---|---|---|
| **通过 A** | 首题冷加载 **≤ 3.5 秒** **且** 稳态 **P50 ≤ 1.5 秒** **且** **P95 ≤ 2.0 秒** **且** 6 秒超时 **≤ 10%（≤ 3/30）** **且** 会话最大 `phys_footprint` 增量 **≤ 350 MB** | 直接满足 `AC-04` 标准条款 |
| **有条件通过 B** | 未达 A 档，但满足：首题冷加载 **≤ 3.5 秒** **且** 稳态 **P95 ≤ 3.0 秒**（涵盖「`P95 ≤ 2.0s` 但 `P50 > 1.5s`」与「`2.0s < P95 ≤ 3.0s`」）**且** 6 秒超时 **≤ 10%** **且** 会话最大 `phys_footprint` 增量 **≤ 350 MB** | 允许 `F-10` 进首包，但**必须同步在 §6 勾选启用 `PRD.md` `AC-04-B` 有条件条款（稳态 P95 ≤ 3.0 秒，商店禁止主打“极速去手写”）** |
| **不通过 C** | 上述条件任一不满足：**首题 > 3.5 秒**，**或** 稳态 **P95 > 3.0 秒**，**或** 6 秒超时 **> 10%**，**或** 会话最大 `phys_footprint` 增量 **> 350 MB** | 严禁按当前模型直接发版；**先允许阶段 0 内量化/剪枝或换轻量模型重测；仅当 PO 决定放弃当前自动去手写方案进入发版时，才与 Q1 C 档一致地将 `F-10` 移出首包、升格 `F-12` 并改写 `PRD.md` §6.2 免费版文案** |

### 4.3 安装包体积门禁（Q3 · 坚守纯离线）

口径统一为：**`xcodebuild -exportArchive` 导出的针对 `iPhone 17`（`arm64`）App Thinning 裁剪后设备变体下载包大小**：

| 档位 | 基准机变体包（含 `.mlmodelc`） | 动作 |
|---|---|---|
| **通过** | **≤ 80 MB** | 维持 `PRD.md` §9 默认目标 |
| **有条件通过** | **80 MB < x ≤ 120 MB** | **PO 优先放宽安装包上限至 ≤ 120 MB 并写入 `PRD.md` §15，坚守端侧离线可用（严禁改为首次启动联网下载模型）** |
| **不通过** | **> 120 MB** | 必须进行模型蒸馏/剪枝/量化减重，否则放弃当前模型或推迟 `F-10` |

## 8. 风险与升级路径

- **外语或红笔切片未达标**：与 §4.1 严格一致——只要任一语言或红笔子切片 **< 60%**，**严禁签 A**（50%–<60% 时降为 **B 档**纳入 `F-12`；若 `< 50%` 则判 **C 档**，或**经 PO 书面确认触发「缩小首发范围后重裁」程序：必须先通过 PRD PR 修改 `PRD.md` §3/§9 首发语言与市场范围并重跑分级盲审，同时将被移出语种的全部样本整段移出分母后重新计算 §2 与 §4.1，严禁仅改商店宣称而不改 PRD 与样本分母**）。
- **CloudKit Spike**：由轨道 C 在 **Slice 1 建库前** 完成 `CKSyncEngine` 启停、LWW、`DeletedPresetKey` 防复活与 `presetKey` 事务合并验证（6 条标准），结论直接入 `M-freeze` 检查表。
