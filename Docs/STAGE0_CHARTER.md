### 裁决线说明（第一件事 — 不是数学题里的线）

**「裁决线」= 阶段 0 结束时，用哪几条数字给去手写下结论**，对应 Charter **§4** 三张表：

| 看什么 | 裁决线（默认值） | 过了线意味着什么 |
|---|---|---|
| **效果** Q1 | 可重做率 **≥85% → A**；**70–84% → B**；**<70% → C** | 决定 MVP 是否必须做自动去手写（F-10 是否 P0） |
| **速度** Q2 | P50 ≤ **1.5s**，P95 ≤ **2.0s**（基准机） | 决定能否满足 AC-04 |
| **体积** Q3 | 安装包 ≤ **80MB** 通过；**80–120MB** 有条件 | 写入 PRD §15 |

不是几何里的「辅助线」，而是 **PO 拍板用的及格分数线**。你想改（例如效果改成 80% 也算 A）说一声，我们改 §4 并记修订即可。

## 4. 通过标准（建议草案 — PO 可在启动前改数字）

### 4.1 效果（Q1）

在 **≥ 80 张** 标注为「带手写/批改」的样张上：

| 档位 | 可重做率（PO / 设计双人盲评「能重做」） | 含义 |
|---|---|---|
| **通过 A** | ≥ **85%** | F-10 维持 **P0**，按 AC-04 全量验收 |
| **有条件通过 B** | **70%–84%** | MVP 仍上自动去手写，但必须同步 **加强 F-12 手动橡皮擦（P1→纳入首包）** 与失败降级文案；商店表述偏「辅助」 |
| **不通过 C** | < **70%** | 触发 PRD §10 退路：**首版无自动去手写**，仅增强原图 + F-12；F-10 改为 **P1/P2**；AC-04 走「有条件验收」 |

> 「能重做」定义：印刷体题干可读、公式/图表无关键缺失、手写遮挡面积不阻碍读懂题意（双人一致）。

### 4.2 性能（Q2）

在基准机型上，对通过 A/B 档中 **随机 30 张** 题图裁剪块：

- **P50 ≤ 1.5 s**，**P95 ≤ 2.0 s**（冷启动后连续推理）。
- 任一张 **> 3 s** 须记录原因；若 **> 10%** 样本超 2 s → 不得标 A，最高 B。

### 4.3 体积（Q3）

| 档位 | 安装包（含模型） | 动作 |
|---|---|---|
| 通过 | ≤ **80 MB** | 维持 §9 目标 |
| 有条件 | **80–120 MB** | PO 决定是否调高上限或拆「首次启动下载模型」方案（须写进 PRD §15） |
| 不通过 | > **120 MB** 且无拆分方案 | 重新训练/蒸馏或推迟 F-10 |

## 8. 风险与升级路径

- **训练数据不足** → 缩小首版语言宣称范围（仅中英）须 PO 与 PRD §3 同步修改。  
- **仅红笔场景失败** → 评估 F-13（P2）或首版文案说明「红笔批改去除不稳定」。  
- **CloudKit 未在阶段 0 测** →  acceptable；记入阶段 1 专 Spike（见 [`ROADMAP.md`](ROADMAP.md)）。
