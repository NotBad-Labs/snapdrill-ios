## 1. 一句话定位

面向成年人的 iPhone 原生效率工具：把纸张、照片、PDF 以最低摩擦变成可搜索、可整理、可导出、可打印的**一个本地资料库**。

不是教辅 App、不是题库、不是搜题/解题、不是内容平台；试卷与学习材料只是它擅长处理的内容类型。

## 2. 核心价值链

```text
采集 → 整理 / 找回 → 导出 / 打印
```

回顾、统计、智能增强可提供附加价值，但**不得占据、阻塞或复杂化主路径**。图片是内容真相，OCR 是辅助表达。

## 3. 耐久边界（改动需重新裁决）

- **local-first**：无账户、单一资料库、永久可携带的手动备份
- **免费、无广告、无 IAP**；核心闭环不得靠限制录入、锁定资料或加水印变现
- **用户拥有数据**：可查看 / 编辑 / 删除 / 导出 / 备份；图片入库前去除 EXIF GPS
- **无开发者内容云**：默认不建立可访问的用户内容后端，不恢复第三方行为分析
- **中性成人工具**：界面与文案成熟中性，无低龄化、焦虑、排名、连续签到
- **Apple 原生优先**，第三方依赖不得削弱隐私或依赖边界

## 4. Release 1 · Must outcomes（结果级，可验收）

| # | 必须满足的用户结果 |
| --- | --- |
| 1 | 不注册/不登录即可完成核心链路；普通启动默认 Dashboard，一次操作可达 Capture 与 Library |
| 2 | 相机、文档扫描、相册、PDF 输入；OCR 失败不阻止保存可读图片 |
| 3 | 资料库支持浏览、搜索、筛选、详情、编辑、分类与删除 |
| 4 | 删除后提供持久化五秒撤销；后台与重启不缩短窗口 |
| 5 | 多选资料生成无空白/无重复条目的 PDF，可预览、分享、保存、系统打印；打印是一等终点 |
| 6 | 完整手动备份与恢复；损坏 store 有可理解的恢复路径，不静默丢数据 |
| 7 | 权限拒绝、OCR 失败、存储失败、DB 打不开均有替代路径，不白屏、不假空库 |
| 8 | 未保存草稿在异常退出后可恢复；仅保存成功或用户明确丢弃才删除 |
| 9 | 内容默认只在设备处理；无未授权网络上传 |
| 10 | 中英文、VoiceOver、Dynamic Type、iPhone 竖屏下可完成核心任务 |
| 11 | 公开构建中未批准能力**零入口、零激活、零副作用**（含 Tab、通知、深链、后台任务、AX 元素） |

## 5. 明确非目标

账号 / Profile / Workspace / 儿童身份；题库、搜题、答案搜索、自动解题、课程与内容推荐；社交、排行榜、签到、虚拟奖励；CloudKit 或同步、开发者内容后端、第三方行为分析；Pro / StoreKit / 订阅 / 广告；Word 导出；iPad / Mac / Vision Pro 发行；中国大陆专项版；Share Extension / App Intent / Shortcut / Widget；Review、SmartPaper、高级统计的公开入口。

代码里已经存在 ≠ 产品已批准；未批准能力默认隐藏。

## 6. 平台与发布

iOS 26+、iPhone-only、英文 + 简体中文、免费无广告无 IAP、美国主体全球版。

## 7. 验收判据

1. **测试能否仅凭本文写出用例** —— 每条 Must 至少对应一个可观察结果
2. 新用户无需说明即可完成「采集 → 补充 → 保存 → 找回 → 导出 / 打印」
3. 草稿、删除、DB 打开失败、备份与恢复的失败路径不静默丢数据
4. 无未预期网络上传、广告、IAP、账号或隐藏功能副作用
5. 签名、隐私、构建、安装、App Store Connect 事实绑定到**同一候选提交**
