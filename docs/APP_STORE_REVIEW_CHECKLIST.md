# App Store 审核检查清单

> 基于 Apple App Store Review Guidelines 2025 版本  
> 最后更新: 2025年11月27日

---

## 📋 审核前必检项目

### 一、隐私与数据 (Guideline 5.1)

#### 1.1 隐私权限声明 ✅

当前项目 `Info.plist` 配置：

| 权限 | Key | 已配置 | 说明 |
|------|-----|--------|------|
| 相机 | `NSCameraUsageDescription` | ✅ | "需要使用相机拍摄错题照片" |
| 相册 | `NSPhotoLibraryUsageDescription` | ✅ | "需要访问相册选择错题照片" |
| 推送 | `UIBackgroundModes` | ✅ | `remote-notification` |

**审核要点：**
- ✅ 所有权限都有清晰的中文说明
- ✅ 说明与实际用途一致
- ⚠️ 建议：权限说明可更详细，如"用于拍摄错题并保存到错题本"

#### 1.2 隐私政策 (必需)

- [ ] 提供隐私政策 URL（App Store Connect 必填）
- [ ] 隐私政策包含以下内容：
  - [ ] 收集哪些数据
  - [ ] 如何使用数据
  - [ ] 数据存储位置（本地/云端）
  - [ ] 第三方数据共享情况
  - [ ] 用户删除数据的方式
  - [ ] 联系方式

**推荐隐私政策模板：**

```
NotBad 错题本 隐私政策

1. 数据收集
   - 错题图片：存储在本地设备/iCloud
   - 学习数据：学科、掌握程度等元数据
   
2. 数据使用
   - 仅用于错题管理和复习提醒
   - 不会用于广告或营销
   
3. 数据存储
   - 默认存储在设备本地
   - 可选启用 iCloud 同步
   
4. 数据共享
   - 不与任何第三方共享用户数据
   
5. 数据删除
   - 用户可随时在 App 内删除所有数据
   - 卸载 App 将删除本地所有数据
   
6. 联系方式
   - 邮箱: [your-email@example.com]
```

#### 1.3 App Privacy（App Store Connect 隐私标签）

根据项目功能，需要填写的隐私标签：

| 数据类型 | 是否收集 | 用途 | 是否与用户关联 |
|---------|---------|------|---------------|
| 照片 | ✅ | App 功能 | ✅ 是 |
| 用户内容 | ✅ | App 功能 | ✅ 是 |
| 使用数据 | ⬜ 待确认 | - | - |
| 诊断数据 | ⬜ 待确认 | - | - |

### 二、内容与功能 (Guideline 4.0)

#### 2.1 功能完整性

- [ ] 所有功能正常工作（无崩溃、无无限加载）
- [ ] 空状态有合理的提示和引导
- [ ] 所有按钮和链接都可响应
- [ ] 没有占位符内容（Lorem ipsum、示例图片等）

#### 2.2 内容年龄分级

NotBad 错题本建议分级：

| 分级选项 | 建议选择 | 说明 |
|---------|---------|------|
| 暴力内容 | 无 | 教育类应用 |
| 成人内容 | 无 | 无任何成人内容 |
| 赌博 | 无 | 不涉及 |
| 恐怖内容 | 无 | 不涉及 |
| 医疗信息 | 无 | 不涉及 |
| 用户生成内容 | ✅ 有 | 用户可拍照上传 |

**建议年龄分级：4+**（教育类应用）

#### 2.3 本地化检查

- [ ] 所有 UI 文案使用中文
- [ ] 日期格式符合中国习惯
- [ ] 没有未翻译的英文字符串

---

### 三、设计规范 (Guideline 4.0)

#### 3.1 Human Interface Guidelines 合规

- [ ] 使用标准 iOS 控件和手势
- [ ] 支持深色模式
- [ ] 支持 Dynamic Type（动态字体）
- [ ] iPad 适配（如声明支持）
- [ ] 安全区域适配（刘海屏、灵动岛）

#### 3.2 App 图标

- [ ] 提供所有必需尺寸的图标
- [ ] 图标清晰、可识别
- [ ] 图标与 App 功能相关
- [ ] 图标不含透明度（iOS 图标要求）

#### 3.3 启动屏幕

- [ ] 使用 LaunchScreen.storyboard 或 Launch Screen Info.plist
- [ ] 启动屏幕不含广告
- [ ] 启动屏幕到主界面过渡流畅

---

### 四、技术要求 (Guideline 2.0)

#### 4.1 性能要求

- [ ] 冷启动时间 < 400ms（Apple 建议）
- [ ] 无内存泄漏
- [ ] 无主线程阻塞
- [ ] 电池消耗合理

#### 4.2 稳定性要求

- [ ] 无崩溃（Crash 率 < 0.1%）
- [ ] 无 watchdog 超时
- [ ] 网络断开时正常工作（离线模式）

#### 4.3 兼容性

当前项目配置：
- **最低 iOS 版本**: iOS 26.0+
- **支持设备**: iPhone + iPad

- [ ] 在最低支持版本上测试
- [ ] 在不同尺寸设备上测试
- [ ] 在模拟器和真机上都测试

---

### 五、元数据 (Guideline 2.3)

#### 5.1 App Store 信息

- [ ] App 名称清晰、不误导
- [ ] 副标题简洁描述功能
- [ ] 描述与实际功能一致
- [ ] 关键词合理、不堆砌
- [ ] 截图真实展示 App 界面
- [ ] 预览视频（如有）真实展示功能

**建议 App Store 描述：**

```
NotBad 错题本 - 科学复习，轻松提分

【核心功能】
📸 快速采集：拍照即可录入错题
🧠 科学复习：基于艾宾浩斯遗忘曲线智能提醒
📊 学习统计：可视化掌握进度
🏷️ 分类管理：按学科、难度、知识点整理

【特色亮点】
• 简洁设计，专注学习
• 本地存储，保护隐私
• 支持 iCloud 同步
• 完全免费，无广告

适合人群：中小学生、备考学生、终身学习者
```

### 六、安全合规 (Guideline 5.6)

#### 6.1 数据安全

- [ ] 敏感数据使用 Keychain 存储
- [ ] 网络请求使用 HTTPS
- [ ] 无硬编码的密钥或凭证
- [ ] 图片数据在本地加密存储（如需）

#### 6.2 代码安全

- [ ] 无调试代码泄露到 Release
- [ ] 无私有 API 调用
- [ ] 无第三方 SDK 违规使用

---

### 七、特殊功能声明

#### 7.1 后台模式

当前配置的后台模式：
- `remote-notification`：远程推送

- [ ] 后台模式使用合理，有实际需求
- [ ] 不滥用后台刷新

#### 7.2 App Groups / iCloud

当前 Entitlements 配置：
- `com.apple.developer.icloud-services`: CloudKit
- `aps-environment`: development（需改为 production）

- [ ] 上架前将 `aps-environment` 改为 `production`
- [ ] iCloud 容器 ID 配置正确
- [ ] App Groups 配置正确（如有 Widget）

## 🚫 常见拒审原因及规避

| 原因 | 对应条款 | 规避方法 |
|------|---------|---------|
| 崩溃或 Bug | 2.1 | 充分测试，使用 TestFlight 内测 |
| 功能不完整 | 2.1 | 确保所有功能可用 |
| 隐私政策缺失 | 5.1.1 | 提供完整隐私政策 |
| 权限说明不清 | 5.1.1 | 权限描述要具体 |
| 元数据不准确 | 2.3 | 描述与功能一致 |
| 用户界面问题 | 4.0 | 遵循 HIG 设计规范 |
