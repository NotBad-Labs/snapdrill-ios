## 商业化铁律

**绝不限制录入数量。**

竞品普遍采用限制免费录入数量的模式（如"每天免费 10 道"），用户反馈负面。不限制录入是 SnapDrill 的核心差异化。
录入是生命线，限制录入等于削弱产品核心价值。

## 付费模式（Freemium + 订阅，Bear 模式，2026-03-07 确立）

**定价模式**：参照 Bear（$2.99/月 或 $29.99/年），SnapDrill Pro 为打包订阅。
iCloud 同步与其他增值功能打包，不单独售卖同步——避免 App Store 审核指引 3.2.2 风险。智能组卷和高级统计的 Hybrid 定价详见 ADR-001。
Bear / Day One / Ulysses 等 iOS 独立 App 已验证此模式多年，Apple 审核无问题。

| 免费（永久） | SnapDrill Pro（订阅） |
|---|---|
| 完整单设备闭环（采集→管理→导出/打印） | iCloud 多设备实时同步（核心卖点） |
| 间隔重复复习 + Multi-Profile | 图片处理增强：去手写/去批改痕迹/试卷还原（免费限次体验 + Pro 无限） |
| 智能组卷：基础模板限次体验 | 智能组卷：无限生成 + 精准选题（weakness/difficulty/recency）+ 多版式（ADR-001） |
| 基础统计（总题数、按科目计数、近期趋势） | 高级统计：趋势图 + 难度分布 + 薄弱排行 + 交叉筛选（ADR-001） |
| 手动备份/恢复（`.zip`） | Word 导出（Pro 付费；高级排版，家长二次调整后打印；[阻塞: #486（前置 #479）]）|

免费层包含 MoSCoW Must + Should 全部功能，Pro 层包含 Could 中的增值项。完整功能清单见 `../reference/scope-and-roadmap.md`§功能全景。
探索性商业化方向见 `../reference/scope-and-roadmap.md`§待评估。

> ⚠️ Pro 功能为目标设计，**当前实现状态见 `../reference/feature-status.md`§功能状态总表**：StoreKit #479 未接（源码 `ProEntitlementProvider.isProUser` 硬编码 false），Pro 全部为"敬请期待"占位，首版国内 TestFlight 纯免费、无法购买或测试 Pro。

**Word 导出定位说明**（承接 vision §1 录入体验是生命线 + §4 数据属于用户）：
- PDF 是基础导出（免费），覆盖「打印一份错题卷」核心场景
- Word 是 PDF 的增值升级（Pro），用于家长想二次调整段落格式、页眉页码、字体后再打印
- 不破坏 vision §1 边界——Word 不是新的录入路径，是导出格式的增值延伸

**分层原则**（2026-04-01 讨论确立）：
- 免费层 = 完整的单设备产品体验（核心价值链闭环：采集 → 管理 → 导出/打印，另含可选留存功能：复习、智能组卷基础体验）
- Multi-Profile 是基础可用性（多孩家庭），不是增值体验，放免费层
- 付费层 = 跨设备流转 + 智能增强 + 图片处理增强，核心卖点是 iCloud 同步
- 图片处理增强（去手写/去批改痕迹/试卷还原）采用"免费限次体验 + Pro 无限使用"策略，让用户先感受价值再转化（蜜蜂试卷/橙果/试卷宝均验证此模式）
- 智能组卷（Smart Paper）和高级统计采用 Hybrid 模式（免费限次/基础 + Pro 无限/深度），与图片处理增强策略统一（ADR-001，2026-04-10 决策）
- 智能组卷是 Pro 核心转化引擎（算法选题 + 多版式），高级统计提升 Pro 专业感和长期价值

**免费层完整定义**：

| 环节 | 免费层能力 | 边界说明 |
|---|---|---|
| 采集 | Camera / Photos / PDF / Manual / Clipboard(文本) / Share Extension 全入口可用；无限录题；OCR 展示、复制、手动修正可用 | 不限制录入数量，不做"每日 N 题" |
| 管理 | 搜索、学科/标签/难度过滤、排序、编辑、批量打标签、批量删除、Multi-Profile | 单设备内题库完整可管理，多孩家庭可直接使用 |
| 导出 | PDF、PDF 增强（去答案打印/留白/页眉页码）、单题快速打印、JSON、CSV、`.zip` 手动备份/恢复 | 导出/打印是基础能力，不作为订阅门槛。注意：基础"去答案打印"（隐藏答案字段）是免费功能，与 Pro 的"图片处理增强"（AI 去手写/去批改痕迹）是不同层面 |
| 复习 | 基础 SM-2 间隔重复复习、Dashboard 待复习入口、复习卡片外观设置 | 复习是免费附加值，不做强制付费墙 |
| 数据管理 | 纯本地存储、卸载提醒、媒体缓存清理、换机靠手动备份恢复 | 免费层不含 iCloud 自动同步，但必须可迁移 |

**免费版体验完整性保障**：
- 单设备无限录题 + 无广告 + 纯本地 = 完整可用的产品
- `.zip` 手动备份/恢复 = 免费用户换手机不丢数据，确保用户数据可携带、不被平台锁定。此承诺建立在备份格式持续向后兼容之上（见 `../features/active/feat-backup.md`§备份与恢复设计 + `../features/active/feat-backup.md`§备份与恢复）
- 付费解锁的是「增值体验」（多设备流转、图片处理增强、高级导出），不是「基础能力」

**数据迁移方案**：
- 免费用户：手动导出 / 导入 `.zip` 备份文件
- Pro 用户：iCloud CloudKit 自动同步，换机后数据自动回来

**核心付费场景**：家长"妈妈手机随时拍 + 孩子 iPad 随时练 + 打印机随时印"的闭环工作流，
iCloud 同步是打通这个闭环的引擎，图片处理增强（去手写/试卷还原）和组卷排版是核心增值能力。

**订阅取消后数据降级策略（硬性承诺，StoreKit 落地前定稿）**：
- **数据完整保留**：本机已同步的所有题目、Profile、复习进度、图片**完全保留**，**完整可编辑**，与免费用户体验一致
- **核心功能降级清单**：取消订阅后**仅**关闭以下 Pro 能力：
  - iCloud 多设备同步（新数据停止跨设备 push，本机数据仍在）
  - 智能组卷无限生成（回到免费层基础模板限次）
  - 高级统计图表（回到免费层基础统计）
  - 图片处理增强（回到免费层限次体验额度）
  - Word 导出（回到 PDF 免费导出）
- **数据所有权不变**：可继续查看、编辑、删除、导出（PDF/JSON/CSV/.zip）、手动备份所有数据
- **不得做**：不锁定题目为「只读」、不隐藏图片、不阻断手动备份、不诱导「再不订阅就丢失」
- 该承诺写入 App Store 描述与隐私政策，避免事后被指控「订阅陷阱」

### 定价策略（2026-04-01 确立，横向研究 Infuse / Bear / Craft 后决策）

**全免费发布**——先积累口碑和用户基数，不上订阅。

**Pro 订阅（iCloud 同步就绪后引入）**——iCloud 同步为核心付费点，图片处理增强（去手写/去批改痕迹/试卷还原）和高级导出为增值功能。

**分市场定价**（Apple 允许每个 Storefront 独立设定订阅价格）：

| 层级 | 中国区（CNY） | 美国区（USD） | 说明 |
|---|---|---|---|
| **Pro 月订阅** | ¥8/月 | $1.99/月 | 起步低价获客 |
| **Pro 年订阅** | ¥68/年 | $19.99/年 | 年费优惠约 30% |
| **Lifetime 买断** | ¥298 | $49.99 | 为不喜欢订阅的用户提供选择 |

**14 天 Free Trial**——让用户先体验 iCloud 同步的便利再决定是否付费（Bear 的做法）。

**Grandfather 涨价策略**（Bear 模式）：
- 老用户永远保持注册时的价格，涨价只影响新用户
- 用户量增长验证后，新用户涨到 ¥12/月 / $2.99/月
- 老用户只要不中断订阅，永远保持 ¥8/月 / $1.99/月
- Apple StoreKit 原生支持此模式——续期按原价扣，新订阅按新价

**汇率说明**：¥8 CNY ≈ $1.10 USD，与 Apple 均衡化体系中 ¥6 → $0.99 的映射一致 [来源: Apple App Store Connect 定价矩阵，各 Storefront 独立设定]。
不建议中美同价（¥9.9/月 vs $9.9/月），汇率差 7 倍会导致定价失衡。

**定价原则**：
- 首发全功能免费（积累用户和口碑）
- 付费功能必须是"增值"而非"解锁基础能力"
- 价格定位：用户群体（家长 + 学生）可承受（对标 Bear $2.99/月 的工具 App 价位）
- 不做去水印——产品本身不应该有水印，这不是尊重用户的做法
- 保留 Lifetime 选项——参考 Infuse（$94.99 起），为一次性付费用户提供选择

**竞品定价参考**（2026-04-01 调研，价格为调研当日数据，可能已变动）：

| App | 月费 | 年费 | Lifetime | 模式 |
|---|---|---|---|---|
| **Infuse** | $0.99 | $9.99 | $94.99 | 免费够用，Pro 加码 |
| **Bear** | $2.99 | $29.99 | 无 | 免费单设备，Pro 同步+导出 |
| **Craft** | ~$8 | ~$96 | 无 | 免费有上限，Plus 无限 |
| **SnapDrill** | ¥8/$1.99 | ¥68/$19.99 | ¥298/$49.99 | 免费完整，Pro 同步+增值 |

## 隐私策略（2026-03-07 确立，Bear 模式）

> 产品承诺：`vision.md`§P4 数据属于用户
> 功能规格（字段、opt-in）：`../features/active/feat-settings.md`§使用数据
> 技术实现：`privacy-compliance.md`§核心口径

**核心定位**：参照 Bear（Shiny Frog）的 Freemium + Apple CloudKit 模式——不自建用户账号，不主动收集儿童信息。这是 vs 国内竞品（喵喵机/橙果等）的关键差异。

| 维度 | 竞品（喵喵机/橙果等） | SnapDrill |
|---|---|---|
| 注册 | 手机号必须 | 无注册 |
| 数据收集 | 姓名、学校、年级、位置 | 默认不收集。**国内版**（当前 shipping）：纯本地、零 Firebase（注入 `NoOpAnalyticsService`，ADR-004）；**海外版**（C 路径，未来）：匿名 Analytics / Crashlytics 独立开关，opt-in 后可关闭 |
| 存储 | 自建云端 | 纯本地（iCloud 多设备同步规划中，[阻塞: #485（前置 #479）]；Apple 负责） |
| 合规负担 | 极重（ICP+等保+审计+儿童隐私） | 较轻（App 备案 + Apple 审核，不主动收集用户数据） |

**为什么这是核心差异化**：
- 2025 年中国四部门联合专项行动，3852 款 App 被通报侵害用户权益（同比增 152%）[来源: 工信部/网信办等四部门 2025 年度 App 侵害用户权益专项整治通报]
- 教育类 App 是重点监管对象——收集儿童个人信息属于敏感信息处理
- 家长最怕孩子的学习数据被平台收集利用
- SnapDrill 不主动收集用户数据 = 大幅降低监管风险 + 家长信任

**iCloud 区域差异**：中国区 iCloud 由云上贵州运营，数据存储在中国境内；中国大陆 iCloud 同步体验可能与其他市场有差异，iCloud 同步实现时做针对性测试。开启 Apple Advanced Data Protection 后，CloudKit 数据端到端加密，只有用户能解密。

**用户须知（必须在产品中醒目提示）**：
- 免费版纯本地存储，**卸载 App = 数据永久丢失**——需在设置中和适当时机明确提醒
- 建议定期手动备份（`.zip` 文件），或升级 Pro 启用 iCloud 自动同步

### App Store 年龄分级策略（2026-03-23 确立）

**年龄分级**：**4+**（Unrestricted）。SnapDrill 无不当内容、无社交功能、无 App 内购买诱导、无第三方广告。

**Kids Category 决策**：**不申请**。理由：
- Kids Category 限制较多（禁止外部链接、禁止第三方 SDK 向儿童发送数据等）
- SnapDrill 二进制含第三方分析/崩溃 SDK（海外版启用 Firebase；国内版 Firebase-Free、运行时不初始化，编译层尚未剔除待 C 路径 —— ADR-004），技术上仍属含第三方 SDK
- SnapDrill 的主操作者是家长（非儿童直接使用），定位为「家庭场景的效率工具」而非「儿童 App」
- 4+ 年龄分级已足以覆盖目标用户群

**Declared Age Range API**（iOS 26+）：后续评估是否集成。该 API 允许 App 请求用户分享其年龄范围（由系统从 Apple Account 获取，需家长同意）。SnapDrill 的目标用户横跨多个年龄段（家长 + 6-18 岁学生），需评估是否及如何使用。美国多州已立法要求年龄核实，持续关注。**硬边界（与 vision §4 隐私优先一致）**：仅在 App Store 审核要求 / 法规强制要求场景下集成，**绝不**作为日常 Analytics 维度采集；集成时年龄范围信息只用于审核 / 合规判定，不存储、不上传、不进入 Analytics 事件属性。

**COPPA / 儿童隐私合规姿态**（2026-03-30 更新）：

SnapDrill 的产品定位是**效率工具**（utility tool），不是教育工具（educational tool）：
- 不提供任何教育内容（无课本、无试卷、无题库）
- 所有内容由用户自主拍摄和录入
- 本质是"采集 → 管理 → 导出/打印"的数字化归档工具
- 类比：Scanner Pro、备忘录 — 学生也用，但不是"面向儿童的 App"

FTC 判定 COPPA "directed to children" 的核心标准与 SnapDrill 的对照：
1. **视觉设计和语气** — 成熟、家长友好基线，非幼稚卡通风格
2. **是否提供面向儿童的内容** — 不提供任何内容，所有数据来自用户
3. **营销对象** — 面向家长和学生，非专门面向 <13 岁儿童
4. **App Store 分类** — 未进入 Kids Category

虽然用户群包含 12-13 岁初中生，但效率工具定位与 "directed to children" 有本质区别。

**当前合规措施**：
- 零注册、默认不收集个人信息
- 匿名使用数据：**国内版**（当前 shipping）完全禁用（注入 `NoOpAnalyticsService`，OSLog 实测零网络出境，ADR-004）；**海外版**（C 路径，未来）首次启动默认不采集、用户可在设置中 opt-in
- Privacy Manifest 声明数据不关联、不追踪

**App Store 营销注意事项**：避免使用 "children""kids""儿童教育" 等触发 FTC/Apple 审查的措辞，强调"效率工具""数字化归档""家长和学生"。

**后续评估**：如 App Store 审核或法律咨询认为需更严格合规，再考虑 Declared Age Range API 集成或 Analytics 默认关闭。美国多州已立法要求年龄核实，持续关注。

### 隐私合规风险应对预案

| 风险场景 | 影响 | 应对措施 | 升级触发条件 |
|---|---|---|---|
| **COPPA 混合受众质疑** — FTC 或 Apple 认定 SnapDrill "directed to children" | App 下架或罚款 | 保持效率工具定位；ASO 避免 children/kids 措辞；Analytics 预留默认关闭开关；预备 Declared Age Range API | App Store 审核被拒含 "children" 关键词；或收到 FTC inquiry |
| **中国数据合规趋严** — 教育类 App 被要求 ICP 备案或等保测评 | 中国区下架风险 | 纯本地 + iCloud（云上贵州）不触发跨境传输；App 备案按要求完成；不主动收集用户数据 | 监管新规明确覆盖"不收集数据的工具类 App"；或收到整改通知 |
| **App Store 审核拒绝** — 隐私条款变更导致被拒 | 发布延迟 | Privacy Manifest 每次 Xcode 大版本更新时检查；第三方 SDK 跟进 Apple 签名要求 | 被拒且 Resolution Center 反馈涉及隐私条款 |

**日常检查节奏**：
- 每次 iOS 大版本（WWDC 后）：审查 Privacy Manifest 要求变更
- 每季度：扫描 FTC 和中国监管最新通报
- App Store 审核被拒时：立即分析拒绝理由，归档到本表

## 商业模型假设

> 发布前用于统一口径和埋点定义；数值假设待真实用户数据验证，不作为对外承诺。

| 指标 | 定义 | 用途 | 当前口径 |
|---|---|---|---|
| DAU | 当日打开 App 且完成至少一次有效会话的去重设备数 / 用户数 | 衡量日常使用黏性 | 待发布后以 Analytics 事件定义固化 |
| MAU | 最近 30 天内至少完成一次有效会话的去重设备数 / 用户数 | 衡量月活规模 | 待发布后以 Analytics 事件定义固化 |
| DAU/MAU | 日活与月活之比 | 衡量使用频率与产品习惯形成度 | 目标是验证"高频录入 + 低压复习"是否成立 |
| Trial Start Rate | 看到付费墙后开启 Free Trial 的用户占比 | 衡量付费墙和价值表达是否有效 | iCloud 同步上线后可衡量 |
| Trial Conversion Rate | Trial 到期后转为付费订阅的用户占 Trial 开启用户比例 | 衡量 iCloud 同步和增值功能是否足够打动用户 | 核心商业化指标之一 |
| Paid Conversion Rate | MAU 中成为有效付费用户的比例 | 衡量整体变现效率 | 与 Trial Conversion Rate 联动观察 |
| Retention D1 / D7 / D30 | 注册日或首次使用日后第 1/7/30 天仍活跃的用户比例 | 衡量首次价值、周留存和月留存 | 首轮验证录入闭环与复习附加值 |
| ARPPU | 平均每个付费用户带来的收入 | 衡量定价和产品组合是否健康 | 需区分月订阅 / 年订阅 / Lifetime |
| LTV | 单个用户生命周期内贡献的累计净收入 | 用于判断可持续获客与长期价值 | 需结合 churn、续订率和成本估算 |
| Churn Rate | 订阅用户在一个计费周期后流失的比例 | 衡量订阅稳定性和取消后的价值缺口 | 与订阅取消后降级策略强相关 |

## 已知风险与张力

> 本节于 2026-05-29 自 `product-vision.md` 迁移（vision 瘦身重构：vision 只留 why，本类规格归本文档）。

### 免费完整 vs Pro 转化

免费层越完整，付费转化越依赖 iCloud/组卷/图片增强的真实价值。如果免费用户发现手动备份 + 单设备足够满足需求，Pro 转化率会极低。发布后前 3 个月验证此张力。

### 纯本地 vs 增长

不做社交、不做内容、不做打卡、不做推荐，意味着没有网络效应驱动的增长引擎。增长完全依赖 App Store ASO + 口碑。需验证"零摩擦工具"本身是否能驱动足够的自然传播。

### 隐私 vs 数据驱动

**（海外版）** Analytics 默认 opt-in，意味着行为数据只覆盖愿意授权的用户子集；如果 opt-in 率过低（< 10%），成功信号将严重偏向早期 adopters，可能误判产品方向。**国内版** Firebase-Free、零采集，无此偏差，但也因此完全依赖 App Store Connect / 访谈 / TestFlight 信号（ADR-004）。

### iCloud 变现的承载能力

iCloud 同步作为 Pro 核心引擎，受限于：用户已有 iCloud 空间（5GB 免费易击穿）、中国区 CloudKit 性能、用户可能只用单设备不需要同步。如果 iCloud 不足以支撑付费转化，需要准备替代或补充的变现路径（如高级导出格式、批量打印排版、专业 OCR 增强等）。
