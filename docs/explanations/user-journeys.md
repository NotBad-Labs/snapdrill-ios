# SnapDrill 用户旅程

> **上游依赖**：`vision.md`（使命、产品原则）、`positioning-and-audience.md`（通用受众定位）。
>
> 本文件用代表性的成人 / 通用生产力工作流验证产品设计是否真的支撑了用户需求。
> 用户是管理自己资料的成年人；产品也服务成年人整理家庭资料，但不建立儿童独立账户、儿童模式或儿童专属体验。
>
> 旅程内容变更由开发者维护；新增旅程或修改验证结论需产品负责人确认。

---

## 旅程 1：首次采集与保存（first capture）

**人物**：方哲，自由职业设计师，第一次打开 SnapDrill。
**触发**：桌上有一份纸质参考资料，他想验证「拍一张就能存下来」。

**步骤**：

1. **首次打开**。系统自动创建默认资料库（vault），不要求注册、不要求填身份信息、不要求先配置字段。Onboarding 只用几页说明：这是一个采集、归档、整理任何题目与文档的效率工具。
2. **进入采集**。底部 Tab 里「采集」明确可达，他直接点进去。
3. **拍第一项**。举起手机拍照，自动框选基本正确，他微调边缘后确认。
4. **OCR 展示结果**。识别出文字，界面不强迫他逐字校对，也不堆一屏字段。
5. **直接保存**。点保存，得到成功反馈，内容已入库。从进入采集页到保存完成控制在 30 秒内（不含 Onboarding）。
6. **轻量引导下一步**。保存后才提示：以后想补充来源、级别或自定义属性等字段可在设置里按需开启——不是第一次就必须做的事。

**结束状态**：默认资料库已建立，第一项内容完成录入，用户确认这是一个零学习成本就能开始的工具。

**关键设计验证**：
- 首次启动不索取额外信息，零注册不挡门外
- Onboarding 只解释价值、不要求配置
- 默认字段极少，首次即可完成录入
- 进入采集页到保存成功 < 30 秒，符合愿景成功信号

## 旅程 2：长期考试/题目归档（long exam/problem archive）

**人物**：陈澜，在职备考研究生入学考试的成年人，已积累一段时间。
**触发**：做完一套模拟卷，要把需要回看的几道题归档，并把老师在群里发的练习图也存进来。

**步骤**：

1. **连续拍照录入**。试卷铺在桌上，对准第一道需要回看的题拍照、裁剪、OCR、保存；保存后自动回到摄像头，连续录入下一道，无需每次重新进入采集。
2. **一图多题裁剪**。群里转发的一张图含 4 道题，她从相册导入后框住第 1 道保存，同一张图再次出现，继续框住第 3 道保存——一张图连续裁剪多题，零重复选图。
3. **PDF 导入**。教辅 PDF 共 8 页，她选中含重点题的几页，逐页裁剪录入，原图中的公式、图形作为图片完整保留。
4. **元数据自动沿用**。分类、来源等字段沿用上次选值作为默认，连续录入摩擦最低。

**结束状态**：题库持续增长，每条记录保留裁剪后的原图与可检索 OCR 文本，元数据一致。

**关键设计验证**：
- 采集入口一步可达，保存后连续录入无摩擦
- 一图多题、PDF 多页选择不重复操作
- 原图是真相（公式 / 图形完整保留），OCR 不完美不阻塞保存
- 字段自动沿用减少重复输入

## 旅程 3：职业证书/培训资料整理（professional certification / training material）

**人物**：林越，职场人士，正在备考一门职业证书（如 PMP / CPA）。
**触发**：培训机构发来一批讲义与真题 PDF，他想按来源归类，便于冲刺阶段按主题调取。

**步骤**：

1. **PDF 导入 + 逐页选择**。从文件 App 打开培训讲义 PDF，逐页预览，选中要归档的页。
2. **裁剪录入 + 自定义来源**。裁剪某道真题，来源选「机构真题」（他之前自定义新增的选项），分类自动填好，保存。
3. **打标签**。给重点题加自定义标签「高频」「重点」，便于后续按主题过滤。
4. **混合内容 OCR**。讲义含中英文术语，OCR 同时识别；个别符号识别不准他手动修正关键术语，其余以原图兜底。

**结束状态**：证书备考资料按来源 / 标签结构化归档，可在冲刺阶段按主题快速调取。

**关键设计验证**：
- PDF 导入支持多页选择，覆盖培训资料场景
- 自定义来源 / 标签满足专业分类需求
- 中英文混合 OCR 可用，修正只需补对自己有价值的关键词
- 工作流对试卷 / 题目保持专业锐度，但不绑定任何特定人群

## 旅程 4：用分类整理不同项目（organize projects with taxonomy）

**人物**：苏宁，同时整理工作、考试与家庭资料。
**触发**：她希望快速区分不同来源和场景，但不想维护多个工作区。

**步骤**：

1. **建立分类**。用分类、来源、级别、标签或自定义维度表达项目与场景。
2. **采集并归类**。保存时选择对应字段，系统保留原图与 OCR 文本。
3. **过滤与导出**。在唯一资料库中组合过滤条件，得到某个项目的资料集并导出/打印。
4. **跨主题检索**。需要全局搜索时无需切换上下文，所有资料仍在一个索引内。

**结束状态**：一个资料库承载全部资料，动态 taxonomy 提供组织边界。

**关键设计验证**：
- 无工作区创建/切换成本
- 分类组合足以覆盖不同项目与场景
- 过滤只影响展示，不改底层数据
- 个人资料不等于数据 partition

## 旅程 5：搜索 / 过滤 / 编辑（search / filter / edit）

**人物**：陈澜（同旅程 2），距考试两周，已积累 80+ 条记录，想按主题整理重点。
**触发**：想按分类和薄弱点把重要题目挑出来，考前重点看。

**步骤**：

1. **进入题库**。默认按录入时间倒序，看到全部记录。
2. **多维过滤**。按分类过滤缩减列表，再叠加标签「几何」与自定义的「考前重点」级别，缩小到一组需要集中整理的题目。
3. **查看与编辑**。打开一道题看原图、OCR 文字、元数据；发现缺答案，点编辑补上解题思路与一张手写过程照片，保存。
4. **改元数据 + 批量打标签**。把另一道题的级别字段改为「重点」；进入选择模式勾选 5 道类似题，一次性批量打上「考前」标签。
5. **搜索**。记得某题含「抛物线」，搜索框输入关键词，命中 OCR 识别过的文字。
6. **误删与撤销**。整理中误删一道题，底部 Toast「已删除，5 秒内可撤销」，点撤销立即恢复。

**结束状态**：约 20 分钟完成整理——补答案、调整动态字段、批量打标签、按需检索。

**关键设计验证**：
- 过滤支持多维组合（分类 + 标签 + 自定义字段）
- 搜索基于 OCR 文字
- 编辑完整：补答案（文字 + 图片）、改动态字段、加标签、批量操作
- 软删除 + 5 秒撤销兜底误删，不做回收站

## 旅程 6：导出 / 打印（export / print）

**人物**：林越（同旅程 3），冲刺阶段，想把一组题打印成纸质练习。
**触发**：把「高频」标签的题目过滤出来，导出成可打印资料。

**步骤**：

1. **过滤结果集**。在题库按标签 / 分类过滤形成结果集。
2. **PDF 导出 + 预览**。发起 PDF 导出，进入导出前预览，可选「去答案模式」（隐藏答案字段）、留白答题区、页眉页码。
3. **打印**。确认后生成 PDF，通过系统打印（AirPrint）输出纸质资料；也可分享 / 保存 PDF。
4. **单题快速打印**。其中一道特别重要的题，他在详情页选中直接快速打印（固定 1 题/页），贴在桌前。

**结束状态**：导出一份去答案打印资料并打印，单题快速打印 1 道；原始数据不被导出修改。

**关键设计验证**：
- 过滤 → 导出 PDF → 打印路径通畅，打印是价值链一等终点
- 「去答案模式」（免费，隐藏答案字段，布局层）与 Pro 的「图片处理增强」（AI 去手写）是不同功能
- 导出 / 打印是只读操作，不夹带其他资料库的内容
- 导出不嵌水印 / 广告 / 公开传播引导

## 旅程 7：备份 / 恢复（backup / restore）

**人物**：方哲（同旅程 1），换新 iPhone，免费用户，未订阅 Pro。
**触发**：旧手机换新，他希望题库完整迁移，且不依赖账号或云订阅。

**步骤**：

1. **旧设备手动备份**。在设置页导出一个 `.zip` 文件（打包全部资料库的题目、图片、元数据、复习进度），通过系统分享面板保存到文件 App / 网盘。
2. **新设备安装并恢复**。新机首次打开自动创建默认资料库，设置中提供恢复入口；选中 `.zip` 后系统先校验文件完整性与版本兼容性。
3. **执行恢复**。校验通过后恢复全部资料库的题库、标签、复习进度与图片，不依赖账号登录，也不依赖 iCloud 订阅。
4. **异常透明兜底**。若部分图片解压失败，结果摘要明确提示「图片缺失」，不假装全部成功；元数据原子恢复（全成功或回滚）。

**结束状态**：免费用户完成换机迁移，数据可带走、不被平台绑定。

**关键设计验证**：
- 免费用户也有可执行的数据迁移路径，`.zip` 是完整恢复入口而非象征性导出
- 恢复前先校验，失败时不破坏现有数据
- 元数据原子恢复、图片 best-effort，失败项透明提示，不静默吞掉
- 备份覆盖全部资料库，迁移后隔离关系保持一致
