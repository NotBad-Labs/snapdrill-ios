## 它的地位：驾驶舱，不是宪法

这张图**不是真相源，是决策视图**。它聚合下面这些 SSOT，只回答一个问题：「现在做什么 / 这块值不值」。**它和任何 SSOT 冲突时，SSOT 赢、这张图算过期**——所以**别为了"对齐它"去改下面的源（那就反了）**：

## 0. 怎么用（30 秒，决定它不腐烂）

- **它是决策工具，不是日志**：开工前用它「选做什么 / 砍什么」，不是做完用它记账。
- **入场闸**（每件想做的事先过这一问）：
  > 「这件事成功，会改变**哪条赌注**的置信度？用**什么可观察信号**证明？」
  > **答不出 → 现在不做。** 答得出但要硬编理由 → 你只是想做它，诚实承认。
- **PMF 验证前，代码是负债**（每行都增加你将来转向的阻力），经证实的认知才是资产。
- **维护纪律**：每周一次 ~15min，每次必须做一个动作（继续 / 停止 / 合并 / 转向）；旧内容默认删不归档；**当前赌注 ≤3、当前在做 ≤2**；一页放不下 = 已失败。
- **谁拥有**：赌注 / 置信度 / 触发器是**你（PO）的判断**，下面是 Claude 填的草稿，你改。
