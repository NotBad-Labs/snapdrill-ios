# 产品定位与受众（COPPA 受众判定驱动）

> 本文件定义 SnapDrill 的**对外定位**与**目标受众法律属性**，以及由此对各开发线（UI / 营销 / 合规）的**约束**。
> **定位变更需产品负责人（PO）批准**（同 `vision.md` §10 规则）；本文记录的定位由 PO 于 2026-06-11 拍板。
> 三方法律分析（2 份外部 COPPA 报告 + 内部 web 核验）的详细版在 PO 法律工作集；本文是 git-tracked 的可执行摘要，供各 worktree 的 agent 对齐。

---

## 1. 对外定位（PO 2026-06-11 决策）

**SnapDrill = 通用效率工具：扫描、归档、整理任何题目与文档。**

用例不限于儿童作业 —— 试卷、竞赛题、职业证书资料、培训材料、票据等同样适用。一个成年人整理自己的信息技术竞赛题，与一位家长归档孩子的错题，是同一个工具的同一种用法。

### 铁律：定位 ≠ 产品
要变的是**对外定位 / 营销 / UI 观感 / 受众信号**，**不是产品内核**：
- ✅ 产品可继续为"试卷 / 错题 / 学习资料"场景做深度优化 —— 这是产品锐度（PMF），**不影响法律定性**（COPPA 看营销+受众+UI，不看你的功能恰好对作业好用）。
- ✅ 要变的：别让 app 在营销与界面上**看起来是"给儿童自己用的学习 App"**。

**净收益**：拿到 COPPA general-audience（通用受众）抗辩 + 更大 TAM，同时不牺牲"对试卷/错题特别好用"这个杀手锏。

---

## 2. 受众法律属性判定（COPPA）

**判定（校准后）**：SnapDrill = **可辩护的 general-audience（通用受众）目标**，非天然给定，须靠一致执行挣得。

- **最强有利事实（结构性）**：① **无儿童独立登录端**（单一成人/家长操作，儿童无法独立使用）② **零采集已实证**（本地存储、无云同步、无第三方分析、Firebase 已编译剔除、EXIF 剥离）。
- **核心法律原理**：COPPA 只管"从儿童在线收集 PI"；零采集 = 触发点大幅压缩；"从家长收集关于儿童的信息"不当然触发 COPPA。
- **主要不利因子**：subject-matter（孩子作业）—— 靠"通用化定位 + 成人/家长导向营销 UI"压过；**重贴标签消不掉它，须靠一致执行**。
- **内部风险基线**：在执行一致达成前，按"**至少可能落入混合受众**"准备，不预设已是通用受众。
- ⚠️ **终审须执业儿童隐私律师**：directed-to-children 的 totality（整体情况评估法）定性，FTC 不对具体产品预先盖章。

## 3. 对各开发线的约束（guardrail）

### UI（设计权归 Codex + PO；以下是法律/定位约束，非设计稿）
COPPA directed-to-children 会看"视觉/动画角色/儿童化激励/语言"。**承接并强化 `vision.md` §产品定位"不做连续天数/成就弹窗/排行榜"红线**：
- ❌ 卡通形象/吉祥物/宠物养成、游戏化勋章/积分/闯关、**连续签到 streak**、虚拟货币/奖励、童声/儿童配乐、低龄化文案、独立"儿童模式/孩子复习页"（局部儿童化 = Recolor 案陷阱）。
- ✅ 成人生产力工具观感（文件夹/时间轴/标签/检索/对比/笔记）；复盘/复习框成"回顾/查漏/复盘"生产力语言。
- ✅ 不引入"儿童独立账户/登录"概念。

### 营销 / ASO / 官网（合规线 Antigravity 起草，最终 PO 定稿）
- App Store 类目方向：**Productivity / Utilities（不要 Education）**。
- 副标题/描述/关键词：扩到"归档整理**任何**题目与文档"，用例首位放成人/通用例子；**移除 "K-12 / students / 作业神器 / 让孩子…" 作为主叙事**。
- 全球版品牌 **"SnapDrill" 已中性、不改名**；重定位活在描述层。
- 官网文案与"零采集"口径对齐一并处理。

### 合规 / 隐私
- "零采集"是 general-audience 抗辩的硬地基 → **不可破**（加云同步须 E2E、加第三方云 AI 须单独 VPC、加儿童登录即降级混合受众）。
- "零采集"对外宣称前须一次**全量网络流量测试 + SDK 清点**（文案不能代替事实）。

## 4. 会改变判定的触发器（任一发生 = 重审律师）

云同步/备份（须 E2E）· 第三方云 AI 诊断（须单独 VPC）· **儿童登录/儿童模式**（降级混合受众）· 采集传输人脸/声纹（敏感 PI 红线）· "整体成人化 + 局部儿童专区"（Recolor 陷阱）。
