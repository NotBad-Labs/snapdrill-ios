## 2. 愿景与策略

### 2.1 产品愿景
打造一个 **安全、简洁、智能** 的 K12 错题管理与复习工具，让学生在本地优先与隐私可控的前提下获得高效学习体验。

### 2.2 核心原则
1. **学习价值优先**：功能取舍以学习效果与效率为第一准则。
2. **隐私与安全默认开启**：数据留存在用户掌控范围内，本地优先，CloudKit 私有空间同步。
3. **技术前沿但可落地**：优先使用 iOS 26 / Swift 6.2 的现代能力，但每一项指标都需可验证。
4. **免费且无广告**：核心功能永久免费，无任何付费墙或广告干扰。

### 2.3 问题陈述
- 学生：纸质错题本整理耗时、难检索、无法智能复习。
- 家长：缺少非侵入式的学习洞察与辅导建议。
- 教师：难以获得班级层面薄弱点统计与复盘依据。
- 市场：竞品臃肿、社交压力大、隐私保护不足。

## 3. 市场与受众快照

### 3.1 目标用户
| 层级 | 受众 | 核心诉求 |
| :-- | :-- | :-- |
| 一级 | 中国 K12 学生 (重点：初中理科) | 高效录入、智能复习、隐私保护 |
| 二级 | 家长 (vNext) | 周期性报告、尊重隐私的协作 |
| 三级 | 教师 (vNext) | 班级洞察、错题统计、教学优化 |

### 3.2 设备与平台覆盖
- **最低支持**：iOS 26.0，面向 2024Q4 起售的 iPhone 17 系列及更新设备。
- **开发工具链**：Xcode 26.1.1 + Swift 6.2.1（已验证）。
- **适配策略**：首发优化 iPhone 17 Pro / Pro Max，iPadOS 20 版本为 Stretch 目标。

### 3.3 商业与定位
- 定位：**完全免费**的个人作品，使命驱动，不以商业变现考核。
- 社区/协作能力需在保证 COPPA/GDPR 的前提下逐步引入。
- 未来可探索教育机构合作或自愿支持，但不得限制核心功能。

## 5. 功能需求（Function Requirements）

### 5.1 错题录入模块（Capture）
- **范围**：拍照/导入 → OCR → 校对 → 分类 → 保存草稿/提交。
- **关键能力**：
  - 单张 & 批量拍照，自动裁剪 + 手动微调。
  - 基于 Vision 的 OCR，支持中文与基础数学公式；处理耗时 < 2s/张（Baseline）。
  - 草稿箱自动保存，支持离线录入并在联网时同步。
- **用户旅程**：Tab「录入」→ 线性流程，可在校对前中断保存（A-UC-03）。
- **验收**：AC-UC-01/02/03；埋点：E-UC-START, E-UC-COMPLETE。

### 5.2 错题管理模块（Bank）
- **范围**：列表/网格浏览、条件筛选、批量操作、收藏夹。
- **关键能力**：
  - 按学科、难度、掌握度、标签、时间、来源筛选。
  - 搜索响应 < 500ms（Baseline）；批量操作支持撤销（A-BK-02）。
  - 收藏与重点标记，支持离线只读提醒。
- **验收**：AC-BK-01/02；埋点：E-BK-VIEW, E-BK-FILTER。

### 5.3 复习模块（Review）
- **范围**：遗忘曲线计划、卡片流交互、复习提醒、记录回写。
- **关键能力**：
  - 卡片滑动交互：掌握/未掌握/稍后等状态，交互响应 < 100ms。
  - AI/规则结合生成复习队列，与 SwiftData/CloudKit 同步学习记录。
  - 中断恢复：回到上一张卡片；完成后生成总结页。
- **验收**：AC-RR-01/02；埋点：E-RR-START, E-RR-CARD, E-RR-DONE。

### 5.4 分析与报告（Analytics）
- **范围**：趋势、薄弱知识点、AI 建议。
- **关键能力**：
  - 学科/题型/标签维度的掌握度趋势图表。
  - 学习建议生成：设备端模型优先，云端增强需用户授权。
  - 周/月报生成，可导出为 PDF/图像（个人留存）。
- **验收**：AC-AN-01/02；埋点：E-AN-VIEW, E-AN-EXPORT。

### 5.5 发现社区（Discovery，MVP 范围）
- **范围**：匿名错题分享、互助问答、学习打卡，默认 13 岁以下关闭。
- **年龄验证**：
  - 注册时采集出生年月（可选，用于年龄分层）
  - 13 岁以下用户自动禁用社区功能
  - 家长授权流程：发送确认邮件至家长邮箱，点击链接后开启
- **隐私保护**：
  - 内容自动匿名化处理（移除姓名、学校、班级等个人信息）
  - 双层审核：AI 预过滤 + 人工抽检（高风险内容 100% 复审）
  - 分享范围可控：公开/仅好友/仅自己
  - 用户可随时删除自己发布的内容
- **数据权利**：
  - 用户可导出所有社区数据（JSON 格式）
  - 删除账户后 30 天内完全清除数据
  - 符合 COPPA、GDPR、《个人信息保护法》要求
- **验收**：AC-DS-01；埋点：E-DS-OPEN, E-DS-POST。

### 5.6 云同步（Cloud Sync）
- **范围**：CloudKit 私有数据库，多设备同步、冲突解决、备份恢复。
- **关键能力**：
  - 增量同步、重试与冲突合并策略（以时间戳 + 乐观锁）。
  - 手动备份/恢复入口；同步状态提示。
- **验收**：AC-SYS-03；埋点：E-SYNC-START, E-SYNC-FAIL。
