# NotBad PRD 验收标准（Given-When-Then）

**文档版本**: v6.0  
**最后更新**: 2025-09-18  
**关联文档**: [PRD v6.0](./NotBad%20错题本%20App%20-%20产品需求文档%20(PRD)%20v6.0%20(Swift6.2%20+%20iOS26).md)

## 概述

本文档定义了 NotBad 错题本 App 各功能模块的验收标准，采用 Given-When-Then 格式确保需求的可测试性和明确性。

## 核心功能验收标准

### F-UC-01: 拍照录入错题

**Given** 用户已进入错题录入界面  
**When** 用户点击拍照按钮并拍摄包含错题的照片  
**Then** 系统应在 P95 < 2.5s 内完成 OCR 识别，中文识别准确率 P95 > 90%，并显示可编辑的识别结果

**Given** OCR 识别置信度低于阈值  
**When** 系统检测到低置信度区域  
**Then** 系统应高亮显示低置信度区域，并提供手动编辑功能

### F-UC-02: 错题分类管理

**Given** 用户已录入多个错题  
**When** 用户对错题进行分类操作  
**Then** 系统应支持按学科、难度、掌握度等维度进行分类，并保持分类的持久性

### F-RR-01: 智能复习计划

**Given** 用户已录入错题且开启复习提醒  
**When** 系统基于遗忘曲线算法计算复习时机  
**Then** 系统应基于在端预测 + 通知调度策略推送复习提醒（不保证系统建议的确定性触达）

### F-SYS-02: 本地数据存储

**Given** 用户进行任何数据操作  
**When** 应用意外退出或重启  
**Then** 所有已保存的数据应完整保留，数据完整性 99.9%

## 性能验收标准

### NFR-PERF-01: 应用启动性能

**Given** 应用处于完全关闭状态  
**When** 用户点击应用图标启动应用  
**Then** 冷启动时间 P95 < 1.2s（基准设备: iPhone 12 / iPhone SE (2022) / current flagship）

### NFR-PERF-02: 内存使用

**Given** 应用正常运行  
**When** 用户进行常规操作（非 OCR）  
**Then** 内存使用 P95 < 60MB

**Given** 应用执行 OCR 处理  
**When** 处理单张图片  
**Then** OCR 峰值内存使用 P95 < 300MB

### NFR-PERF-03: 滚动性能

**Given** 用户在错题列表界面  
**When** 用户进行滚动操作  
**Then** 滚动丢帧率 P95 < 1%

## 安全与隐私验收标准

### NFR-SEC-01: 数据保护

**Given** 应用存储用户数据  
**When** 数据存储到本地  
**Then** 敏感数据应使用 AES-256 加密，启用 NSFileProtectionComplete

**Given** 应用需要存储密钥  
**When** 密钥生成或存储  
**Then** 本地密钥必须使用 Keychain 存储

### NFR-SEC-02: 隐私合规

**Given** 应用处理未成年人数据  
**When** 数据收集和处理  
**Then** 未成年人数据应默认进入匿名桶处理

**Given** 应用需要第三方服务  
**When** 集成外部 SDK  
**Then** 不得集成第三方广告/追踪 SDK

## 云同步验收标准

### F-SYS-03: CloudKit 同步

**Given** 用户已登录 Apple ID 且开启 iCloud  
**When** 用户在多设备间操作同一数据  
**Then** 仅支持同一 Apple ID 下的多设备同步，不包含跨账号分享

**Given** 网络连接正常  
**When** 数据同步操作执行  
**Then** 同步操作应在 5 秒内完成

## AR 功能验收标准（vNext 实验性）

### F-UC-03: AR 沉浸式录入

**Given** 设备支持 ARKit 9.0  
**When** 用户启用 AR 录入模式  
**Then** AR 渲染帧率 P95 ≥ 60fps

**Given** 设备不支持 ARKit  
**When** 用户尝试访问 AR 功能  
**Then** 系统应优雅降级到常规录入模式

## 无障碍验收标准

### NFR-A11Y-01: VoiceOver 支持

**Given** 用户开启 VoiceOver  
**When** 用户使用应用核心功能  
**Then** 100% 支持 VoiceOver 屏幕阅读器

### NFR-A11Y-02: 动态字体支持

**Given** 用户调整系统字体大小  
**When** 用户使用应用  
**Then** 应用应支持 iOS 动态字体调节

## 验收流程

1. **开发完成**: 功能开发完成并通过单元测试
2. **自测验证**: 开发团队按照验收标准自测
3. **QA 测试**: QA 团队执行完整的验收测试用例
4. **产品验收**: 产品团队确认功能符合验收标准
5. **发布准备**: 通过所有验收标准后方可进入发布流程

## 质量门禁

- 所有 Must Have 功能必须 100% 通过验收标准
- Should Have 功能至少 90% 通过验收标准
- 性能指标必须在 P95 要求范围内
- 安全与隐私要求必须 100% 合规
- 无障碍功能必须 100% 支持 VoiceOver

---

**注意**: 本文档中的验收标准为最终发布的最低要求，实际实现应力求超越这些标准。
