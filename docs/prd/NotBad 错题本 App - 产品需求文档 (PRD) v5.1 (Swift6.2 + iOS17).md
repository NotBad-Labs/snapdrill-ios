## 2. 项目概述

### 2.1. 产品简介

NotBad是一款专为K-12学生设计的智能错题管理应用。它通过OCR技术、智能分类和个性化复习计划，帮助学生高效地整理和学习错题，从而巩固知识、提升学业成绩。

### 2.2. 项目目标

- **核心目标**: 打造一款用户体验一流、功能强大的错题管理工具，成为学生日常学习的得力助手。
- **技术目标**:
  - **目标平台**: iOS 17.0+
  - **开发语言**: Swift 6.2
  - **核心框架**: SwiftUI, Vision, CoreML, ARKit, CloudKit
  - **开发工具**: Xcode 16.2, TestFlight, GitHub Actions
  - **基础设施**: 自托管macOS Runner, Synology NAS (用于CI/CD存储)

## 3. 范围与优先级

### 3.1. 功能范围

#### 3.1.1. MVP (最小可行产品) 核心功能

- **错题拍摄与导入**: 支持高清晰度图片和视频录制，便于清晰呈现错题细节。
- **OCR识别与录入**: 自动从图片中提取题目和答案文本。
- **错题分类**: 自动或手动将错题归类至相应知识点，便于系统化复习。
- **错题解析**: 提供详细的错题解析，包括知识点讲解、类似例题和解题思路。
- **错题收藏与复习**: 允许用户标记和收藏重要错题，方便后续复习。
- **学习进度追踪**: 实时追踪用户的学习进度，并提供阶段性报告。
- **个性化推荐**: 根据用户的学习情况，智能推荐复习资料和习题。
- **数据同步**: 通过CloudKit在用户自己的多台Apple设备间同步数据。

#### 3.1.2. vNext (未来版本) 规划功能

- **空间计算 (Spatial Computing)**: 利用ARKit实现错题的3D可视化和交互。用户可以将错题模型放置在真实环境中，从不同角度观察和学习。
- **智能分析报告**: 基于学生的学习数据，生成个性化的学习建议和进度报告。
- **家长/教师账户 (vNext)**: 允许家长或教师查看学生的学习进度，并进行辅导。
- **多平台支持 (vNext)**: 将应用扩展到iPadOS和macOS平台。

### 3.2. 优先级 (MoSCoW)

- **Must Have**: MVP核心功能列表中的所有项目。
- **Should Have**: 优化OCR识别速度和准确率，增强搜索功能。
- **Could Have**: vNext规划中的功能，如AR、高级报告等。
- **Won't Have (This Time)**: 社交分享功能、实时协作、第三方登录。

### 4.2. 非功能性需求

#### 4.2.1. 性能与稳定性

| 类别      | 指标                                                                                                                            | 备注                                                                 |
| :-------- | :------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------- |
| 性能      | - **应用启动时间 (冷启动)**: < 1.5秒 <br>- **内存占用 (平均)**: < 250MB <br>- **UI响应时间**: 所有核心交互在 < 100ms 内完成 | 遵循 [附录C: 指标对齐](../appendices/METRICS_ALIGNMENT.md) 中定义的测量方法。 |
| 稳定性    | - **崩溃率**: < 0.1% (千分之一) <br>- **ANR率 (应用无响应)**: < 0.05%                                                           | 通过Firebase Crashlytics和Xcode Metrics进行监控。                       |
| 兼容性    | 在iOS 17.0及以上版本的所有设备上无重大功能或UI问题。                                                                            | 遵循 [附录D: 平台降级矩阵](../appendices/PLATFORM_DEGRADATION_MATRIX.md)。 |
| 功耗      | 在典型使用场景下，应用不应导致设备异常发热或电量快速消耗。                                                                        | 通过Xcode Energy Organizer进行分析。                                 |
| OCR准确率 | 对于印刷体文字，识别准确率 > 98%；对于清晰的手写体，准确率 > 92%。                                                              | 使用标准化的测试图像集进行验证。                                     |

#### 4.2.2. 其他非功能需求

- **安全性**: 确保用户数据的安全存储与传输，所有数据存储在用户的私有CloudKit数据库中，符合Apple的隐私指南。
- **可用性**: 应用应具备高可用性，遵循Apple HIG（人机界面指南），确保直观易用。
- **可维护性**: 代码应遵循清晰的结构和注释规范，便于后续维护和功能扩展。
- **可测试性**: 提供完整的单元测试和UI测试用例，确保关键功能的稳定性。
