  1) 变更首先在PRD提出与评审（范围/指标/NFR）。

## **1\. 项目概述 (Project Overview)**

### **1.1 产品愿景 (Product Vision)**

打造一个**安全、简洁、智能**的K12学习复习应用，通过Swift 6.2最新技术赋能，帮助学生科学高效地管理和复习错题，最终形成自主、高效、完整的学习闭环。

### **1.2 问题陈述 (Problem Statement)**

* **学生痛点**: 传统纸质错题本整理繁琐、检索困难、易于丢失，且无法提供基于遗忘曲线的科学复习规划，导致"无效整理"和"低效复习"。
* **家长痛点**: 难以客观、无侵入性地了解孩子的学习薄弱点，无法提供精准有效的辅导，常常陷入"管太多"或"管不了"的焦虑。
* **市场问题**: 现有应用普遍功能臃肿、广告干扰严重、过度社交化，或将用户数据作为商业变现的资源，缺乏一个真正以"学习效率"和"隐私安全"为核心的纯粹工具。
* **教师痛点**: 缺乏高效工具了解学生错题分布和学习进度，难以进行班级层面的分析与针对性辅导。

### **1.3 技术约束与要求 (Technical Constraints & Requirements)**

#### **1.3.1 平台要求 (Swift 6.2 & iOS 26 升级)**
- **最低支持**: iOS 26.0+ (全面拥抱最新系统特性)
- **开发环境**: Xcode 26+, **Swift 6.2** 🆕
- **并发模型**: **Enhanced Actor Isolation** + **Improved TaskGroup** 🚀
- **UI框架**: SwiftUI (充分利用iOS 26新组件和Proactive Intelligence)
- **架构模式**: Clean Architecture + **Swift 6.2 Enhanced Concurrency**
- **空间计算**: 适配 visionOS 3.0, 引入AR/VR学习场景  espacial 🆕

#### **1.3.2 性能要求 (基于Swift 6.2 & iOS 26优化) 🚀**
- **应用启动**: < **1.0秒** (iOS 26 App Resume + Swift 6.2并发优化，性能提升40%+)
- **响应时间**: < **0.5秒** (Proactive Intelligence 预测性加载 + Enhanced Actor)
- **内存使用**: < **50MB** (iOS 26 智能内存管理 + Swift 6.2 ARC优化)
- **并发安全**: **100%编译时保证** + Enhanced Sendable Checking
- **滚动流畅度**: > **120fps** (iOS 26 ProMotion + Swift 6.2性能优化)
- **编译时间**: **减少40%** (Swift 6.2编译器优化)
- **AR渲染帧率**: > **90fps** (ARKit 9.0 优化) 🆕

#### **1.3.3 Swift 6.2 & iOS 26 新特性利用 🆕**
- **Proactive Intelligence**: 预测用户意图，智能预加载复习内容，优化提醒时机。
- **Enhanced Pattern Matching**: 复杂数据筛选和分类，提升AI分析准确率。
- **空间计算 & ARKit 9.0**: 引入AR错题录入、3D知识图谱可视化、沉浸式复习场景。
- **Improved Error Handling**: 更优雅的错误处理机制，提升应用稳定性。
- **Enhanced Collections**: 高性能数据操作，加速搜索和统计。
- **App Intents 2.0**: 更强大的Siri集成和自动化工作流。

### **1.4 核心价值主张 (Core Value Propositions)**

#### **1.4.1 学生价值 (iOS 26 赋能) 🚀**
* **AR沉浸式录入**: 通过ARKit 9.0，将错题拖拽到虚拟空间中，实现空间化整理。
* **Proactive智能复习**: iOS 26 Proactive Intelligence预测最佳复习时机，在锁屏界面智能推送。
* **3D知识图谱**: 将薄弱知识点以3D形式可视化，直观展示关联性。
* **安全与隐私增强**: 利用iOS 26新的隐私特性，提供更强的本地数据保护。

#### **1.4.2 家长价值**
* **透明监督**: 基于授权的学习进度可视化，无需"偷看"。
* **科学指导**: 客观数据支撑的辅导建议，避免盲目督促。
* **隐私尊重**: 孩子主动分享，建立信任而非监控关系。

#### **1.4.3 教师价值 (新增)**
* **班级洞察**: 匿名统计学生薄弱点分布，优化教学重点。
* **作业管理**: 数字化作业分发与完成度跟踪。
* **个性辅导**: 基于数据的学生个体化指导建议。

* **隐私优先**: 本地优先架构，明确的数据控制权
* **纯净体验**: 无广告，无社交压力，专注学习

* **科学方法**: 基于认知科学的复习算法

## **3\. 用户画像与需求分析 (User Personas & Requirements)**

### **3.1 用户场景 (User Scenarios)**

> 本章节取代传统用户画像，通过场景化叙事定义核心需求，使团队更好地共情用户。

#### **3.1.1 场景一：考后错题整理 (学生)**

*   **用户**: 小明，初二学生
*   **背景**: 数学月考刚结束，小明拿着满是红叉的试卷，心情有点沮丧。他想把错题整理下来，但一想到要抄半天题、画图，就觉得很烦。
*   **核心期望 (Job to be Done)**: "我希望能有一种方法，**拿出手机对着试卷拍一下，所有错题就自动、清晰地存进App里**，并且App能告诉他这些题分别考的是哪个知识点。这样他就能马上开始复习，而不是把时间浪费在抄写上。"
*   **关联需求**: `F-UC-01` (拍照创建), `F-AI-02` (知识点识别)

#### **3.1.2 场景二：睡前高效复习 (学生)**

*   **用户**: 小明，初二学生
*   **背景**: 晚上10点，小明准备睡觉前进行今日错题复习。他不想再翻看厚重的错题本，希望能有更轻松、专注的复习方式。
*   **核心期望 (Job to be Done)**: "我希望App能像单词卡片一样，**自动把今天的错题推送给我**。我只需要在床上滑动卡片，就能快速回顾。对于掌握的题，向右滑过；没掌握的，向左滑重点标记，明天再练。"
*   **关联需求**: `F-RR-01` (卡片式复习), `F-AI-01` (智能复习计划)

#### **3.1.3 场景三：了解学习状况 (家长)**

*   **用户**: 李妈妈，小明的妈妈
*   **背景**: 李妈妈工作很忙，但非常关心小明的学习。她不想通过翻看作业本或频繁追问来给孩子压力，但又迫切想知道“他到底哪里没学会？”
*   **核心期望 (Job to be Done)**: "我希望能**每周收到一份简单清晰的学习报告**，告诉我小明最近在哪些知识点上反复出错。如果能给出一些具体的辅导建议，比如‘可以看看这个知识点的讲解视频’，那就更好了。我希望这一切都在尊重孩子隐私的前提下进行。"
*   **关联需求**: `F-PG-01` (家长报告), `F-PG-02` (隐私授权)

#### **3.1.4 场景四：班级教学提效 (教师)**

*   **用户**: 张老师，初中数学老师
*   **背景**: 张老师希望提高教学的针对性。他发现班里总有几个知识点，每次考试都有接近一半的学生出错。
*   **核心期望 (Job to be Done)**: "如果我能**匿名地看到班级学生的高频错题和薄弱知识点统计**，我就可以在课堂上重点讲解，或者设计针对性的练习题。这比我一道道题去统计要高效得多。"
*   **关联需求**: `F-TE-01` (班级学情分析)

## **4\. 产品功能需求 (Product Functional Requirements)**

### **4.1 核心功能模块 (Core Function Modules)**

#### **4.1.1 错题录入模块 (Capture Module)**

**功能描述**: 通过拍照和OCR技术快速录入错题信息

**主要功能**:
* 📷 **拍照录入**: 支持单张/批量拍照，自动裁剪和增强
* 🔤 **OCR识别**: 基于Vision框架的文字识别，支持数学公式
* ✏️ **手动编辑**: OCR结果可编辑，支持富文本格式
* 🏷️ **智能分类**: AI自动识别学科和知识点
* 📁 **批量处理**: 支持批量导入和处理

**技术要求**:
* OCR准确率 > 95%（中文）, > 90%（数学公式）
* 单张照片处理时间 < 2秒
* 支持图片格式：JPEG, PNG, HEIC
* 最大图片尺寸：10MB

#### **4.1.2 错题管理模块 (Management Module)**

**功能描述**: 对录入的错题进行分类、搜索和管理

**主要功能**:
* 📊 **分类体系**: 按学科、难度、掌握度分类
* 🔍 **搜索功能**: 支持关键词、标签、时间范围搜索
* 🏷️ **标签系统**: 自定义标签，支持多标签
* 📈 **统计分析**: 错题数量、掌握度分布统计
* 🗂️ **收藏夹**: 重要错题收藏和快速访问

#### **4.1.3 复习模块 (Review Module)**

**功能描述**: 基于遗忘曲线的智能复习系统

**主要功能**:
* 🧠 **智能算法**: 基于艾宾浩斯遗忘曲线的复习时机
* ⏰ **复习提醒**: 个性化的复习通知和计划
* 📝 **重做功能**: 生成空白模板，验证掌握程度
* 📊 **进度跟踪**: 复习次数、正确率统计
* 🎯 **自适应调整**: 根据表现调整复习频率

#### **4.1.4 分析报告模块 (Analytics Module)**

**功能描述**: 基于学习数据的智能分析和建议

**主要功能**:
* 📈 **学习趋势**: 错题数量、掌握度变化趋势
* 🎯 **薄弱分析**: 识别薄弱知识点和题型
* 💡 **改进建议**: AI生成的个性化学习建议
* 📊 **对比分析**: 与同年级平均水平对比
* 📅 **学习报告**: 周报、月报生成和分享

### **4.2 高级功能模块 (Advanced Function Modules)**

#### **4.2.1 家长协作模块 (Parent Collaboration)**

**功能描述**: 家长参与孩子学习过程的协作功能

**主要功能**:
* 🔐 **授权访问**: 学生主动授权家长查看学习数据
* 📱 **进度分享**: 定期分享学习进度和成就
* 💬 **沟通工具**: 家长与学生的学习讨论
* 📊 **家长报告**: 专门为家长设计的简化报告
* 🔒 **隐私控制**: 细粒度的隐私设置和访问控制

#### **4.2.2 教师管理模块 (Teacher Management) 🆕**

**功能描述**: 教师管理班级和了解学生学习情况

**主要功能**:
* 👥 **班级管理**: 创建班级，生成邀请码
* 📚 **作业分发**: 数字化作业布置和收集
* 📊 **班级统计**: 匿名化的班级学习数据分析
* 🎯 **个性指导**: 基于数据的学生辅导建议
* 📈 **教学优化**: 基于班级数据的教学内容调整建议

#### **4.2.3 云同步模块 (Cloud Sync)**

**功能描述**: 跨设备的数据同步和备份

**主要功能**:
* ☁️ **iCloud同步**: 基于CloudKit的基础同步（免费）
* 📱 **多设备支持**: iPhone, iPad同步
* 🔄 **增量同步**: 只同步变更部分，节省流量
* 📦 **数据备份**: 自动备份到iCloud
* 🔀 **冲突解决**: 智能处理数据冲突

## **7\. 数据需求 (Data Requirements)**

### **7.1 数据模型 (Data Model)**

#### **7.1.1 核心数据实体 (Core Data Entities)**

**错题实体 (ReviewItem)**:
```
- id: UUID (主键)
- content: ReviewContent (题目内容)
- metadata: ReviewItemMetadata (元数据)
- studyHistory: [StudyRecord] (学习记录)
- masteryLevel: MasteryLevel (掌握程度)
- createdAt: Date (创建时间)
- updatedAt: Date (更新时间)
```

**学习记录 (StudyRecord)**:
```
- id: UUID (主键)
- reviewItemId: UUID (关联错题)

- startTime: Date (开始时间)
- endTime: Date (结束时间)
- result: StudyResult (学习结果)
- difficulty: DifficultyLevel (难度评分)
```

**用户配置 (UserProfile)**:
```
- id: UUID (主键)
- nickname: String (昵称)
- grade: Grade (年级)
- subjects: [Subject] (学科偏好)
- preferences: UserPreferences (个人偏好)

```
