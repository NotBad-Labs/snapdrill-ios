本目录用于存放项目各类会议的纪要。

**命名规范**: `YYYY-MM-DD - 会议主题.md`

**示例**:

- `2025-09-11 - v4.1 需求评审会.md`
- `2025-09-15 - OCR 优化技术方案研讨会.md`

**纪要模板**:

```markdown
# YYYY-MM-DD - 会议主题

- **日期**: 
- **参会人**: 
- **主持人**: 

## 议题
1. ...
2. ...

## 结论
- **决策1**: ... (负责人: XXX, 截止日期: YYYY-MM-DD)
- **决策2**: ...

## 行动项 (Action Items)
- [ ] AI-1: ... (负责人: XXX)
- [ ] AI-2: ... (负责人: XXX)

## 讨论过程
...
```
