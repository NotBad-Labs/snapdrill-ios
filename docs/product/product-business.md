## 商业化铁律

**绝不限制录入数量。**

这是竞品最令人反感的做法（"每天免费 10 道"），也是 SnapDrill 的核心差异化。
录入是生命线，限制录入 = 扼杀产品价值。

## 付费模式（Freemium + 订阅，Bear 模式，2026-03-07 确立）

**定价模式**：参照 Bear（$2.99/月 或 $29.99/年），SnapDrill Pro 为打包订阅。
iCloud 同步与其他增值功能打包，不单独售卖同步——避免 App Store 审核指引 3.2.2 风险。
Bear / Day One / Ulysses 等 iOS 独立 App 已验证此模式多年，Apple 审核无问题。

| 免费（永久） | SnapDrill Pro（订阅） |
|---|---|
| 无限录入（拍照、导入、文档扫描、PDF、手动） | iCloud 多设备实时同步（CloudKit） |
| OCR 文字识别（Apple Vision 原生） | 多 Profile 数据同步 |
| 分类管理、搜索、过滤、批量操作 | 智能复习卷生成（SM-2 驱动选题 → 打印） |
| PDF 导出（含去答案打印、留白答题区、页眉页码） | 高级导出格式（Word） |
| 基础间隔重复复习 | 高级统计 + 趋势图 |
| 本地数据存储 + 1 个 Profile | 高级识别（数理化公式等，待评估） |
| 手动备份 / 恢复（`.snapdrill` 文件） | AI 解题提示（未来） |

**免费版体验完整性保障**：
- 单设备无限录题 + 无广告 + 纯本地 = 完整可用的产品
- `.snapdrill` 手动备份/恢复 = 免费用户换手机不丢数据，也是抵御"绑架数据"指控的盾牌
- 付费解锁的是「增值体验」（多设备流转、高级导出），不是「基础能力」

**数据迁移方案**：
- 免费用户：手动导出 / 导入 `.snapdrill` 备份文件
- Pro 用户：iCloud CloudKit 自动同步，换机后数据自动回来

**核心付费场景**：家长"妈妈手机随时拍 + 孩子 iPad 随时练 + 打印机随时印"的闭环工作流，
iCloud 同步是打通这个闭环的引擎，组卷排版是配套杀招。

### 定价策略（2026-04-01 确立，横向研究 Infuse / Bear / Craft 后决策）

**v1.0 全免费发布**——先积累口碑和用户基数，不上订阅。

**v1.x 引入 Pro 订阅**——iCloud 同步为核心付费点，附带高级导出等增值功能。

**分市场定价**（Apple 允许每个 Storefront 独立设定订阅价格）：

| 层级 | 中国区（CNY） | 美国区（USD） | 说明 |
|---|---|---|---|
| **Pro 月订阅** | ¥8/月 | $1.99/月 | 起步低价获客 |
| **Pro 年订阅** | ¥68/年 | $19.99/年 | 年费优惠约 30% |
| **Lifetime 买断** | ¥298 | $49.99 | 为不喜欢订阅的用户提供选择 |

**14 天 Free Trial**——让用户先体验 iCloud 同步的便利再决定是否付费（Bear 的做法）。

**Grandfather 涨价策略**（Bear 模式）：
- 老用户永远保持注册时的价格，涨价只影响新用户
- 用户量增长验证后，新用户涨到 ¥12/月 / $2.99/月
- 老用户只要不中断订阅，永远保持 ¥8/月 / $1.99/月
- Apple StoreKit 原生支持此模式——续期按原价扣，新订阅按新价

**汇率说明**：¥8 CNY ≈ $1.10 USD，与 Apple 均衡化体系中 ¥6 → $0.99 的映射一致。
不建议中美同价（¥9.9/月 vs $9.9/月），汇率差 7 倍会导致定价失衡。

**定价原则**：
- 首发全功能免费（积累用户和口碑）
- 付费功能必须是"增值"而非"解锁基础能力"
- 价格定位：用户群体（家长 + 学生）可承受（对标 Bear $2.99/月 的工具 App 价位）
- 不做去水印——产品本身不应该有水印，这不是尊重用户的做法
- 保留 Lifetime 选项——参考 Infuse（$94.99 起），为一次性付费用户提供选择

**竞品定价参考**（2026-04-01 调研）：

| App | 月费 | 年费 | Lifetime | 模式 |
|---|---|---|---|---|
| **Infuse** | $0.99 | $9.99 | $94.99 | 免费够用，Pro 加码 |
| **Bear** | $2.99 | $29.99 | 无 | 免费单设备，Pro 同步+导出 |
| **Craft** | ~$8 | ~$96 | 无 | 免费有上限，Plus 无限 |
| **SnapDrill** | ¥8/$1.99 | ¥68/$19.99 | ¥298/$49.99 | 免费完整，Pro 同步+增值 |

## 隐私策略（2026-03-07 确立，Bear 模式）

SnapDrill **不收集任何可识别个人信息**（no personally identifiable information）。没有注册，没有手机号，没有学校年级。
匿名使用数据（Firebase Analytics / Crashlytics）默认开启，用户可在设置中关闭。

| 维度 | 竞品（喵喵机/橙果等） | SnapDrill |
|---|---|---|
| 注册 | 手机号必须 | 无注册 |
| 数据收集 | 姓名、学校、年级、位置 | 零可识别个人信息（仅匿名 Analytics，可关闭） |
| 存储 | 自建云端 | 纯本地 + iCloud（Apple 负责） |
| 合规负担 | 极重（ICP+等保+审计+儿童隐私） | 极轻（App 备案 + Apple 审核即可，不触碰用户数据 = 无等保/审计负担） |

**为什么这是杀手级差异化**：
- 2025 年中国四部门联合专项行动，3852 款 App 被通报侵害用户权益（同比增 152%）
- 教育类 App 是重点监管对象——收集儿童个人信息属于敏感信息处理
- 家长最怕孩子的学习数据被平台收集利用
- SnapDrill 不触碰用户数据 = 零监管风险 + 家长信任

**技术实现**：参照 Bear（意大利独立工作室 Shiny Frog 开发）的模式——
- 同步基于 Apple CloudKit，利用设备已有的 Apple ID 凭证，无需单独注册
- 中国区 iCloud 由云上贵州运营，数据存储在中国境内，**合规责任在 Apple 侧**。中国大陆 iCloud 同步体验可能与其他市场有差异，v1.5 实现时做针对性测试
- 开启 Apple Advanced Data Protection 后，CloudKit 数据端到端加密，只有用户能解密

**用户须知（必须在产品中醒目提示）**：
- 免费版纯本地存储，**卸载 App = 数据永久丢失**——需在设置中和卸载前明确提醒
- 建议定期手动备份（`.snapdrill` 文件），或升级 Pro 启用 iCloud 自动同步

### App Store 年龄分级策略（2026-03-23 确立）

**年龄分级**：**4+**（Unrestricted）。SnapDrill 无不当内容、无社交功能、无 App 内购买诱导、无第三方广告。

**Kids Category 决策**：**不申请**。理由：
- Kids Category 限制较多（禁止外部链接、禁止第三方 SDK 向儿童发送数据等）
- SnapDrill 使用第三方分析和崩溃报告 SDK，虽然不收集个人信息，但技术上属于第三方 SDK
- SnapDrill 的主操作者是家长（非儿童直接使用），定位为「家庭场景的效率工具」而非「儿童 App」
- 4+ 年龄分级已足以覆盖目标用户群

**Declared Age Range API**（iOS 26+）：v1.5 评估是否集成。该 API 允许 App **请求用户分享其年龄范围**（由系统从 Apple Account 获取，需家长同意），App 据此提供年龄适宜的体验。注意：这不是 App 声明自己的目标年龄段，而是 App 向系统请求用户的年龄信息。SwiftUI 用法：`@Environment(\.requestAgeRange)`；UIKit 用法：`AgeRangeService.requestAgeRange(ageGates:_:_:in:)`，支持最多 3 个 age gate 阈值。SnapDrill 的目标用户横跨多个年龄段（家长 + 6-18 岁学生），需评估是否及如何使用。美国多州（Utah、Louisiana、Texas）已立法要求年龄核实，v1.5 时需关注合规要求。

**COPPA / 儿童隐私合规姿态**（2026-03-30 更新）：

SnapDrill 的产品定位是**效率工具**（utility tool），不是教育工具（educational tool）：
- 不提供任何教育内容（无课本、无试卷、无题库）
- 所有内容由用户自主拍摄和录入
- 本质是"拍照 → 整理 → 复习"的数字化归档工具
- 类比：Scanner Pro、备忘录 — 学生也用，但不是"面向儿童的 App"

FTC 判定 COPPA "directed to children" 的核心标准与 SnapDrill 的对照：
1. **视觉设计和语气** — 成熟、家长友好基线，非幼稚卡通风格
2. **是否提供面向儿童的内容** — 不提供任何内容，所有数据来自用户
3. **营销对象** — 面向家长和学生，非专门面向 <13 岁儿童
4. **App Store 分类** — 未进入 Kids Category

虽然用户群包含 12-13 岁初中生，但效率工具定位与 "directed to children" 有本质区别。

**当前合规措施**：
- 零注册、零可识别个人信息收集
- Firebase Analytics/Crashlytics 匿名数据收集默认开启，用户可在设置中关闭
- ATT 预询问流程提供知情选择
- Privacy Manifest 声明数据不关联、不追踪

**App Store 营销注意事项**：避免使用 "children""kids""儿童教育" 等触发 FTC/Apple 审查的措辞，强调"效率工具""数字化归档""家长和学生"。

**v1.5 评估**：如 App Store 审核或法律咨询认为需更严格合规，再考虑 Declared Age Range API 集成或 Analytics 默认关闭。美国多州（Utah、Louisiana、Texas）已立法要求年龄核实，v1.5 时持续关注。

## 竞品分析（2026-03-07 行业调研）

### 行业格局

错题本 App 市场已形成三个梯队：

| 梯队 | 代表产品 | 特点 |
|---|---|---|
| 巨头附属 | 喵喵机（作业帮）、小猿口算（猿辅导）、快对 | 背靠亿级题库，免费引流卖硬件/课程 |
| 垂直工具 | 蜜蜂试卷、试卷宝、A+错题本、橙果错题本 | 以去手写/试卷还原为核心卖点，订阅制 |
| 独立小众 | 刺猬错题本、纠错大师、错题plus | 功能轻量，用户量小 |

### 竞品致命缺陷（用户真实痛点，来自知乎测评）

1. **录入界面拥挤** — 一屏塞满字段，容易误操作（SnapDrill 对策：默认仅开启学科）
2. **付费限制录入** — 橙果免费 50 题后收费，部分 App 每天 10 题（SnapDrill 对策：永不限制）
3. **注册流程繁琐** — 要求手机号+学校+年级+位置权限（SnapDrill 对策：零注册）
4. **OCR 不准 + 强制校对** — 用户被迫修正识别错误（SnapDrill 对策：展示但不强迫校对）
5. **打印要会员** — 基础功能付费化（SnapDrill 对策：基础 PDF 导出免费）

### SnapDrill 的差异化定位

| 维度 | 喵喵机（最大竞品） | SnapDrill |
|---|---|---|
| 定位 | 搜题+练题+打印 | 存档+管理 |
| 商业模式 | App 免费 + 卖打印机硬件 | App 免费 + 订阅增值 |
| 数据 | 云端存储，收集用户信息 | 纯本地 + iCloud |
| 注册 | 手机号必须 | 无注册 |
| 平台 | Android 优先，iOS 体验一般 | iOS 原生精品 |
| 题库 | 2.5 亿题库（作业帮） | 无题库（我们是工具不是内容） |
| 技术 | 第三方 OCR + 云端匹配 | Apple Vision 原生端上识别 |

### 与 Anki 的本质区别（2026-03-23 从 product-vision.md 迁入）

Anki 是"记忆工具"——用户为了记住知识而制卡。
SnapDrill 是"存档工具"——用户为了留存有价值的题目而录入，复习只是附带福利。

很多目标用户（中小学生及家长）**根本不知道 Anki 的存在**——这本身就是机会。
