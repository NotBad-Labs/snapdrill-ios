## 商业化铁律

**绝不限制录入数量。**

竞品普遍采用限制免费录入数量的模式（如"每天免费 10 道"），用户反馈负面。不限制录入是 SnapDrill 的核心差异化。
录入是生命线，限制录入等于削弱产品核心价值。

## 付费模式（Freemium + 订阅，Bear 模式，2026-03-07 确立）

**定价模式**：参照 Bear（$2.99/月 或 $29.99/年），SnapDrill Pro 为打包订阅。
iCloud 同步与其他增值功能打包，不单独售卖同步——避免 App Store 审核指引 3.2.2 风险。
Bear / Day One / Ulysses 等 iOS 独立 App 已验证此模式多年，Apple 审核无问题。

| 免费（永久） | SnapDrill Pro（订阅） |
|---|---|
| 完整单设备闭环（采集→管理→导出/打印） | iCloud 多设备实时同步（核心卖点） |
| 间隔重复复习 + Multi-Profile | 图片处理增强：去手写/去批改痕迹/试卷还原（免费限次体验） |
| 手动备份/恢复 | 智能复习卷生成（SM-2 组卷打印） |
| — | Word 导出 |
| — | 高级统计 + 趋势图 |

免费层包含 MoSCoW Must + Should 全部功能，Pro 层包含 Could 中的增值项。完整功能清单见 `product-requirements.md`§功能全景。
探索性商业化方向见 `product-requirements.md`§待评估。

**分层原则**（2026-04-01 讨论确立）：
- 免费层 = 完整的单设备产品体验（价值链闭环：采集 → 管理 → 导出/打印，另含独立附加值：复习）
- Multi-Profile 是基础可用性（多孩家庭），不是增值体验，放免费层
- 付费层 = 跨设备流转 + 智能增强 + 图片处理增强，核心卖点是 iCloud 同步
- 图片处理增强（去手写/去批改痕迹/试卷还原）采用"免费限次体验 + Pro 无限使用"策略，让用户先感受价值再转化（蜜蜂试卷/橙果/试卷宝均验证此模式）
- 智能复习卷（SM-2 选题打印）需要用户先完成"导出 → 练习 → 标定错误"的闭环，是进阶能力
- 高级统计是锦上添花，不是付费主力

**免费层完整定义**：

| 环节 | 免费层能力 | 边界说明 |
|---|---|---|
| 采集 | Camera / Photos / Document Scan / PDF / Manual 全入口可用；无限录题；OCR 展示、复制、手动修正可用 | 不限制录入数量，不做"每日 N 题" |
| 管理 | 搜索、学科/标签/难度过滤、排序、编辑、批量打标签、批量删除、Multi-Profile | 单设备内题库完整可管理，多孩家庭可直接使用 |
| 导出 | PDF、PDF 增强（去答案打印/留白/页眉页码）、单题快速打印、JSON、CSV、`.snapdrill` 手动备份/恢复 | 导出/打印是基础能力，不作为订阅门槛。注意：基础"去答案打印"（隐藏答案字段）是免费功能，与 Pro 的"图片处理增强"（AI 去手写/去批改痕迹）是不同层面 |
| 复习 | 基础 SM-2 间隔重复复习、Dashboard 待复习入口、复习卡片外观设置 | 复习是免费附加值，不做强制付费墙 |
| 数据管理 | 纯本地存储、卸载提醒、媒体缓存清理、换机靠手动备份恢复 | 免费层不含 iCloud 自动同步，但必须可迁移 |

**免费版体验完整性保障**：
- 单设备无限录题 + 无广告 + 纯本地 = 完整可用的产品
- `.snapdrill` 手动备份/恢复 = 免费用户换手机不丢数据，确保用户数据可携带、不被平台锁定。此承诺建立在备份格式持续向后兼容之上（见 `product-design.md`§备份与恢复设计 + `product-requirements.md`§备份与恢复）
- 付费解锁的是「增值体验」（多设备流转、图片处理增强、高级导出），不是「基础能力」

**数据迁移方案**：
- 免费用户：手动导出 / 导入 `.snapdrill` 备份文件
- Pro 用户：iCloud CloudKit 自动同步，换机后数据自动回来

**核心付费场景**：家长"妈妈手机随时拍 + 孩子 iPad 随时练 + 打印机随时印"的闭环工作流，
iCloud 同步是打通这个闭环的引擎，图片处理增强（去手写/试卷还原）和组卷排版是核心增值能力。

**订阅取消后数据降级策略（待定）**：
- 已同步到本机的数据是否保留只读、保留完整可编辑，或转为仅单设备继续使用，需在 StoreKit 落地前明确
- 原则约束：不得因取消订阅导致用户已在本机可访问的数据被隐藏或不可导出
- 至少应保证：取消订阅后仍可查看、导出、手动备份已有数据

### 定价策略（2026-04-01 确立，横向研究 Infuse / Bear / Craft 后决策）

**全免费发布**——先积累口碑和用户基数，不上订阅。

**Pro 订阅（iCloud 同步就绪后引入）**——iCloud 同步为核心付费点，图片处理增强（去手写/去批改痕迹/试卷还原）和高级导出为增值功能。

**分市场定价**（Apple 允许每个 Storefront 独立设定订阅价格）：

| 层级 | 中国区（CNY） | 美国区（USD） | 说明 |
|---|---|---|---|
| **Pro 月订阅** | ¥8/月 | $1.99/月 | 起步低价获客 |
| **Pro 年订阅** | ¥68/年 | $19.99/年 | 年费优惠约 30% |
| **Lifetime 买断** | ¥298 | $49.99 | 为不喜欢订阅的用户提供选择 |

**14 天 Free Trial**——让用户先体验 iCloud 同步的便利再决定是否付费（Bear 的做法）。

**Grandfather 涨价策略**（Bear 模式）：
- 老用户永远保持注册时的价格，涨价只影响新用户
- 用户量增长验证后，新用户涨到 ¥12/月 / $2.99/月
- 老用户只要不中断订阅，永远保持 ¥8/月 / $1.99/月
- Apple StoreKit 原生支持此模式——续期按原价扣，新订阅按新价

**汇率说明**：¥8 CNY ≈ $1.10 USD，与 Apple 均衡化体系中 ¥6 → $0.99 的映射一致 [来源待补：需附 Apple Pricing Matrix 链接]。
不建议中美同价（¥9.9/月 vs $9.9/月），汇率差 7 倍会导致定价失衡。

**定价原则**：
- 首发全功能免费（积累用户和口碑）
- 付费功能必须是"增值"而非"解锁基础能力"
- 价格定位：用户群体（家长 + 学生）可承受（对标 Bear $2.99/月 的工具 App 价位）
- 不做去水印——产品本身不应该有水印，这不是尊重用户的做法
- 保留 Lifetime 选项——参考 Infuse（$94.99 起），为一次性付费用户提供选择

## 隐私策略（2026-03-07 确立，Bear 模式）

SnapDrill **不收集任何可识别个人信息**（no personally identifiable information）。没有注册，没有手机号，没有学校年级。
匿名使用数据采用两个独立开关，分别控制 Firebase Analytics 和 Crashlytics，默认开启，用户可在设置中分别关闭。

| 维度 | 竞品（喵喵机/橙果等） | SnapDrill |
|---|---|---|
| 注册 | 手机号必须 | 无注册 |
| 数据收集 | 姓名、学校、年级、位置 | 零可识别个人信息（匿名 Analytics / Crashlytics 独立开关，可分别关闭） |
| 存储 | 自建云端 | 纯本地 + iCloud（Apple 负责） |
| 合规负担 | 极重（ICP+等保+审计+儿童隐私） | 较轻（App 备案 + Apple 审核，不主动收集用户数据） |

**为什么这是核心差异化**：
- 2025 年中国四部门联合专项行动，3852 款 App 被通报侵害用户权益（同比增 152%）[来源待补：需附官方通报链接]
- 教育类 App 是重点监管对象——收集儿童个人信息属于敏感信息处理
- 家长最怕孩子的学习数据被平台收集利用
- SnapDrill 不主动收集用户数据 = 大幅降低监管风险 + 家长信任

**技术实现**：参照 Bear（意大利独立工作室 Shiny Frog 开发）的模式——
- 同步基于 Apple CloudKit，利用设备已有的 Apple ID 凭证，无需单独注册
- 中国区 iCloud 由云上贵州运营，数据存储在中国境内。中国大陆 iCloud 同步体验可能与其他市场有差异，iCloud 同步实现时做针对性测试
- 开启 Apple Advanced Data Protection 后，CloudKit 数据端到端加密，只有用户能解密

数据安全承诺见 `product-vision.md`§数据安全子条款 和 `product-design.md`§备份与恢复设计。

**用户须知（必须在产品中醒目提示）**：
- 免费版纯本地存储，**卸载 App = 数据永久丢失**——需在设置中和适当时机明确提醒
- 建议定期手动备份（`.snapdrill` 文件），或升级 Pro 启用 iCloud 自动同步

### App Store 年龄分级策略（2026-03-23 确立）

**年龄分级**：**4+**（Unrestricted）。SnapDrill 无不当内容、无社交功能、无 App 内购买诱导、无第三方广告。

**Kids Category 决策**：**不申请**。理由：
- Kids Category 限制较多（禁止外部链接、禁止第三方 SDK 向儿童发送数据等）
- SnapDrill 使用第三方分析和崩溃报告 SDK，虽然不收集个人信息，但技术上属于第三方 SDK
- SnapDrill 的主操作者是家长（非儿童直接使用），定位为「家庭场景的效率工具」而非「儿童 App」
- 4+ 年龄分级已足以覆盖目标用户群

**Declared Age Range API**（iOS 26+）：后续评估是否集成。该 API 允许 App 请求用户分享其年龄范围（由系统从 Apple Account 获取，需家长同意）。SnapDrill 的目标用户横跨多个年龄段（家长 + 6-18 岁学生），需评估是否及如何使用。美国多州已立法要求年龄核实，持续关注。

**COPPA / 儿童隐私合规姿态**（2026-03-30 更新）：

SnapDrill 的产品定位是**效率工具**（utility tool），不是教育工具（educational tool）：
- 不提供任何教育内容（无课本、无试卷、无题库）
- 所有内容由用户自主拍摄和录入
- 本质是"采集 → 管理 → 导出/打印"的数字化归档工具
- 类比：Scanner Pro、备忘录 — 学生也用，但不是"面向儿童的 App"

FTC 判定 COPPA "directed to children" 的核心标准与 SnapDrill 的对照：
1. **视觉设计和语气** — 成熟、家长友好基线，非幼稚卡通风格
2. **是否提供面向儿童的内容** — 不提供任何内容，所有数据来自用户
3. **营销对象** — 面向家长和学生，非专门面向 <13 岁儿童
4. **App Store 分类** — 未进入 Kids Category

虽然用户群包含 12-13 岁初中生，但效率工具定位与 "directed to children" 有本质区别。

**当前合规措施**：
- 零注册、零可识别个人信息收集
- 匿名使用数据默认开启，Analytics 和 Crashlytics 可在设置中分别关闭
- Privacy Manifest 声明数据不关联、不追踪

**App Store 营销注意事项**：避免使用 "children""kids""儿童教育" 等触发 FTC/Apple 审查的措辞，强调"效率工具""数字化归档""家长和学生"。

**后续评估**：如 App Store 审核或法律咨询认为需更严格合规，再考虑 Declared Age Range API 集成或 Analytics 默认关闭。美国多州已立法要求年龄核实，持续关注。

### 隐私合规风险应对预案

| 风险场景 | 影响 | 应对措施 | 升级触发条件 |
|---|---|---|---|

**日常检查节奏**：
- 每次 iOS 大版本（WWDC 后）：审查 Privacy Manifest 要求变更
- 每季度：扫描 FTC 和中国监管最新通报
- App Store 审核被拒时：立即分析拒绝理由，归档到本表

### 行业格局

### 竞品致命缺陷（用户真实痛点，来自知乎测评）

1. **录入界面拥挤** — 一屏塞满字段，容易误操作（SnapDrill 对策：默认仅开启学科）
2. **付费限制录入** — 橙果免费 50 题后收费，部分 App 每天 10 题（SnapDrill 对策：永不限制）
3. **注册流程繁琐** — 要求手机号+学校+年级+位置权限（SnapDrill 对策：零注册）
4. **OCR 不准 + 强制校对** — 用户被迫修正识别错误（SnapDrill 对策：展示但不强迫校对）
5. **打印要会员** — 基础功能付费化（SnapDrill 对策：基础 PDF 导出免费）

### 与 Anki 的本质区别（2026-03-23 从 product-vision.md 迁入）

Anki 是"记忆工具"——用户为了记住知识而制卡。
SnapDrill 是"数字化归档工具"——用户为了留存有价值的题目而录入，价值链终点是导出/打印纸质练习卷。复习是独立附加值，不在价值链内。

目标用户群（中小学生及家长）与 Anki 用户群重叠度低，SnapDrill 面向的是"不知道间隔重复但需要存档练习题"的大众市场。

### 隐形竞品：通用工具的替代威胁

除错题本赛道的直接竞品外，用户可能用通用工具替代 SnapDrill 的部分功能。这些通用工具不直接竞争错题本市场，但覆盖了采集和存储环节。

| 通用工具 | 覆盖的能力 | 未覆盖的练习题场景 |
|---|---|---|
| **Apple 备忘录 + 扫描文稿** | 免费扫描（自动边缘检测/透视校正）、OCR 文字搜索（Live Text）、iCloud 同步、文件夹/标签/Smart Folder 过滤 | 未提供题目语义结构（科目/难度/答案配对）、未提供连续裁剪同一张图的采集流程、未提供按学科/难度过滤后导出练习卷、未提供 Multi-Profile 隔离、未提供间隔重复复习 |
| **Notion** | 数据库驱动的结构化笔记、模板、Education Plan（主要面向高等教育，K-12 适用性有限） | 未提供原生文档扫描、对扫描件 OCR 能力有限（依赖前置 OCR）、学习场景需用户自建模板配置成本较高、未提供间隔重复复习 |
| **GoodNotes** | 手写 OCR 搜索、PDF 标注、Study Sets + Smart Learn（基于 spaced repetition 的复习系统） | 未提供面向练习题的结构化采集流程和元数据管理、未提供 Multi-Profile 隔离。定价：年订阅或一次性买断（Special Edition） |

**为什么 Apple 备忘录不是充分替代**：
- 备忘录扫描的是通用"文档"，SnapDrill 采集的是"题目"——题目有科目、难度、答案、标签等结构化元数据，备忘录未提供这些维度
- 备忘录未提供"连续裁剪同一张图上的多道题"的采集流程优化
- 备忘录虽支持标签和 Smart Folder 过滤，但不支持按科目/难度维度过滤后导出练习卷
- 备忘录未提供 Multi-Profile 隔离（多孩家庭场景）
- 备忘录未提供间隔重复复习系统

**观察**：通用工具覆盖了"拍照存档"的基础需求，但未针对"练习题管理"场景做优化。SnapDrill 的差异化在于题目语义结构、针对练习题的采集流程和导出/打印闭环——这些是通用工具通过配置难以复制的垂直能力。

## 商业模型假设

> 发布前用于统一口径和埋点定义；数值假设待真实用户数据验证，不作为对外承诺。

| 指标 | 定义 | 用途 | 当前口径 |
|---|---|---|---|
| DAU | 当日打开 App 且完成至少一次有效会话的去重设备数 / 用户数 | 衡量日常使用黏性 | 待发布后以 Analytics 事件定义固化 |
| MAU | 最近 30 天内至少完成一次有效会话的去重设备数 / 用户数 | 衡量月活规模 | 待发布后以 Analytics 事件定义固化 |
| DAU/MAU | 日活与月活之比 | 衡量使用频率与产品习惯形成度 | 目标是验证"高频录入 + 低压复习"是否成立 |
| Trial Start Rate | 看到付费墙后开启 Free Trial 的用户占比 | 衡量付费墙和价值表达是否有效 | iCloud 同步上线后可衡量 |
| Trial Conversion Rate | Trial 到期后转为付费订阅的用户占 Trial 开启用户比例 | 衡量 iCloud 同步和增值功能是否足够打动用户 | 核心商业化指标之一 |
| Paid Conversion Rate | MAU 中成为有效付费用户的比例 | 衡量整体变现效率 | 与 Trial Conversion Rate 联动观察 |
| Retention D1 / D7 / D30 | 注册日或首次使用日后第 1/7/30 天仍活跃的用户比例 | 衡量首次价值、周留存和月留存 | 首轮验证录入闭环与复习附加值 |
| ARPPU | 平均每个付费用户带来的收入 | 衡量定价和产品组合是否健康 | 需区分月订阅 / 年订阅 / Lifetime |
| LTV | 单个用户生命周期内贡献的累计净收入 | 用于判断可持续获客与长期价值 | 需结合 churn、续订率和成本估算 |
| Churn Rate | 订阅用户在一个计费周期后流失的比例 | 衡量订阅稳定性和取消后的价值缺口 | 与订阅取消后降级策略强相关 |
