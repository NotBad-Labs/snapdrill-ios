## 产品概述

SnapDrill 是**面向家庭教育场景的简洁、私有、原生效率工具**，解决纸质练习题数字化存档低效的问题。

### 核心价值链

**采集 → 管理 → 导出/打印**

复习是独立附加值，不在核心价值链内。免费用户应能完成完整单设备闭环；多设备流转和智能增强属于增值体验。

### 默认基线用户

默认设计基线是**第一次打开 App 的家长**。小学阶段通常由家长操作；中学生可以独立使用，但产品不以“技术型学生”作为默认心智模型。

### 产品不是什么

- 不是内容平台
- 不是社交产品
- 不是打卡/排行榜产品
- 不是靠“限制免费录题数量”收费的产品
- 不是以复习为核心目标的记忆工具

---

## 当前版本目标

当前版本优先保障以下产品目标：

1. 让用户以最低摩擦完成题目数字化录入。
2. 让已录入题目可以被可靠地整理、搜索、过滤、编辑和导出。
3. 让免费层保持完整单设备体验，不把基础能力变成订阅门槛。
4. 让数据保持私有、可迁移、可导出、可恢复。

当前版本**不以**社交传播、学习激励、内容分发为目标。

## 范围界定

### In Scope

#### 采集
- Camera / Photos / Document Scan / PDF / Manual / Clipboard / Share Extension 入口
- OCR 展示、搜索索引、复制、手动修正
- 一图连续裁剪
- 草稿恢复

#### 管理
- 题库浏览
- 搜索、过滤、排序
- 编辑题目、补答案、标签管理
- 批量打标签、批量删除
- 删除撤销（5 秒窗口）
- 多 Profile 隔离管理

#### 导出/打印
- PDF
- JSON
- CSV
- `.snapdrill` 手动备份/恢复
- 基础打印能力

#### 复习
- 基础 SM-2 复习
- Dashboard 待复习入口
- 复习卡片外观设置

#### 设置与个性化
- 用户资料
- 外观模式
- 通知设置
- 字段配置
- 隐私与数据导出入口

### Out of Scope

- 内容平台（题库、课本、课程）
- 社交社区、排行榜、连续打卡
- 注册/登录体系
- 限制免费录入数量
- 儿童导向内容产品定位

### Deferred / Exploratory

- AI 辅助拆题
- 手写体识别增强
- 端上 AI 集成
- iCloud 同步的正式落地设计与实现
- Word 导出
- 某些高级统计与智能增强的深化能力

## 核心能力清单

| 能力 | 当前承诺 | 边界 |
|---|---|---|
| 采集 | 用户可通过多入口录题，OCR 作为辅助文本，原图/主内容保留 | OCR 不是唯一真相源；探索性 AI 识别能力不构成当前承诺 |
| 管理 | 用户可浏览、搜索、过滤、编辑和分类整理题目 | 管理围绕题库，不扩展为社区或内容消费系统 |
| 导出/打印 | 用户可导出 PDF/JSON/CSV，执行打印，做手动备份/恢复 | 基础导出免费；高级导出和多设备流转可属于增值体验 |
| 复习 | 用户可做基础 SM-2 复习 | 复习是附加价值，不重排核心价值链优先级 |
| 设置与个性化 | 用户可管理资料、外观、字段、通知、隐私偏好 | 不引入账号化、社交化身份体系 |
| 数据与隐私控制 | 用户数据本地优先、可导出、可删除、可备份 | 零注册、零 PII、默认不采集匿名遥测是产品边界，不是可选文案 |

## 产品边界

### 价值链边界

采集、管理、导出/打印是产品主路径。复习是附加值，不应反向主导整体产品结构。

### 免费 / Pro 边界

免费层 = **完整单设备体验**。  
Pro = **跨设备流转 + 智能增强 + 深度增值能力**。

### 本地 / 云边界

产品当前默认是本地优先、手动备份可迁移。iCloud 同步是未来增值能力，不是当前基础能力依赖。

### 图片 / OCR 边界

图片是真相，OCR 是辅助展示、搜索与复制文本。不得把 OCR 结果当成唯一主内容。

### 隐私 / 遥测边界

默认不采集匿名遥测，用户明确 opt-in 后才可激活。Not Tracking 与零 PII 是产品边界，不得在实现层被稀释。

---

## 商业与隐私边界

- 免费层必须保持完整单设备产品体验。
- 付费只解锁增值体验，不解锁基础能力。
- 绝不限制免费录入数量。
- 默认不采集匿名 Analytics / Crashlytics，用户可独立控制。
- 不做注册，不收集可识别个人信息，不使用 IDFA。

商业策略与定价细节见 `product-business.md`；合规分析与平台口径见 `../tech/compliance.md`。
