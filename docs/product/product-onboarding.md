# SnapDrill Onboarding 内容规格

> 上游依赖：`product-vision.md`（P5 家长友好、用户画像）、`product-design.md`§引导与帮助设计概要。
> 本文件定义 Onboarding 的页面内容、文案方向和触发规则。

## 设计原则

- **快进不配置**：Onboarding 只介绍核心功能，不要求用户做任何设置
- **3-4 页**：每页一个核心概念，滑动翻页
- **成熟语气**：面向家长，不幼稚、不卡通
- **可跳过**：提供"开始使用"跳过按钮

## 页面内容

### 第 1 页：SnapDrill 是什么

**一句话**：拍一张照片，把练习题存下来。

**要点**：
- 孩子的错题、试卷、作业，拍下来就能数字化存档
- 不用抄题、不用剪贴、不用分类——App 帮你做
- 所有数据存在你的设备上，不需要注册账号

**配图方向**：一张手写试卷 → 拍照 → 结构化题目的转换示意

### 第 2 页：怎么录题

**一句话**：多种方式录入，拍照最快。

**要点**：
- 打开相机，对准题目，自动框选，保存——三步完成
- 也支持从相册选图、扫描文档、导入 PDF
- 录完一题自动回到相机，连续录入不中断

**配图方向**：采集界面截图或线框图（相机取景 + 自动框选效果）

### 第 3 页：存下来能做什么

**一句话**：管理、导出、打印——你的数据你做主。

**要点**：
- 题库里按学科/难度/标签分类查找
- 考前导出 PDF 打印练习卷（可隐藏答案、留答题区）
- 支持复习模式，帮你按遗忘曲线安排复习
- 多个孩子的题库分开管理，互不干扰

**配图方向**：题库列表 + 打印效果示意

### 第 4 页（可选）：你的隐私我们保护

**一句话**：不需注册，数据只属于你。

**要点**：
- 不要求姓名、手机号、学校等直接身份信息
- 所有题目和图片纯本地存储
- 只有你主动开启后，才会匿名收集使用统计（帮助改进产品）

**配图方向**：锁图标或隐私示意

## 结束动作

Onboarding 结束后直接进入 App 主界面（Dashboard）。
用户看到的是：
- 一个已创建好的默认 Profile
- 空的 Dashboard（新用户无数据，展示空状态引导）
- 底部 Tab 栏：首页/题库/采集/复习/设置

## 后续引导

Onboarding 不包含功能配置。以下引导在用户使用过程中触发：

| 触发时机 | 引导内容 | 实现方式 |
|---|---|---|
| 首次进入采集页 | 提示可以拍照或选图 | TipKit |
| 首次录入保存后 | 弹窗：要不要开启更多字段（难度、来源等）？ | Alert |
| 首次进入题库过滤 | 提示可多选学科/标签/难度 | TipKit |
| 首次进入复习 | 提示左滑不记得右滑记得 | TipKit |

## 不做什么

- 不要求填写昵称/头像/学校/年级
- 不要求选择学科或配置字段
- 不弹通知权限请求（用户主动开启提醒时才触发系统弹窗）
- 不播放视频教程（增加认知负担）
- 不做动画过渡特效（家长友好 > 炫技）
