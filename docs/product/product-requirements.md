## 采集方式优先级

| 优先级 | 方式 | 说明 | 版本 |
|---|---|---|---|
| P0 | 摄像头拍照（智能相机） | 最高频场景：看到题 → 拍一张 → 存档。实时文字区域检测 + 稳定性指示器 + 自动框选 | ✅ |
| P0 | 相册导入 | 已有照片（截图、微信图片等）的导入。**iPad 上这是主要录入方式**——举 iPad 拍试卷体验笨重 | ✅ |
| P0 | 文档扫描 | 系统级文档扫描（自动透视校正、边缘检测、多页扫描） | ✅ |
| P0 | PDF 导入 | 试卷、作业的批量数字化。选择 PDF 文件后逐页预览、选择页面、裁剪 | ✅ |
| P1 | 手动编辑 | 兜底方案：用户自己输入文字和图片 | ✅ |
| P1 | 剪贴板导入 | 从系统剪贴板粘贴文本到 SnapDrill | ✅ |
| P1 | iOS Share Extension | 从微信/QQ/浏览器直接分享图片到 SnapDrill，免去保存相册步骤 | ✅ |
| P2 | 其他载体 | 未来扩展（如网页剪藏等） | — |

> **注**：P1 表示重要性仅次于 P0。具体实现状态见底部「v2.0 功能全景」。

## 导出与打印能力

| 状态 | 格式 | 说明 | 付费 |
|---|---|---|---|
| ✅ | PDF | 基础 PDF 导出，含导出前预览 | 免费 |
| ✅ | JSON | 结构化数据导出（隐私设置页，支持 GDPR 数据可携带权；以实际导出字段清单为准） | 免费 |
| ✅ | CSV | 结构化数据导出（隐私设置页，可用 Excel 打开；以实际导出字段清单为准） | 免费 |

打印 vs 导出的设计区分见 `product-design.md`§导出与打印设计。

## 草稿恢复

录入过程中用户意外退出（如来电、误触 Home 键），已输入的内容不应丢失。
- 采集页面退出时自动保存草稿（图片 + OCR 文字，或纯文本）
- 下次进入采集时检测到草稿，弹窗提示用户恢复或放弃（含草稿内容摘要）
- 草稿仅保留最近一份，保存新题目后自动清除
- 草稿 7 天过期后自动清理
- 支持纯文本草稿保存（无图片的手动录入场景）

设计 rationale 见 `product-design.md`§草稿恢复设计。

## 备份与恢复

> 设计决策见 `product-design.md`§备份与恢复设计。行为规格见 `product-cases.md` UC6。

- 手动备份：`.snapdrill` ZIP 文件，打包全部 Profile（题目、图片、元数据、复习进度）
- 恢复前必须执行文件完整性和版本兼容性校验，校验失败必须拒绝恢复且保持现有数据不变
- **向后兼容铁律**：新版本 App 必须能恢复旧版本备份，违反即构成免费用户换机数据永久丢失（S0）。详细策略见 `product-design.md`§备份与恢复设计
- 卸载提醒：设置页和适当时机提醒"卸载 = 数据永久丢失"

首次启动展示多页引导流（~3-4 页），介绍核心功能。不在 Onboarding 中要求字段配置。

首次使用某功能时弹出轻量提示气泡（如首次进入过滤页提示「可多选学科」）。

## 设置与个性化

### 用户资料（纯本地，不上传）

- **昵称**：显示在 Dashboard 问候语中
- **座右铭**：个人激励文字
- **头像**：从预设头像组中选择，或从相册上传自定义照片
- **每日复习目标**：用户自由设定，无硬性范围限制

所有资料纯本地存储，不外传，与 PV-4「不收集可识别个人信息」一致。
这不是注册信息，是本地个性化定制。

### 复习卡片外观

- 字号：正面和背面独立设置，范围相同（题目和答案内容密度天然不同，独立字号是合理需求）
- 对齐方式：左对齐 / 居中 / 右对齐三选项，正反面均默认左对齐
- 提供实时预览

### 通知细节

- 通知权限请求时机：**仅在用户主动开启提醒开关时触发**系统授权弹窗（HIG: 用户理解价值后才请求，不在首次启动时请求）
- 每日复习提醒：开关 + 时间选择（小时/分钟）
- 通知声音开关
- App 图标角标：不使用角标，仅使用本地通知提醒（决策依据：vision P2「不贩卖焦虑」）

### 外观

- 外观模式：跟随系统（默认）/ 浅色 / 深色。HIG 建议跟随系统，但三选项是行业惯例（Telegram、Bear、Notion），Apple 不因此拒审

### 存储维护

- 媒体缓存清理：清理 App 运行产生的临时文件（OCR 临时图片、PDF 渲染缓存等），不影响用户题目数据

### 使用数据（Analytics + 崩溃报告）

- 两个独立开关分别控制 Analytics 和 Crashlytics
- **首次启动默认不采集**（plist 预禁用），用户可在设置中 opt-in 开启或关闭
- 收集的是匿名事件计数和崩溃堆栈，不含任何可识别个人信息或用户内容

### 语言设置

- 支持 App 内直接切换语言（中文/英文直选，不依赖系统设置）

## 功能边界

### 功能边界（MoSCoW 分类）

> **MoSCoW** 优先级框架：Must = 没有就不能发布；Should = 重要但可延期；Could = 锦上添花；Won't = 明确不做。
> Kano 模型映射见 `product-design.md`§价值链与优先级。

#### Must Have（缺失 = 产品不可用）

- 多种方式录入题目（拍照、导入、手动）
- OCR 文字识别（降低手动输入成本）
- 题目分类管理（学科、来源、年级、标签、难度）
- 搜索和过滤
- 导出（PDF / JSON / CSV）
- 本地数据存储（隐私优先）
- 多 Profile（多孩家庭核心场景）
- 草稿恢复（S0 数据丢失防护）
- 删除撤销（数据安全信任）

#### Should Have（缺失 = 有摩擦但可用）

- PDF 增强（去答案、留白、页眉页码）
- 单题快速打印
- 批量打标签
- 批量删除（选择模式 + 软删除）
- 难度过滤
- App 内语言切换
- 手动备份/恢复
- iOS Share Extension
- 基础 SM-2 间隔重复复习（已实现，免费附加值定位）

#### Could Have（锦上添花）

- 图片处理增强：去手写/去批改痕迹/试卷还原（Pro 付费，免费限次体验）[需 PoC: 端上方案可用且 SDK < 50MB]
- 智能组卷 / Smart Paper（Hybrid：免费限次体验 + Pro 无限精准选题，ADR-001）
- iCloud 同步（Pro 付费）[阻塞: #485]
- Word 导出（Pro 付费）
- 高级统计（Hybrid：基础统计免费 + 趋势图/薄弱排行 Pro，ADR-001）
- 题目分享（单题生成卡片分享）
- 批量导出原图（ZIP）
- 数据导入（CSV 导入）
- iPad 大屏优化
- 批量导入增强（AI 辅助拆题，探索性）
- 手写体识别增强（探索性）
- 端上 AI 集成（探索性）
- 角色预设套件（为不同用户类型提供预配置的字段/标签方案，如"小学家长"/"初中生"/"竞赛"）

#### Won't Have（明确不做）

- 提供题库内容（我们是工具，不是内容平台）
- 社交功能（不是社区）
- 排行榜 / 竞争机制（不是游戏）
- 限制免费录入数量（核心差异化，永不限制）
- 去水印（产品本身不应该有水印）
- 注册/登录（零注册是核心差异化）

#### 待评估（需技术可行性确认）

- 公式识别与渲染（LaTeX/MathML，无 Apple 原生 API）
- iPad + Apple Pencil 深度集成（依赖第三方 App 支持）
- 多科目模板（不同学科结构化字段）
- AI 解题提示（远期探索，需明确边界——辅助提示 vs 直接生成答案，与"效率工具"定位的平衡）

### 探索性功能评估框架

| 功能 | 评估维度 | Go 条件 | No-Go 条件 | 评估窗口 |
|---|---|---|---|---|
| 手写体识别增强 | Apple Vision 中文手写识别率 | PoC 识别率 >= 70%（20 张真实试卷） | 识别率 < 50% 且无 Apple 改进路线 | 正式纳入前 |
| AI 辅助拆题 | 文档结构识别的题目边界检测精度 | 边界准确率 >= 80%（10 份真实试卷） | 准确率 < 60% 或误拆严重 | 正式纳入前 |
| 图片处理增强（去手写/去批改痕迹/试卷还原） | 第三方端上方案（离线、无数据上传、Pro 付费） | 端上方案可用，SDK < 50MB，去手写准确率 >= 80% | 所有方案均需云端或准确率 < 60% | 正式纳入前 |
