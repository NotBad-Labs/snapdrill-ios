## 采集方式优先级

| 优先级 | 方式 | 说明 | 版本 |
|---|---|---|---|
| P0 | 摄像头拍照（智能相机） | 最高频场景：看到题 → 拍一张 → 存档。实时文字区域检测 + 稳定性指示器 + 自动框选 | ✅ |
| P0 | 相册导入 | 已有照片（截图、微信图片等）的导入。**iPad 上这是主要录入方式**——举 iPad 拍试卷体验笨重 | ✅ |
| P0 | 文档扫描 | 系统级文档扫描（自动透视校正、边缘检测、多页扫描） | ✅ |
| P0 | PDF 导入 | 试卷、作业的批量数字化。选择 PDF 文件后逐页预览、选择页面、裁剪 | ✅ |
| P1 | 手动编辑 | 兜底方案：用户自己输入文字和图片 | ✅ |
| P1 | 剪贴板导入 | 从系统剪贴板粘贴文本到 SnapDrill | ✅ |
| P1 | iOS Share Extension | 从微信/QQ/浏览器直接分享图片到 SnapDrill，免去保存相册步骤 | ✅ |
| P2 | 其他载体 | 未来扩展（如网页剪藏等） | — |

> **注**：P1 表示重要性仅次于 P0。具体实现状态见底部「v2.0 功能全景」。

## OCR 识别能力演进路线

> OCR 定位策略和设计决策见 `product-design.md`§OCR 定位

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | 印刷体中英文 OCR + 实时文字区域检测 | Apple Vision 高精度识别模式，中英文 |
| ✅ | OCR 手动重试 + 稳定性提示 | 识别失败时提供手动重试选项，并显示稳定性提示引导用户调整拍摄姿势 |
| ✅ | OCR 结果复制到剪贴板 | 用户可在编辑界面复制识别文字到系统剪贴板 |
| [需 PoC: 识别率 >= 70% (20 张真实试卷) 则纳入] | 手写体识别增强 | Vision 对手写体有一定支持，但无独立中文手写识别模型。需评估实际识别率后决定是否作为正式功能 |

**OCR 不阻断保存原则**：
- OCR 文字识别结果不是保存前置条件——用户可以在文字未校对、识别失败、或拒绝再次重试的状态下直接保存题目（图片是真相）
- 保存按钮的可用性只依赖于「至少有一张图片或一段手动文字」，不依赖 OCR 结果质量
- 详细决策见 `product-design.md` §OCR 定位

## 题库排序与过滤

题库列表支持多种排序方式：
- **录入时间**（默认，倒序）
- **学科**
- **难度**
- **复习状态**

## 字段配置规格

> 承接 `product-design.md` §字段可配置系统。设计原则与用户故事见 Design 文档；本段定义产品层规格与验收边界。

### 字段分层（与 Design §字段分层对齐）

| 层级 | 字段 | 录入可见性 | 是否支持过滤 | 是否支持排序 |
|---|---|---|---|---|
| 固定字段 | 题目内容（文字/图片）| 永远可见，不可关闭 | — | 录入时间排序 |
| 默认开启 | 学科 | 默认显示，可在设置关闭 | ✅ 多选 | ✅ |
| 默认关闭 | 难度 | 用户在设置开启 | ✅ 多选 | ✅ |
| 默认关闭 | 来源 | 用户在设置开启 | ❌（决策见 design）| ❌ |
| 默认关闭 | 年级 | 用户在设置开启 | ❌（决策见 design）| ❌ |
| 默认关闭 | 答案 | 用户在设置开启 | ❌ | ❌ |
| 自定义标签 | 用户创建的标签 | 始终可用，不可关闭 | ✅ 多选 | — |

### 系统字段选项管理

「学科 / 来源 / 年级」三个字段的**选项列表**是用户可编辑的（区别于「字段本身是否开启」）：

| 操作 | 验收标准 |
|---|---|
| 增（设置页深度入口）| 用户可手动新增选项，含颜色与图标 |
| 增（录入页无感）| 用户在录入界面输入新值即自动创建选项（颜色/图标默认随机），不跳转设置页 |
| 改 | 重命名时**级联更新所有引用该选项的题目**（保证数据一致性）|
| 删 | 已被题目使用的选项**禁止删除**（保护数据完整性，UI 阻断并提示）|
| 颜色/图标 | 每个选项可选颜色和图标，用于过滤胶囊和列表中的视觉区分 |

### 配置入口分层

| 入口 | 触发场景 | 行为 |
|---|---|---|
| Onboarding | 首次启动多页引导 | **不要求配置任何字段**（Apple HIG: avoid setup info up front）|
| 首次录入后引导 | 用户完成第一次保存 | 弹出引导提示「要不要开启更多字段（难度/来源等）？」|
| 设置页字段管理器 | 用户在设置中主动配置 | 随时开关字段；管理选项列表；调整顺序 |
| 录入页输入新值 | 用户在录入界面输入未知选项 | 无感创建（系统字段选项管理 §增 路径）|
| 题库编辑 | 用户编辑已有题目 | 可扩展尚未开启的字段（不需要先去设置）|

### 自动推断（与字段配置互补）

字段配置决定「字段是否存在」，自动推断决定「字段的默认值」：

- 上次选了「数学」→ 这次默认「数学」
- 上次选了「期中模拟卷三」→ 这次默认同来源
- **Per-Profile 隔离**：切换 Profile 后推断基于该 Profile 的历史，不跨 Profile 漂移
- 自动推断仅作用于「开启的字段」——关闭的字段无 UI 暴露推断值

### 与过滤排序闭环

- 「字段可开启 ≠ 字段可过滤」：来源 / 年级是开启可录入但不过滤的字段（design P2 简洁约束）
- 关闭的字段在过滤 UI 中不出现（哪怕历史题目曾有该字段值）
- 系统字段选项的颜色 / 图标用于过滤胶囊视觉区分

## 草稿恢复

录入过程中用户意外退出（如来电、误触 Home 键），已输入的内容不应丢失。
- 采集页面退出时自动保存草稿（图片 + OCR 文字，或纯文本）
- 下次进入采集时检测到草稿，弹窗提示用户恢复或放弃（含草稿内容摘要）
- 草稿仅保留最近一份，保存新题目后自动清除
- 草稿 7 天过期后自动清理
- 支持纯文本草稿保存（无图片的手动录入场景）

**软删除强退收敛**：
- 题目删除使用 5 秒撤销窗口的软删除模式
- 5 秒倒计时期间用户强制退出 App（杀进程 / Home 键 / 系统杀进程）→ 下次启动时 `DeletionScheduler` 在 App boot 阶段扫描所有未过 5 秒窗口的软删除项，**自动收敛**（已超时则永久删除，未超时则保留待用户操作）
- 不允许出现「软删除中间状态泄漏 / 题目永久从 UI 失踪但还在数据库」的孤儿状态

设计 rationale 见 `product-design.md`§草稿恢复设计。

## 错误处理与分级

承接 `product-design.md` §错误分级：所有用户面错误必须按 L1/L2/L3 分级处理。

| 级别 | 严重性 | 用户感知 | 行为 |
|---|---|---|---|
| **L1 Fatal** | 数据损坏 / 不可恢复 | 全屏 Alert + 操作日志 | 阻断主流程；引导用户备份/反馈；必要时提供「回到上次完整快照」选项 |
| **L2 Error** | 操作失败但可重试 | 卡片或 Banner 内嵌错误 + Retry 按钮 | 不阻断 UI；保留用户输入；提供重试 / 取消两选项 |
| **L3 Warning** | 状态异常但操作完成 | Toast 或 Section footer 提示 | 不打断；用户可忽略 |

适用范围：录入失败 / 保存失败 / 导出失败 / 恢复失败 / 通知调度失败 / 同步失败 / OCR 失败等所有可视错误。

## Multi-Profile 生命周期规格

承接 `product-design.md` §Multi-Profile 设计。覆盖 4 个关键生命周期：

| 场景 | 规格 |
|---|---|
| **创建 Profile** | 新 Profile 立即生效；独立数据库 + 独立图片目录 + 独立 UserDefaults per-profile keys；不复制其他 Profile 数据 |
| **删除 Profile** | 二次确认弹窗（红色危险操作）+ 显式输入 Profile 名称确认；删除物理目录 + 数据库文件 + per-profile UserDefaults；不影响其他 Profile；不可撤销 |
| **切换中断保护** | Profile 切换期间禁止数据写入（saveContext 排队 / UI 显示 loading），切换完成后再放行；切换失败回滚到原 Profile，不留中间态 |
| **最后 Profile 保护** | 当只剩 1 个 Profile 时禁用删除按钮，UI 文案提示「至少保留一个 Profile」 |
| **TipKit 重置** | 切换 Profile 时按 Profile 隔离 TipKit 状态（每个孩子各自看一次新功能引导）|
| **AppActivityTracker 互斥** | 关键操作期间（导出 / 备份 / 恢复）禁止切换 Profile，UI 显示「正在导出/备份/恢复中，请稍候」|

## 备份与恢复

> 设计机制见 `product-design.md`§备份与恢复设计。行为规格见 `product-cases.md` UC6。

- 手动备份：`.zip` ZIP 文件，打包全部 Profile（题目、图片、元数据、复习进度）
- 恢复安全规范：仅在文件完整性与版本兼容性满足要求时执行恢复；不满足时必须拒绝恢复且保持现有数据不变
- **向后兼容规范**：`.zip` 是免费用户换机的数据迁移出口；新版本 App 必须能恢复旧版本备份，任何违反该承诺并导致数据永久丢失的情形按 S0 处理
- 卸载提醒：设置页和适当时机提醒"卸载 = 数据永久丢失"

**元数据原子 vs 图片 best-effort 差异化**（承接 `product-design.md` §备份与恢复设计）：
- **元数据**（题目记录、字段配置、复习进度、Profile 列表）：原子操作，恢复时全成功或全回滚
- **图片**：best-effort 恢复，单张图片解压失败不阻断整体恢复流程；缺失图片对应的题目仍可恢复（OCR 文字保留），UI 显示「图片缺失」占位
- **恢复前安全网**：恢复操作前自动备份当前数据到沙盒临时目录，恢复失败时可一键回滚到操作前状态
- 详细机制（原子写入 / 临时目录策略 / 失败回滚链）见 `product-design.md` §备份与恢复设计

## 设置与个性化

### 用户资料（纯本地，不上传）

- **昵称**：显示在 Dashboard 问候语中
- **座右铭**：个人激励文字
- **头像**：从预设头像组中选择，或从相册上传自定义照片
- **每日复习目标**：用户自由设定，无硬性范围限制

所有资料纯本地存储，不外传，与 PV-4「不收集可识别个人信息」一致。
这不是注册信息，是本地个性化定制。
数据收集范围与合规边界见 `../tech/compliance.md`。

### 复习卡片外观

- 字号：正面和背面独立设置，范围相同（题目和答案内容密度天然不同，独立字号是合理需求）
- 对齐方式：左对齐 / 居中 / 右对齐三选项，正反面均默认左对齐
- 提供实时预览

### 通知细节

- 通知权限请求时机：**仅在用户主动开启提醒开关时触发**系统授权弹窗（HIG: 用户理解价值后才请求，不在首次启动时请求）
- 每日复习提醒：开关 + 时间选择（小时/分钟）
- 通知声音开关
- App 图标角标：不使用角标，仅使用本地通知提醒（决策依据：vision P2「不贩卖焦虑」）

### 外观

- 外观模式：跟随系统（默认）/ 浅色 / 深色。HIG 建议跟随系统，但三选项是行业惯例（Telegram、Bear、Notion），Apple 不因此拒审

### 存储维护

- 媒体缓存清理：清理 App 运行产生的临时文件（OCR 临时图片、PDF 渲染缓存等），不影响用户题目数据

### 使用数据（Analytics + 崩溃报告）

- 两个独立开关分别控制 Analytics 和 Crashlytics
- **首次启动默认不采集**（plist 预禁用），用户可在设置中 opt-in 开启或关闭
- 收集的是匿名事件计数和崩溃堆栈，不含任何可识别个人信息或用户内容
- 数据流向、标识符与合规说明见 `../tech/compliance.md`

### 语言设置

- 支持 App 内直接切换语言（中文/英文直选，不依赖系统设置）

## 功能边界

### 功能边界（MoSCoW 分类）

> **MoSCoW** 优先级框架：Must = 没有就不能发布；Should = 重要但可延期；Could = 锦上添花；Won't = 明确不做。
> Kano 模型映射见 `product-design.md`§价值链与优先级。

#### Must Have（缺失 = 产品不可用）

- 多种方式录入题目（拍照、导入、手动）
- OCR 文字识别（降低手动输入成本）
- 题目分类管理（学科、来源、年级、标签、难度）
- 搜索和过滤
- 导出（PDF / JSON / CSV）
- 本地数据存储（隐私优先）
- 多 Profile（多孩家庭核心场景）
- 草稿恢复（S0 数据丢失防护）
- 删除撤销（数据安全信任）

#### Should Have（缺失 = 有摩擦但可用）

- PDF 增强（去答案、留白、页眉页码）
- 单题快速打印
- 批量打标签
- 批量删除（选择模式 + 软删除）
- 难度过滤
- App 内语言切换
- 手动备份/恢复
- iOS Share Extension
- 基础 SM-2 间隔重复复习（已实现，免费附加值定位）

#### Could Have（锦上添花）

- 图片处理增强：去手写/去批改痕迹/试卷还原（Pro 付费，免费限次体验）[需 PoC: 端上方案可用且 SDK < 50MB]
- 智能组卷 / Smart Paper（Hybrid：免费限次体验 + Pro 无限精准选题，ADR-001）
- iCloud 同步（Pro 付费）[阻塞: #485]
- Word 导出（Pro 付费）
- 高级统计（Hybrid：基础统计免费 + 趋势图/薄弱排行 Pro，ADR-001）
- 题目分享（单题生成卡片分享）
- 批量导出原图（ZIP）
- iPad 大屏优化
- 批量导入增强（AI 辅助拆题，探索性）
- 手写体识别增强（探索性）
- 角色预设套件（为不同用户类型提供预配置的字段/标签方案，如"小学家长"/"初中生"/"竞赛"）—— **边界**：仅作为设置页的可选模板入口（按一下就改字段开关），**不进入 Onboarding**，不增加首次配置摩擦（vision §1 录入体验 + §2 简洁）

#### Won't Have（明确不做）

- 提供题库内容（我们是工具，不是内容平台）
- 社交功能（不是社区）
- 排行榜 / 竞争机制（不是游戏）
- 限制免费录入数量（核心差异化，永不限制）
- 去水印（产品本身不应该有水印）
- 注册/登录（零注册是核心差异化）

#### 待评估（需技术可行性确认）

- 公式识别与渲染（LaTeX/MathML，无 Apple 原生 API）
- iPad + Apple Pencil 深度集成（依赖第三方 App 支持）
- 多科目模板（不同学科结构化字段）—— **边界**：仅作为高级字段配置模板（用户选「数学/英语/物理」自动应用预设字段子集），不扩展核心字段系统的层级（vision §2 简洁，不增加 design §字段可配置系统 复杂度）
- AI 解题提示（**初步评估为蚕食 vision §不是内容平台禁令 + 推翻 H3「核心需求是存档/打印，不是解题」假设；不进入近期路线**。若未来 H3 数据推翻，需先在 vision 加新假设/原则承接才能纳入）

## v2.0 功能全景

> 所有功能统一为 v2.0。已实现功能无特殊标注；未实现功能标注阻塞原因或 PoC 条件。
> requirements 只描述产品能力与实现状态，不记录 PR 编号和 Review 状态。研发流转状态统一维护在 STATUS.md。

**录入**
- 智能相机拍照（实时文字区域检测 + 稳定性指示器 + 自动框选）
- 相册导入
- 文档扫描（含多页选择）
- PDF 导入（文件选择器 + 逐页预览 + 页面选择 + 裁剪）
- 手动编辑
- 剪贴板导入（从系统剪贴板粘贴文本内容）
- 一图一题手动裁剪（自动框选 + 手动调整）
- 一图连续裁剪（同一张图上连续裁剪多题）
- OCR 印刷体中英文识别（Apple Vision 高精度模式），用户可手动修正
- OCR 手动重试 + 稳定性提示（失败后提供重试选项，引导调整拍摄）
- OCR 结果复制到剪贴板
- 字段可配置系统（学科默认开启，其余按需）
- 字段自动推断（沿用上次选值）
- 端上 AI 自动标注（Apple Foundation Models：从题干自动推断学科/难度，离线、零上传）
- 连续录入（保存后自动回到摄像头）
- 草稿恢复（意外退出后可恢复，含纯文本草稿）
- 相机权限缺失处理（权限拒绝/受限时引导用户到系统设置开启）
- iOS Share Extension
- 手写体识别增强 [需 PoC: 识别率 >= 70% (20 张真实试卷) 则纳入]
- AI 辅助拆题 [需 PoC: 边界准确率 >= 80% (10 份真实试卷) 则纳入]

**管理**
- 题库管理：搜索 + 多维过滤（学科/标签/难度）+ 编辑
- 系统字段选项增删改（学科/来源/年级，含颜色和预设图标）
- 题库排序（时间/学科/难度/复习状态）
- 批量打标签（选择模式 + 多题操作）
- 删除撤销（软删除 + 5 秒 Toast 撤销，超时永久删除）
- 批量删除（选择模式 + 软删除）

**复习**
- SM-2 间隔重复复习（翻卡 + 滑动评估）
- Dashboard 统计 + 待复习入口

**导出与备份**
- PDF 导出（含预览、去答案打印、留白答题区、页眉页码）
- 单题快速打印（详情页固定 1 题/页）
- JSON / CSV 结构化数据导出（以实际导出字段清单为准）
- 手动备份/恢复（`.zip` 文件）
- 题目分享卡片（ImageRenderer 生成分享图片）
- 批量导出原图 ZIP
- CSV 数据导入（RFC 4180 合规）
- 图片处理增强（Pro 付费，免费限次体验）：去手写/去批改痕迹/试卷还原 [需 PoC: 端上方案可用且 SDK < 50MB]
- Word 导出（Pro 付费）[阻塞: #486 — 需 StoreKit]
- 智能组卷 / Smart Paper（Hybrid：免费限次 + Pro 无限；SM-2 驱动选题 → 自动排版 → PDF/打印，ADR-001）

**同步与存储**
- iCloud CloudKit 同步（Pro 付费，**付费核心引擎**）：同步范围为全部 Profile（与备份策略对齐），基于 Apple CloudKit，利用设备已有 Apple ID。设计决策见 `product-design.md`§iCloud 同步设计 [阻塞: #485 — 需 StoreKit + CloudKit Container]

**多 Profile**
- 多 Profile / 多题库隔离（本地切换，参考 Obsidian Vault 切换，覆盖多孩家庭场景）

**设置与个性化**
- 用户资料（昵称/座右铭/头像/每日目标，纯本地）
- 复习卡片外观（字号正反面独立设置，对齐三选项默认左对齐）
- 通知设置（提醒时间/声音；不使用角标，仅本地通知提醒）
- 外观模式（跟随系统/浅色/深色）
- 使用数据开关（Analytics 与 Crashlytics 独立开关，默认不采集，用户可 opt-in）
- App 内语言切换（中文/英文直选）
- 媒体缓存清理 + 存储管理

**引导与帮助**
- 多页 Onboarding（功能介绍，不含字段选择）
- 首次录入后字段配置引导
- Feature Tooltips（首次使用提示；TipKit 按 Profile 隔离）
- 帮助中心（外部网页 FAQ 链接）

**隐私与合规**
- 零注册，纯本地存储
- 隐私政策 / 服务条款
- 卸载数据丢失提醒
- 开源许可展示（Firebase SDK 等第三方库，App Store 合规要求）

**无障碍**
- 全模块 VoiceOver 辅助标签、提示和公告（Dashboard / Capture / Library / Settings / Review）

**平台优化**
- iPad 分屏/大屏优化（sidebarAdaptable + 动态 grid 列数）
- iPad + Apple Pencil 深度集成 [需 PoC]

### 探索性功能评估框架

| 功能 | 评估维度 | Go 条件 | No-Go 条件 | 评估窗口 |
|---|---|---|---|---|
| 手写体识别增强 | Apple Vision 中文手写识别率 | PoC 识别率 >= 70%（20 张真实试卷） | 识别率 < 50% 且无 Apple 改进路线 | 正式纳入前 |
| AI 辅助拆题 | 文档结构识别的题目边界检测精度 | 边界准确率 >= 80%（10 份真实试卷） | 准确率 < 60% 或误拆严重 | 正式纳入前 |
| 图片处理增强（去手写/去批改痕迹/试卷还原） | 第三方端上方案（离线、无数据上传、Pro 付费） | 端上方案可用，SDK < 50MB，去手写准确率 >= 80% | 所有方案均需云端或准确率 < 60% | 正式纳入前 |
| 数理化公式识别 | 第三方端上方案（离线、无数据上传） | 端上方案可用，SDK < 50MB | 所有方案均需云端 | 待排期 |

**评估流程**：PoC → 对照 Go/No-Go 条件决策 → Go 创建 Issue；No-Go 标注原因，下次 iOS 大版本重新评估。

**待评估（需技术可行性确认）**
- 数理化公式识别与渲染（LaTeX，无 Apple 原生 API，需第三方端上方案）
