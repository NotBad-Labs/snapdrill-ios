# M-000 Meta-Vision v1.0 Round 3 收敛分析（四家齐版）

> Claude CLI 作为中立主笔，本报告做收敛分析，不下结论；最终修订裁决由用户做出。

## 1. 整体评分对比

| 维度 | Codex | Antigravity | Claude Desktop | DeepSeek | 主笔观察 |

**同源反差**：Claude Desktop（同 Opus）打分整体最低、问题最多——**这反而否定了"同源偏袒"假设**，说明它没有保护 Claude CLI 主笔。如果用户担心同源警告，本轮证据：同源 reviewer 反而最严苛。

## 2. Must-Fix（多家共识真硬伤）

四家中**两家或以上一致指出**的硬伤。这些不修订 v1.0 不能继续推进。

### 2.1 降级时双核裁决权真空 ⚠️

| 提出方 | 表述 |
|---|---|
| DeepSeek §2.1 | 「双核机制完整性被破坏时，裁决权如何运作？……至少应声明一条原则：双核机制完整性被破坏时，裁决权自动回退至用户」|
| Claude Desktop §2 隐含 | 「双核同意通过 = 默认通过……opt-out 机制全部留白」|

**问题**：用户口述允许降级到 Claude + DeepSeek，但 DeepSeek 无裁决权。此时「双核同意默认通过」机制失效，§4 没回答怎么办。

**建议修订**：§4 加一句「双核任一方不可用时，自动通过权失效，回退用户裁决」。

### 2.2 「异源辅助方」概念未定义 ⚠️

| 提出方 | 表述 |
|---|---|
| Antigravity §2.1 | 「智能体是黑盒，运行期无法自证其源……『异源辅助方提出反对导致双核通过权失效』成无法被执行的虚空条款」|
| DeepSeek §2.2 | 「关键概念未定义——『异源辅助方』指谁？降级状态下 DeepSeek 既辅助又异源……」|
| Claude Desktop §3.1 | 「『智能体』本身未定义——同厂商不同模型？同模型不同 prompt？元层应给独立定义骨架」|

**问题**：「异源」「智能体」「独立」三个核心概念都未定义，§7 整套伪共识失效机制无法机械执行。

**建议修订**：§7 补一句「异源 = 独立模型权重 + 独立训练谱系」，或者下沉到 M-001 但 M-000 必须给原则锚。

### 2.3 「沉默推定同意」漏洞 ⚠️

| 提出方 | 表述 |
|---|---|
| Claude Desktop §2.2 | 「双核同意 + 异源辅助方沉默 → 2 同意 + 1 沉默 = 3/3 一致 = 伪共识。从『沉默推定同意』到『伪共识』的距离非常近」|
| Antigravity 隐含 | 「同源高维共谋的检测难度」（盲点段）|

**问题**：用户原话「双核同意可不询问用户」+ §7 「异源辅助方强烈反对触发用户裁决」——但**辅助方沉默时**呢？文档没说。

**建议修订**：§7 加一句「辅助方沉默不构成认同；伪共识失效仅在异源方主动表态时不触发」。或者反向：「关键决策必须要求辅助方明确表态，无表态默认上交」。

### 2.4 「不可逆操作」边界过粗 ⚠️

| 提出方 | 表述 |
|---|---|
| Codex §1.A | 「不可逆操作」是开放概念，缺界定 |
| Claude Desktop §3.2 | 「代码世界几乎所有本地操作通过 git 可逆，真正不可逆的是外部副作用」|

**建议修订**：§4 「不可逆操作」改为「跨越本地工作区边界、产生外部副作用、对外承诺」（或类似收敛措辞）。

### 2.5 「伪共识」概念散在三处违反 SSOT ⚠️

| 提出方 | 表述 |
|---|---|
| Claude Desktop §6 | 「§4 提伪共识、§7 提伪共识、M-005 也管伪共识——违反 §8『每个概念只有一处权威定义』」|

**建议修订**：M-000 只保留「**伪共识判定原则**」（什么算伪共识 = 训练同源 + 一致结论），具体识别方法放 M-005，触发后裁决流程放 M-002。

### 2.6 「主笔自评」段不应在正文 ⚠️

| 提出方 | 表述 |
|---|---|
| Claude Desktop §2.5 | 「自我指涉的元评论不是宪法条款，建议挪到 PR 描述或 changelog」|
| Antigravity §7 风格 | 「冷峻、客观、纯粹的行为规范」要求消除元评论 |

**建议修订**：挪 v1.0 末尾「主笔自评」段到 commit message 或 docs/archive/research/M-000-meta-vision-roundtrip-20260521/ 的元数据；释放 50+ 字给真正遗漏。

## 4. 用户取舍的真挑战（多家强论证挑战）

这些是 round 2 用户已经拍板的取舍，但 round 3 出现**多家有强论证认为可能出问题**。需要用户重新评估。

### 4.1 取舍 3「1500 字硬上限 + 不强制一进一出」——三家挑战 ⚠️⚠️

| 家 | 论证 |
|---|---|
| Antigravity §5.1 | 「『文字压实黑洞』——AI 为塞规则会删掉对人类友好的解释、抽象成黑话/密电码；规则可能空心化」|
| Claude Desktop §五取舍 3 | 「v1.0 已经接近上限（1300-1400 字），增量空间已极小；若加数据治理/成本治理/智能体定义，1500 字根本不够。建议放宽 2000 字或上限指『不含 frontmatter/表格/自评』」|
| DeepSeek §5.其一 | 「『电报体』隐患——硬上限本意防大杂烩，但可能逼成信息完整但语义脆弱。建议软上限（超过需用户批准）+ 豁免条款」|

**主笔观察**：**三家提相似担忧**，论证一致——硬上限会让宪法走向「压缩 → 语义脆弱 → 歧义」。

**给用户的折中选项**：
- **A**：维持 1500 字硬上限不变（接受 trade-off）
- **B**：上限放宽到 2000 字（DeepSeek/Claude Desktop 倾向）
- **C**：上限定义改为「正文不含 frontmatter / 指针表格 / 主笔自评」的 1500 字（给气口）
- **D**：硬上限改软上限，超过需用户明确批准 + 在裁决日志阐释理由（DeepSeek 提议）

### 4.2 取舍 4「默认多方 + 无判据矩阵」——三家挑战 ⚠️⚠️

| 家 | 论证 |
|---|---|
| Codex §5.4 | 「执行者会在两种坏结果间摇摆：机械多方浪费注意力 vs 私自单方破坏权威。如果用户坚持，文档应明说『是价值宣言，不是无成本流程』」|
| Antigravity §5.2 | 「人类决策疲劳——人会『敷衍勾选』，废黜用户最高裁决权严肃性，为伪共识打开后门」|
| Claude Desktop §五取舍 4 | 「不预设 = 无机构记忆。建议折中：豁免决定强制写日志，但不预设判据，让日志在 3-6 个月后自然涌现判据」|

**主笔观察**：DeepSeek 是唯一**不挑战**这一取舍的——它认为「成本允许时成立」。其他三家都担忧执行漂移。

**给用户的折中选项**：
- **A**：维持「默认多方 + 用户当时当下豁免」不变
- **B**：保留默认多方，但**豁免决定强制写裁决日志**（不预设判据，事后归类）—— Claude Desktop 提议
- **C**：在 M-000 明文写「这是价值选择，质量优先于效率，承认有成本」——Codex 提议
- **D**：建立"高风险准入门槛"，低风险默认单方+Lint——Antigravity 提议（你之前已明确拒绝预设矩阵）

### 4.3 取舍 6「主笔轮换不强制」——一家挑战

| 家 | 论证 |
|---|---|
| DeepSeek §5.其二 | 「驾照类比未审视的假设：轮换收益总大于不轮换。如果用户长期不轮换，『提醒』就等同于没有机制。建议加：连续 N 次未轮换时，分歧裁决阶段额外附加主笔偏见自查」|

**主笔观察**：单家担忧，但论证有价值。可视为下游 M-001 主笔轮换细则要加的兜底。

## 7. DeepSeek 身份误识别——元规则的元实证 🪞

**事件**：DeepSeek V4-Pro 在 zero-context API 调用下，盲点段写「我作为 **Claude** 第三轮 review 的盲点」。

**意义**：
1. **印证 §7 伪共识条款的现实风险**——某家模型可能因训练数据 leakage 实质性承载另一家的 prior

**主笔建议**：把这个观察作为 M-000 §7 风险条款的**官方注记案例**（在 archive 或 commit message 中），证明该条款不是理论臆测，而是实证存在。

## 8. 元层级反思

### 8.1 同源警告假设被本轮 review 否定

我之前一直警告 Claude Desktop chat（同 Opus）有同源偏向风险。**但本轮 Claude Desktop Code 给出最严苛的评分**（治理 6.5 / 表述 6），找出问题最多。这反过来证明：

- 同源 ≠ 偏袒
- 干净的 zero-context（Desktop Code 没 CLAUDE.md/AGENTS.md）足以剥离仓库偏向
- 我之前的"主笔同源警告"假设有点过度

### 8.2 异源是必要不充分条件

- Antigravity（Gemini，异源）给认识论 9.2 — 高分确认
- DeepSeek（V4-Pro，异源 + 训练数据有 Claude leakage）给认识论 9 + 身份误识别 — 异源但有同质性
- 真正的"异源"是**异源 + 训练数据无 leakage**——这个标准在当下任何主流大模型都难达到

**结论**：M-000 §7 "伪共识"条款不仅是理论必要，是**当前模型生态下的实证现实**。

### 8.3 三家挑战字数硬上限

Antigravity / Claude Desktop / DeepSeek 三家同时挑战 1500 字硬上限。这是 round 3 最强的多家共识。**用户上次拍板这个上限的依据，可能需要重新评估**。
