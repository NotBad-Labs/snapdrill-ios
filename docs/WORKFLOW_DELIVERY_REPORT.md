## 🎯 交付目标

**用户需求**：
> "为了不同的人或者 AI 协同工作，我想确认目前的工作流能够形成闭环，比如 PRD 或者 ROADMAP 能否提醒同事或者 AI 按照某一个特定的工作流进行，而不会出现偏差呢？"

**交付承诺**：
建立一套完整的工作流闭环系统，包含文档体系、自动化检查、防偏差机制，确保：
1. 人类与 AI 都能明确"该走哪个流程"
2. 自动化 CI 强制执行 PRD 对齐
3. 任何偏离 PRD 的行为都被拦截
4. 所有决策可追溯到 PRD

### 场景 1：新功能开发（正常流程）✅
```
开发者："实现 OCR 功能"

    ↓ 确认走【流程 B：功能实现流程】

    ↓ 编写代码（包含 PRD 溯源注释）
    ↓ 提交 PR（包含 PRD 引用）
    ↓ CI 自动检查：✅ 通过
    ↓ 评审批准：✅
    ↓ 合并成功
```
**验证结果**：✅ 每个步骤都有文档/模板/自动化支持

### 场景 2：用户要求与 PRD 冲突（防偏差）✅
```
用户："添加第三方服务器同步"
    ↓ AI 查阅 PRD §1.2："本地优先"
    ↓ 检测到冲突 ⚠️
    ↓ AI 停止实现

    ↓ 评审批准后：AI 继续实现
```
**验证结果**：✅ AI 不会擅自决策，有明确升级路径

### 场景 3：PRD 定义不清晰（防阻塞）✅
```
开发者："实现遗忘曲线"
    ↓ 查阅 PRD §4.3.3
    ↓ 发现参数未明确 ⚠️
    ↓ 查阅 WORKFLOW.md：停止并走【流程 A】
    ↓ 创建 PRD 变更请求（补充定义）
    ↓ PRD 变更批准
    ↓ 继续实现
```
**验证结果**：✅ 有明确的"停止条件"与后续步骤

### 场景 4：反向约束拦截（自动防护）✅
```
开发者提交 PR
    ↓ 代码包含注释："TODO: PRD 应该增加缓存"
    ↓ CI 自动检测到反向约束
    ↓ CI 自动拒绝 PR
    ↓ CI 自动评论：提示先走【流程 A】
    ↓ 开发者移除注释或创建 PRD 变更请求
    ↓ 重新提交
```
**验证结果**：✅ 自动化拦截反向约束，无法绕过

## 🎉 核心成果

### 1. 工作流决策树（核心价值）

```mermaid
graph TD
    A[开始工作] --> B{需要改变产品行为?}
    B -->|是| C[流程 A: PRD 变更流程]
    B -->|否| D{是否新增功能?}
    D -->|是| E{PRD 中已定义?}
    E -->|是| F[流程 B: 功能实现流程]
    E -->|否| C
    D -->|否| G{是否修复 Bug?}
    G -->|是| H[流程 C: Bug 修复流程]
    G -->|否| I{是否重构/优化?}
    I -->|是| J[流程 D: 重构优化流程]
    I -->|否| K[流程 E: 文档/工具流程]
```

**价值**：任何人（人类/AI）都能在 30 秒内确定该走哪个流程。

### 2. AI 协作标准化

**AI 强制规则**（复制粘贴使用）：
```markdown
你是 NotBad 项目的 AI 协作者。必须严格遵守：

1. PRD 为宪法
   - 单一事实来源：docs/prd/PRD v6.2.md
   - 任何功能实现前，先阅读并引用 PRD 对应章节
   - 如 PRD 未定义或不清晰，停止并提示："需要先更新 PRD"

2. 工作流强制执行
   - 查阅 docs/WORKFLOW.md 决策树，确认当前任务走哪个流程
   - 新功能：走【流程 B】
   - PRD 变更：走【流程 A】
   - Bug 修复：走【流程 C】

3. 代码溯源要求
   - 每个新文件顶部必须注释：
     // PRD 章节：§X.Y.Z
     // 验收标准：AC-XXX-YYY-NN
   - PR 描述必须包含 PRD 章节编号

4. 禁止行为
   - ❌ 实现 PRD 未定义的功能
   - ❌ 创建与 PRD 冲突的文档
   - ❌ 绕过测试要求
   - ❌ 修改 PRD 而不走流程 A
```

**价值**：所有 AI 助手输出标准化，减少偏差。

### 3. 三重防偏差机制

```
┌─────────────────────────────────────────┐
│         层级 1：文档引导                 │
│  WORKFLOW.md 决策树 + AI_GUIDE 模板      │
└─────────────┬───────────────────────────┘
              ↓ 如果违规
┌─────────────────────────────────────────┐
│         层级 2：自动化拦截               │
│  CI 检查 PRD 引用 + 反向约束 + 覆盖率    │
└─────────────┬───────────────────────────┘
              ↓ 如果通过但有问题
┌─────────────────────────────────────────┐
│         层级 3：人工双保险               │
│  PR 模板强制填写 + 评审清单 + 批准机制   │
└─────────────────────────────────────────┘
```

**价值**：多层防护，确保不偏离 PRD。
