## **1\. 核心业务概念**

| 术语 (中文) | 英文术语 (English Term) | 定义 |
| :---- | :---- | :---- |
| **复习项** | Review Item | 需要复习的单个学习内容单元，是系统的核心实体。 |
| **学习闭环** | Learning Loop | "创建→复习→重做→掌握"的完整学习流程。 |
| **错题重做** | Redo Item | 针对已记录的复习项，重新作答以验证掌握程度的功能。 |
| **掌握度** | Mastery Level | 用户对某个复习项的掌握程度状态 (未掌握, 模糊, 已掌握)。 |
| **知识点** | Concept / Knowledge Point | 复习项所属的具体知识单元，用于分类和分析。 |
| **学习会话** | Study Session | 一次连续的学习活动。 |
| **复习模板** | Redo Template | 错题重做功能中生成的空白答题模板。 |

## **2\. 用户角色与权限**

| 术语 (中文) | 英文术语 (English Term) | 定义 | 配额限制 |
| :---- | :---- | :---- | :---- |
| **免费用户** | Free User | 使用基础功能的用户。 | 每日30个，每月500个复习项 |
| **Pro用户** | Pro User | 订阅或购买专业版的用户。 | 无限制 |
| **学生用户** | Student User | 主要使用者，K12阶段学生。 | 根据付费状态决定 |
| **家长用户** | Parent User | 查看孩子学习报告的用户。 | \- |

## **新增：性能相关术语 (基于Swift 6优化)**
| 术语 (中文) | 英文术语 (English Term) | 定义 | 目标值 |
| :---- | :---- | :---- | :---- |
| **启动性能** | Launch Performance | 应用启动到可用状态的时间 | < 1.5秒 |
| **响应性能** | Response Performance | 用户操作到系统响应的时间 | < 1秒 |
| **并发性能** | Concurrency Performance | 多任务并行处理的效率 | 提升30%+ |
| **内存效率** | Memory Efficiency | 应用内存使用效率 | < 80MB |
| **类型安全** | Type Safety | 编译时类型检查覆盖率 | 100% |
| **并发安全** | Concurrency Safety | 编译时并发访问安全检查 | 100% |
| **滚动流畅度** | Scroll Performance | 列表滚动时的帧率 | > 60fps |
| **动画流畅度** | Animation Performance | 界面动画的流畅度 | > 60fps |

## **4\. 业务流程与规则**

| 术语 (中文) | 英文术语 (English Term) | 业务规则 |

## **5\. 数据指标与分析（更新）**

| 术语 (中文) | 英文缩写 (Abbr.) | 业务意义 | 计算口径/备注 |
| :---- | :---- | :---- | :---- |
| **L1-月活跃记录用户** | MARU | 增长指标：月内创建 ≥1 个复习项的用户数 | 对应 PRD L1 指标（REQ-011） |

| **周学习闭环完成率** | WLLCR | 学习效果指标 | - |
| **Pro转化率** | CVR | 商业成功指标 | - |
| **次月留存率** | M2R | 产品粘性指标 | - |
