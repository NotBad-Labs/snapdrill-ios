# SnapDrill 产品需求文档（PRD）

- 状态：当前产品需求
- 产品负责人：PO
- 最后确认：2026-07-25

## 1. 产品定义

SnapDrill 是一款面向成年人的 iPhone 通用效率工具。它帮助用户把自己已有的纸张、照片和
PDF，以尽可能低的摩擦变成可搜索、可整理、可导出和可打印的一个本地资料库。

教育材料、考试资料和家庭作业可以被处理，但 SnapDrill 不是教辅软件，也不把用户定义为
学生、家长或教师。

## 2. 问题与目标用户

纸张、聊天附件、扫描件和 PDF 容易分散在相册、文件和桌面上。用户真正需要的是：

1. 快速采集，不重复录入；
2. 保存前看清内容并补充必要字段；
3. 稍后按文字或分类找回；
4. 把选中的资料交付为 PDF、打印件或备份文件。

首个目标用户是需要反复处理结构化纸张或 PDF 的成年人，例如职业考试、培训、工作资料和
家庭资料管理者。这是产品切入点，不是教育人群限制。

## 3. 市场参照与边界

SnapDrill 参考中国大陆成熟产品中已经验证过的操作模型：

- 拍照或导入材料；
- 裁剪、清理和 OCR；
- 分类、查找和重复利用；
- 合并为文档并打印。

参考对象包括
[橙果错题本](https://apps.apple.com/cn/app/id1240025662)、
[作业帮](https://www.zuoyebang.com/about) 和
[小猿搜题](https://apps.apple.com/cn/app/id906995758)。
这些产品只提供工作流参考，不构成需求清单。

SnapDrill 明确不复制它们的题库、答案搜索、自动解题、课程、教师服务、内容推荐、社区、
广告和会员增长体系。产品价值来自管理用户自己的材料，而不是平台内容。

## 4. 产品原则

1. **核心链路优先**：采集 -> 整理 / 找回 -> 导出 / 打印。
2. **快速但不草率**：默认操作少；保存前仍能确认图片、文字和关键字段。
3. **本地优先**：无需账号即可完成全部核心任务，用户内容默认不上传。
4. **用户拥有数据**：资料可查看、编辑、删除、导出和完整备份。
5. **中性成人工具**：界面和文案不低龄化，不使用焦虑、排名或连续签到推动使用。
6. **Apple 原生优先**：优先使用系统扫描、相册、文件、分享、打印和无障碍能力。
7. **附加功能不得干扰主线**：保留在代码中的实验能力不能占据首页或核心导航。

## 5. 核心用户流程

### 5.1 首次使用

用户不注册账号。简短引导后进入 Dashboard，并能直接开始采集或打开资料库。

### 5.2 采集

用户从相机、文档扫描、相册或 PDF 获取内容，确认裁剪和方向后进入预览与编辑。
OCR 结果可编辑、可搜索，但 OCR 失败不能阻止用户保存可读图片。

编辑界面提供通用元数据：

- 分类（Category）
- 来源（Source）
- 级别（Level）
- 标签（Tags）

字段均可选，不能让首次保存依赖预先配置。以后可以增加自定义字段，但不属于首版必需能力。

### 5.3 整理与找回

用户在单一资料库中浏览、搜索、筛选、查看详情、编辑字段和删除资料。资料可以只有文字、
只有主图，或同时具有文字与图片。

### 5.4 导出与打印

用户选择一条或多条资料，生成可预览的 PDF，并通过系统能力分享、保存或打印。打印是正式
终点，不能只用“分享成功”替代打印验证。

### 5.5 备份与恢复

用户可以随时导出一个完整备份文件，并在同版 App 中恢复。备份可能包含私人文字与图片，
导出前必须提示。恢复失败时原资料库保持不变。

## 6. 首版需求

| ID | 必须满足的用户结果 |
|---|---|
| PRD-01 | 不注册、不登录即可完成核心链路；产品只呈现一个资料库 |
| PRD-02 | 普通启动默认进入 Dashboard；一次操作可到 Capture 或 Library |
| PRD-03 | 支持相机、系统文档扫描、相册和 PDF 输入 |
| PRD-04 | 保存前可确认图片、编辑 OCR 文字并选择分类、来源、级别和标签 |
| PRD-05 | 未保存草稿在异常退出后可恢复；只有保存成功或用户明确丢弃才删除 |
| PRD-06 | 资料库支持浏览、搜索、筛选、详情、编辑和分类 |
| PRD-07 | 删除后提供持久化五秒撤销；后台或重启不能缩短期限 |
| PRD-08 | 多选资料可生成无空白、无重复条目的 PDF，并可预览、分享、保存和打印 |
| PRD-09 | 支持完整手动备份与恢复；损坏、恶意或超限输入在修改现有资料前被拒绝 |
| PRD-10 | 权限拒绝、OCR 失败、存储失败和数据库打不开都有可理解的恢复路径，不出现白屏或假空库 |
| PRD-11 | 内容默认只在设备处理和保存；图片入库前移除 EXIF 位置信息 |
| PRD-12 | 中英文、VoiceOver、Dynamic Type、深色模式和所有支持的 iPhone 尺寸可完成核心任务 |
| PRD-13 | 首版仅支持竖屏 iPhone；用户材料保持自身方向 |
| PRD-14 | 首版免费、无广告、无 IAP、无付费墙，不限制核心录入、导出或备份 |
| PRD-15 | 公开构建中不存在未批准功能的入口、通知、深链、后台任务或其他副作用 |

## 7. 明确不做

首版不包含：

- SnapDrill 账号、多个 Profile、Workspace、班级或儿童身份；
- 题库、搜题、答案搜索、自动解题、课程和内容推荐；
- 社交、排行榜、连续签到、虚拟奖励和裂变增长；
- CloudKit 或其他同步、开发者可访问的内容后端、第三方行为分析；
- Pro、StoreKit、订阅、广告或 IAP；
- Word 导出、iPad、Mac 或 Vision Pro 发行；
- 中国大陆专项版本、专项账号或专项商业化；
- Share Extension、App Intent、Shortcut、Widget 或其他系统入口；
- Review、SmartPaper、高级统计的公开入口。

这些项目只有经过新的产品决策并更新本 PRD 后才能进入开发范围。代码中已经存在不等于产品
已经批准。

## 8. 数据与兼容承诺

- 当前尚无外部用户，旧开发数据和旧开发期备份不构成兼容承诺。
- 首次向 PO 以外的人提供可下载构建后，本机升级和正式备份兼容性开始成为用户承诺。
- 在此之前必须完成单资料库收敛、稳定备份格式、恢复原子性和恶意输入防护。
- 下游数据契约负责固定精确不变量；代码和测试只能证明实现状态，不能降低产品权利。

## 9. 首版验收

公开候选至少满足：

1. 一名新用户无需说明即可完成“采集 -> 补充字段 -> 保存 -> 找回 -> 导出 / 打印”；
2. 核心流程在英文和简体中文、VoiceOver、常用 Dynamic Type 与支持的 iPhone 尺寸上可完成；
3. 草稿、删除、数据库打开失败、备份和恢复的失败路径不会静默丢失数据；
4. App 无非预期网络上传、广告、IAP、账号或隐藏功能副作用；
5. 本地验证、CI、真机相机 / 扫描、系统打印和发布签名证据绑定到同一候选提交；
6. 未解决的数据丢失、崩溃、白屏、核心流程阻断或隐私问题为零。

## 10. 决策职责

PO 决定产品身份、用户、需求优先级、公开承诺、商业模式、平台范围和发布。Agent 可以在本 PRD
边界内自主分析、实现、测试并创建 Draft PR；任何改变本 PRD 的提案必须先由 PO 审阅。
