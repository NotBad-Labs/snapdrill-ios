- 位置：§10.1 必填字段、§10.2 可选字段

- 强烈反对三要素（M-005 §B.3）：
  - 引用具体事实错误：M-002 §10.1 写「七个字段缺一不可」，但 M-000 §5 的最低字段清单包含「元层级注记」；user-decision-log 当前 #001-#024 也实际均以该字段收尾。
