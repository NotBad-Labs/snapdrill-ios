# NotBad 开发路线图 - 基于 PRD v6.2

本文档从 PRD v6.2 派生，列出按优先级排序的实施计划。

---

## 🎯 Phase 1：工程基础对齐（预计 3-5 天）

### 目标
建立符合 PRD v6.2 技术规范的工程基础，确保后续开发在正确的平台上进行。

### 任务清单

#### 1.1 升级工程配置
- [ ] 设置 SWIFT_VERSION = 6.2
- [ ] 设置 IPHONEOS_DEPLOYMENT_TARGET = 26.0
- [ ] 启用 Swift 6 严格并发检查
- [ ] 配置 Xcode 项目使用 SwiftData 框架

**PRD 依据**：§3.1 技术栈

#### 1.2 建立目录结构
```
NotBad/
├── Domain/              # 领域层
│   ├── Models/         # SwiftData 模型
│   └── Services/       # 业务服务
├── Presentation/        # 表示层
│   ├── Views/          # SwiftUI 视图
│   ├── ViewModels/     # 视图模型
│   └── Coordinators/   # 导航协调器
├── Infrastructure/      # 基础设施层
│   ├── Persistence/    # 数据持久化
│   ├── OCR/           # OCR 服务
│   ├── Telemetry/     # 遥测
│   └── CloudSync/     # 云同步（可选）
└── Resources/          # 资源文件
```

**PRD 依据**：§3.1 技术栈、§3.2 架构模式

#### 1.3 SwiftData 模型基础
- [ ] 创建 ModelContainer 配置
- [ ] 定义基础 Schema 版本控制
- [ ] 配置数据迁移策略

**PRD 依据**：§3.1 数据持久化

#### 1.4 导航架构骨架
- [ ] 实现 AppCoordinator（使用 @Observable）
- [ ] 定义导航路由枚举
- [ ] 创建 CoordinatorView 作为根视图

**PRD 依据**：§3.2 架构模式、§4.2 用户旅程

## 🎯 Phase 2：核心数据模型（预计 5-7 天）

### 目标
实现 PRD 定义的所有核心数据实体，支持离线优先的本地存储。

### 任务清单

#### 2.1 错题模型（Question）
```swift
@Model
class Question {
    var id: UUID
    var createdAt: Date
    var updatedAt: Date
    var source: Source // 拍照、手动、导入
    var originalImage: Data?
    var extractedText: String
    var tags: [Tag]
    var subject: String?
    var difficulty: Difficulty?
    var isFavorite: Bool
    var isArchived: Bool
    // ... PRD §4.3.2 定义的其他字段
}
```

**PRD 依据**：§4.3.2 错题管理

#### 2.2 标签模型（Tag）
```swift
@Model
class Tag {
    var id: UUID
    var name: String
    var color: String
    var createdAt: Date
    var questions: [Question]
}
```

**PRD 依据**：§4.3.2 标签系统

#### 2.3 复习记录模型（ReviewRecord）
```swift
@Model
class ReviewRecord {
    var id: UUID
    var question: Question
    var reviewedAt: Date
    var result: ReviewResult // 掌握、未掌握、稍后
    var nextReviewDate: Date?
}
```

**PRD 依据**：§4.3.3 复习系统

#### 2.4 用户配置模型（UserProfile）
```swift
@Model
class UserProfile {
    var id: UUID
    var dateOfBirth: Date?
    var onboardingCompleted: Bool
    var telemetryEnabled: Bool
    var cloudOCREnabled: Bool
    // 家长控制相关字段
}
```

**PRD 依据**：§8.2 合规与隐私

## 📊 里程碑与发布计划

### MVP（Minimum Viable Product）
**包含 Phases 1-5**
- 基础工程
- 核心数据模型
- 错题捕获
- 错题管理
- 复习系统

**预计时间**：6-8 周  
**目标**：可用的本地优先错题本，支持离线使用

### V1.0（First Public Release）
**包含 Phases 1-9**
- MVP 功能
- 数据分析
- 合规与隐私
- 遥测基础设施
- 完整用户旅程

**预计时间**：10-12 周  
**目标**：可公开发布的完整产品

### V1.1（Cloud Sync）
**包含 Phase 10**
- V1.0 功能
- CloudKit 同步

**预计时间**：V1.0 后 3-4 周  
**目标**：支持多设备同步

### V2.0（Community）
**包含 Phase 11**
- V1.1 功能
- 社区分享与发现

**预计时间**：V1.1 后 6-8 周  
**目标**：社区驱动的学习生态
