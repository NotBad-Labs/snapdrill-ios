# SnapDrill 非功能需求（NFR）

> 性能、隐私、存储、兼容性的量化标准。功能需求见 `../product/product-requirements.md`。

---

## 性能

| 指标 | 目标 | 测量方式 |
|---|---|---|
| **App 启动（冷启动）** | < 2 秒到首屏可交互 | Xcode Instruments Time Profiler |
| **OCR 识别响应** | < 2 秒（印刷体中英文） | 拍照后到文字出现在编辑区 |
| **题库列表加载** | < 500ms（200 题） | 从 Tab 切换到列表渲染完成 |
| **搜索响应** | < 300ms | 输入关键词到结果更新 |
| **PDF 导出** | < 5 秒（50 题） | 点击导出到预览页显示 |
| **快速打印** | < 3 秒（4 题） | 选中题目到系统打印面板弹出 |
| **备份打包** | < 30 秒（500 题 + 图片） | 点击备份到 ShareSheet 弹出 |
| **滚动帧率** | 60fps（无掉帧） | 题库列表快速滚动 |

## 内存

| 场景 | 上限 | 防护措施 |
|---|---|---|
| 题库浏览（200 题） | < 150MB | 图片按需加载 + 下采样 |
| PDF 批量导出 | < 200MB | autoreleasepool 逐页释放 |
| 备份/恢复 | < 200MB | 流式 ZIP 写入，不全量加载 |
| 图片裁剪 | < 300MB | Mantis 内部管理 |

## 存储

| 指标 | 基准 |
|---|---|
| **单题均值** | OCR 文字 ~5KB + 压缩图片 ~200KB ≈ **205KB** |
| **200 题** | ~40MB |
| **2000 题** | ~400MB |
| **图片压缩** | 长边限制 2000px，JPEG quality 0.8 |
| **草稿** | 最近 1 份，7 天过期自动清理 |
| **缓存** | 临时文件 + OCR 中间产物，用户可手动清理 |

## 隐私与安全

| 需求 | 标准 |
|---|---|
| **零注册** | 不要求手机号、邮箱、学校年级 |
| **默认零收集** | 默认不收集个人信息，opt-in 后仅匿名应用标识符 |
| **端上处理** | OCR 在设备上执行，图片不上传云端 |
| **EXIF 剥离** | 保存图片前清除 GPS 等位置信息 |
| **Analytics 默认不采集** | 首次启动默认不采集（plist 预禁用），用户可在设置中 opt-in；两个独立开关分别控制 Analytics 和 Crashlytics |
| **Not Tracking** | Privacy Manifest 声明 NSPrivacyTracking = false，不使用 IDFA |
| **CSV 注入防护** | 导出 CSV 时以 `=+\-@` 开头的值前加 tab |

## 兼容性

| 维度 | 要求 |
|---|---|
| **最低 iOS** | 26.0 |
| **设备** | 所有支持 iOS 26 的 iPhone 和 iPad |
| **屏幕尺寸** | iPhone（compact）+ iPad（regular）自适应 |
| **方向** | iPhone 竖屏；iPad 横竖屏均支持 |
| **分屏** | iPad Slide Over + Split View 不崩溃 |
| **国际化** | 中文（简体）+ 英文，App 内可切换 |
| **深色模式** | 跟随系统 / 浅色 / 深色 三选项 |

## 无障碍

| 需求 | 标准 |
|---|---|
| **VoiceOver** | 全模块所有常见任务可完成 |
| **Dynamic Type** | 复习卡片字号 12-24pt 可调 |
| **手势替代** | 滑动操作必须有对应按钮 fallback |
| **色彩对比度** | 文字与背景对比度 ≥ 4.5:1（WCAG AA） |

## 可靠性

| 场景 | 要求 |
|---|---|
| **数据持久性** | 保存操作后数据不丢失（saveContext 失败必须 rollback） |
| **草稿恢复** | 意外退出后可恢复（S0 级防护） |
| **删除安全** | 5 秒撤销窗口 |
| **备份完整性** | 恢复前自动备份当前数据（安全网） |
| **崩溃率** | < 0.1%（Crashlytics 监控） |
