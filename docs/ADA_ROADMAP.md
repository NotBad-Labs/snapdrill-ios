# Apple Design Award 冲刺路线图

**目标**：打造符合 Apple Design Awards 标准的 K12 教育应用  
**对标产品**：Flighty (2023 ADA)、Things 3、Obsidian  
**核心理念**：3-6 万行代码的"黄金区间"，用细节取胜

---

## 🎯 ADA 评判维度

| 维度 | 说明 | 我们的策略 |
|------|------|-----------|
| **Innovation** | 创新性 | 本地优先 + OCR + 艾宾浩斯算法 |
| **Inclusivity** | 包容性 | VoiceOver、Dynamic Type、高对比度 |
| **Interaction** | 交互体验 | 触觉反馈、流畅动画、手势操作 |
| **Delight** | 愉悦感 | 完成动画、音效、庆祝效果 |
| **Platform** | 平台特性 | Widget、Shortcuts、Spotlight、Live Activities |

---

## Phase 1：平台特性（最高杠杆）

> *这是独立开发者能赢大厂的关键——把 Apple 给的轮子用到极致*

### 1.1 Widget 小组件
- [ ] **今日待复习** - 显示待复习题目数量
- [ ] **学习进度** - 环形进度图展示掌握率
- [ ] **快捷入口** - 点击直接进入复习模式
- [ ] 支持多种尺寸（small/medium/large）
- [ ] 支持 Lock Screen Widget (iOS 16+)

### 1.2 Spotlight 搜索
- [ ] 题目内容可被全局搜索
- [ ] 搜索结果显示题目摘要和科目
- [ ] 点击搜索结果直接打开详情页
- [ ] 支持 `CSSearchableItem` 索引

### 1.3 Shortcuts 快捷指令
- [ ] **"扫描错题"** - 直接打开相机扫描
- [ ] **"开始复习"** - 进入今日复习队列
- [ ] **"添加错题"** - 手动输入模式
- [ ] 支持 Siri 语音触发
- [ ] 提供 `AppIntents` 集成

### 1.4 Live Activities 灵动岛
- [ ] 复习进行中显示进度 (3/10)
- [ ] 显示当前科目图标
- [ ] 支持暂停/继续操作
- [ ] 复习完成时自动结束

---

## Phase 2：包容性（评委重点）

> *盲人学生也能用这个 App 复习吗？*

### 2.1 VoiceOver 无障碍
- [ ] 所有按钮都有 `accessibilityLabel`
- [ ] 图片有描述性 `accessibilityLabel`
- [ ] 复杂视图使用 `accessibilityElement(children:)`
- [ ] 自定义操作使用 `accessibilityAction`
- [ ] 测试：关闭屏幕，仅用 VoiceOver 完成完整流程

### 2.2 Dynamic Type 动态字体
- [ ] 所有文字使用语义字体 (`.body`, `.headline`)
- [ ] 布局在超大字号下不会溢出
- [ ] 图片/图标尺寸随字号适当缩放
- [ ] 测试：设置最大字号，检查所有页面

### 2.3 其他包容性
- [ ] 颜色对比度符合 WCAG AA 标准
- [ ] 尊重 `reduceMotion` 系统设置
- [ ] 尊重 `reduceTransparency` 设置
- [ ] 支持 Bold Text 粗体文字

---

## Phase 3：愉悦感（加分项）

> *完成一组复习时，有没有精美的动画？*

### 3.1 触觉反馈 (Haptic)
- [ ] 保存成功：`.success`
- [ ] 删除确认：`.warning`
- [ ] 按钮点击：`.light`
- [ ] 复习完成：`.notification(.success)`
- [ ] 错误发生：`.notification(.error)`

### 3.2 动画效果
- [ ] 列表增删有流畅过渡
- [ ] 复习完成有庆祝粒子效果
- [ ] 页面切换有自然转场
- [ ] 进度条有平滑动画
- [ ] 卡片翻转有 3D 效果

### 3.3 声音设计（可选）
- [ ] 扫描成功提示音
- [ ] 复习正确/错误音效
- [ ] 全部完成庆祝音效
- [ ] 尊重系统静音设置

## 🏆 对标案例分析

### Flighty (2023 ADA 得主)
- **团队规模**：3 人
- **核心策略**：全世界最快适配 Live Activities
- **启示**：紧跟 Apple 新特性，就能用 3 人兵力打出 30 人效果

### Obsidian
- **团队规模**：2 人起步
- **核心策略**：Local-First 架构，避开后端泥潭
- **启示**：本地优先是独立开发者最强护城河

### Procreate
- **团队规模**：个位数工程师
- **核心策略**：自研渲染引擎，做到极致
- **启示**：在核心能力上必须深入底层
