# 架构决策记录索引

本目录用于记录影响系统架构的关键技术与产品决策。每条 ADR 都是不可变历史记录；若有新决策取代旧方案，应创建新的 ADR，并在旧 ADR 标记"已取代"。

**注意**: 由于项目重构，ADR-001 到 ADR-004 已标记为"已废弃"，不再适用于当前项目架构。当前有效的 ADR 为 ADR-005 和 ADR-006。

## 规范
- 命名格式: ADR-XYZ 标号递增且不重用。
- 状态枚举: 提议中 / 已采纳 / 已废弃 / 已取代。
- 修改原则: 已采纳的 ADR 不直接改写内容（除错别字），变更通过新 ADR 链接取代。
- 适用场景: 架构/技术选型、跨领域约束、数据/同步策略、安全 & 合规策略、关键成本折中。
