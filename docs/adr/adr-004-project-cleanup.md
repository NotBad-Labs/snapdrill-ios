# ADR-004: 项目结构清理与规范

## 状态

提议中

## 上下文

- 项目文件累积导致结构臃肿，影响开发效率和 CI 性能
- 需要建立可持续的清理机制，保持结构清晰与成本可控

## 决策

采用分层清理策略：

1. 保留层：核心源码、测试、关键文档
2. 归档层：历史文档、旧版配置（迁移到 docs/archive/）
3. 删除层：临时文件、构建产物（不入库）

## 清理原则

- 保持 Git 历史完整性
- 分阶段执行，每次一个模块
- 每次清理创建 PR 审查
- 保持 70%+ 测试覆盖率与逻辑门槛稳定

## 后果

- ✅ 项目结构清晰
- ✅ CI 性能提升
- ⚠️ 团队需要适应新结构
