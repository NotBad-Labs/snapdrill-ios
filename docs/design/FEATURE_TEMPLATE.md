# 功能设计文档（模板）

> 目的：在编码前统一目标、边界与方案，降低返工成本；设计文档与代码同仓、同审查。

## 背景与目标

- 业务背景：为何要做？
- 用户价值：解决什么问题？
- 目标指标：成功的度量（如留存、转化、时延、崩溃率）

## 约束与范围

- 非目标（Out of scope）
- 平台与最低版本
- 性能/安全/隐私要求

## 方案设计

- API 设计与数据模型
- 状态流转与时序图/流程图
- 错误处理与降级策略（与全局错误处理对齐）
- 可测试性：如何进行单测/契约测试/集成测试

## 替代方案评估

- 方案 A：优缺点
- 方案 B：优缺点
- 决策理由（如需，补充 ADR 链接）

## 发布与回滚

- Feature Flag 策略
- 迁移方案（数据/配置）
- 回滚路径与监控项

## 风险与缓解

- 已识别风险
- 缓解措施

## 附录

- 术语与链接（PRD/ADR/代码路径）
