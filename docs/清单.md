## ⚠️ 重要提醒

### 开发原则
1. **协议优先**: 先定义协议，再实现
2. **测试驱动**: 每个模块都要有对应测试
3. **离线优先**: 核心功能必须离线可用
4. **性能监控**: 满足所有性能指标

### 验收标准
每个任务完成后必须：
- [ ] 通过所有单元测试
- [ ] 满足PRD中的AC标准
- [ ] 代码review通过
- [ ] 性能基准测试通过

### 风险管控
- **OCR准确率风险**: 准备多个识别引擎备选
- **CloudKit配额风险**: 实现本地降级策略
- **家长权限风险**: 严格测试撤销流程
