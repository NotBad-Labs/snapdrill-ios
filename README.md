## 🚀 如何开始 (Getting Started)

这部分对于新加入的开发者，或者当你在新电脑上配置环境时至关重要。

### 先决条件 (Prerequisites)

* macOS Sonoma 14.0 或更高版本
* Xcode 16.0 或更高版本

### 安装与运行 (Installation & Running)

1.  通过 Xcode 克隆本仓库，或使用命令行：
    ```bash
    git clone [https://github.com/your-username/NotBad.git](https://github.com/your-username/NotBad.git)
    ```
2.  使用 Xcode 打开 `NotBad.xcworkspace` 文件。
3.  选择一个模拟器 (例如 iPhone 15 Pro)。
4.  点击 Xcode 左上角的 "Build and Run" 按钮 (▶︎) 即可运行。
