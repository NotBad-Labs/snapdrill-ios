# NotBad 错题本

> 一个简洁、本地优先、注重隐私的 K12 错题管理工具

## 快速开始

```bash
# 打开项目
open NotBad.xcodeproj

# 在 Xcode 中运行
# ⌘+R - 运行主应用
# ⌘+U - 运行测试
```

### 运行 Package 测试

```bash
cd Packages/ReviewKit && swift test
cd Packages/ProcessKit && swift test
```
