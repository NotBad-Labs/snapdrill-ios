# 创建架构决策记录 (ADR)

本工作流通过自动化步骤协助您创建符合规范的 ADR 文件。

## 执行步骤

1. **自动识别编号和目录**:
   - 默认存储路径: `docs/ADR/` (如不存在则自动创建)
   - 自动扫描该目录以获取下一个可用的 ADR 编号 (例如 `ADR-001`)

2. **生成模板**:

   使用 `write_to_file` 工具在 `docs/ADR/` 下创建一个名为 `ADR-###-[描述].md` 的文件。模板内容如下：

   ```markdown
   # ADR-###: [描述]

   *   **Status**: Proposed
   *   **Owner**: [姓名/Agent]
   *   **Decided By**: [决策会议/讨论记录]
   *   **Date**: {{DATE}}

   ## Context (上下文)
   [描述我们需要解决的问题，目前的局限性，以及为什么现在需要做出决策。]

   ## Decision (决策)
   [详细描述选定的方案，以及排除的其他备选方案。]

   ## Consequences (后果)
   [决策带来的正面和负面影响，包括对性能、复杂度和未来扩展性的影响。]
   ```

3. **后续操作**:
   - 文件创建后，请填充具体内容。
   - 提交 PR 时，请确保包含该 ADR 文件。

## 注意事项

- 编号必须是三位数字 (001, 002...)。
- 遵循 `docs/adr-guide.md` 中的“历史不可变”原则。
