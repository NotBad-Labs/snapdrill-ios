架构建议（融入模块清单）
    •    架构图/包结构中（如你现有的Package.swift和目录结构），建议在每个大模块内再明确列出核心子模块代码分区。例如 Sources/Data/SyncEngine.swift、Sources/AI/UnifiedOCR.swift 等，这样代码结构和文档、团队协作都一目了然。
    •    每个模块（类/actor/struct）都建议用类似 Swift 6 doc comment + Protocol/Dependency Injection 方式定义接口，方便mock和单元测试。
    •    在你的 “数据模型设计” 部分，也可以适当用注释标注出数据层相关模块（比如 TagManager、StatisticsManager），强化领域驱动感。
