# ADR-007: SM-2 间隔重复算法选型

## 背景

SnapDrill 的复习功能需要一个间隔重复（Spaced Repetition）算法来调度题目的复习时间。核心需求：根据用户自我评估（记得/不记得）自动调整下次复习间隔。

## 决策

**采用 SM-2 算法（SuperMemo 2），实现为纯值类型 `ReviewScheduler` + `SM2State`。**

SM-2 是间隔重复领域的经典算法（1987 年 Piotr Woźniak 提出），被 Anki、SuperMemo 等工具验证超过 35 年。算法简单（一个公式 + 5 个参数），易于实现和调试。

用户交互简化为两个主要操作：右滑（记得）= Good 评分，左滑（不记得）= Again 评分。卡片底部另有按钮提供相同功能，适配不习惯滑动手势的用户。SM-2 的完整 5 级评分（Again/Hard/Good/Easy）在内部保留，但 UI 层只暴露最常用的两个。

## 被否决的方案

### 方案 A：FSRS（Free Spaced Repetition Scheduler）

- **为什么否决**：FSRS 是 2022 年提出的新算法，基于机器学习优化参数，理论上比 SM-2 更精准。但 SnapDrill 的产品定位是「存档工具，复习是附带福利」（见 product-vision.md），不是专业记忆工具。SM-2 的精度完全够用，FSRS 的复杂度（需要训练数据、参数调优）与产品定位不匹配
- **何时重新评估**：如果用户反馈明确表示复习间隔不合理，且数据量足以支撑 FSRS 参数训练

### 方案 B：Anki 的修改版 SM-2

- **为什么否决**：Anki 在 SM-2 基础上做了大量修改（如 Learning Steps、Relearning Steps、Graduating Interval 等），增加了 10+ 个可配置参数。这些参数对 Anki 的「专业记忆用户」有价值，但对 SnapDrill 的目标用户（35 岁妈妈、初中生）是认知负担
- **补充**：SnapDrill 的用户甚至不需要知道「间隔重复」这个概念，算法应该完全透明

### 方案 C：简单固定间隔（1天、3天、7天、30天）

- **为什么否决**：不考虑用户掌握程度，所有题目使用相同间隔。容易导致已掌握的题目频繁出现（浪费时间）或未掌握的题目间隔过长（遗忘）
- **何时适用**：如果目标用户明确表示不需要智能调度（目前无此反馈）

## 后果

**正面**：
- 算法实现约 50 行代码，纯值类型（SM2State 是 struct），无副作用，100% 可单元测试
- ReviewScheduler 在 Core 包中，零外部依赖，`swift test` 覆盖所有边界条件
- 用户无需理解算法——左滑右滑即可，算法静默调整间隔

**负面**：
- SM-2 对所有用户使用相同参数（easeFactor 初始 2.5），无法个性化。专业记忆用户可能觉得间隔调整不够精准
- SM-2 没有「遗忘曲线」的数学建模，只有经验公式

**技术债**：无。SM-2 的简单性是有意的设计选择，与产品定位一致。
