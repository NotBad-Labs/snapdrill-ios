## 商业化铁律

**绝不限制录入数量。**

这是竞品最令人反感的做法（"每天免费 10 道"），也是 SnapDrill 的核心差异化。
录入是生命线，限制录入 = 扼杀产品价值。

## 付费模式（Freemium + 订阅，Bear 模式，2026-03-07 确立）

**定价模式**：参照 Bear（$2.99/月 或 $29.99/年），SnapDrill Pro 为打包订阅。
iCloud 同步与其他增值功能打包，不单独售卖同步——避免 App Store 审核指引 3.2.2 风险。
Bear / Day One / Ulysses 等 iOS 独立 App 已验证此模式多年，Apple 审核无问题。

| 免费 | SnapDrill Pro（订阅） |
|---|---|
| 无限录入（拍照、导入、手动） | iCloud 多设备实时同步（CloudKit） |
| OCR 文字识别（Apple Vision 原生） | 组卷排版打印（选错题 → 自动排版 → PDF，v1.5） |
| 分类管理、搜索、过滤 | 高级导出格式（Word） |
| 基础间隔重复复习 | 高级识别（数理化公式，LaTeX 渲染，v2.0） |
| 本地数据存储 | 去手写 / 试卷还原（AI 笔迹清除，v2.0） |
| 基础 PDF 导出 | 未来高级功能 |
| 手动备份 / 恢复（`.snapdrill` 文件） | — |

**免费版体验完整性保障**：
- 单设备无限录题 + 无广告 + 纯本地 = 完整可用的产品
- `.snapdrill` 手动备份/恢复 = 免费用户换手机不丢数据，也是抵御"绑架数据"指控的盾牌
- 付费解锁的是「增值体验」（多设备流转、高级导出），不是「基础能力」

**数据迁移方案**：
- 免费用户：手动导出 / 导入 `.snapdrill` 备份文件
- Pro 用户：iCloud CloudKit 自动同步，换机后数据自动回来

**核心付费场景**：家长"妈妈手机随时拍 + 孩子 iPad 随时练 + 打印机随时印"的闭环工作流，
iCloud 同步是打通这个闭环的引擎，组卷排版是配套杀招。

### 定价原则

- 首发全功能免费（积累用户和口碑）
- 付费功能必须是"增值"而非"解锁基础能力"
- 价格定位：学生群体可承受（对标小额订阅，非高端工具价格）
- 不做去水印——产品本身不应该有水印，这不是尊重用户的做法

## 隐私策略（2026-03-07 确立，Bear 模式）

SnapDrill **不收集任何个人信息**。没有注册，没有手机号，没有学校年级。

| 维度 | 竞品（喵喵机/橙果等） | SnapDrill |
|---|---|---|
| 注册 | 手机号必须 | 无注册 |
| 数据收集 | 姓名、学校、年级、位置 | 零收集 |
| 存储 | 自建云端 | 纯本地 + iCloud（Apple 负责） |
| 合规负担 | 极重（ICP+等保+审计+儿童隐私） | 极轻（仅 ICP 备案） |

**为什么这是杀手级差异化**：
- 2025 年中国四部门联合专项行动，3852 款 App 被通报侵害用户权益（同比增 152%）
- 教育类 App 是重点监管对象——收集儿童个人信息属于敏感信息处理
- 家长最怕孩子的学习数据被平台收集利用
- SnapDrill 不触碰用户数据 = 零监管风险 + 家长信任

**技术实现**：参照 Bear（意大利独立工作室 Shiny Frog 开发）的模式——
- 同步基于 Apple CloudKit，利用设备已有的 Apple ID 凭证，无需单独注册
- 中国区 iCloud 由云上贵州运营，数据存储在中国境内，**合规责任在 Apple 侧**
- 开启 Apple Advanced Data Protection 后，CloudKit 数据端到端加密，只有用户能解密

**用户须知（必须在产品中醒目提示）**：
- 免费版纯本地存储，**卸载 App = 数据永久丢失**——需在设置中和卸载前明确提醒
- 建议定期手动备份（`.snapdrill` 文件），或升级 Pro 启用 iCloud 自动同步

## 竞品分析（2026-03-07 行业调研）

### 行业格局

错题本 App 市场已形成三个梯队：

| 梯队 | 代表产品 | 特点 |
|---|---|---|
| 巨头附属 | 喵喵机（作业帮）、小猿口算（猿辅导）、快对 | 背靠亿级题库，免费引流卖硬件/课程 |
| 垂直工具 | 蜜蜂试卷、试卷宝、A+错题本、橙果错题本 | 以去手写/试卷还原为核心卖点，订阅制 |
| 独立小众 | 刺猬错题本、纠错大师、错题plus | 功能轻量，用户量小 |

### 竞品致命缺陷（用户真实痛点，来自知乎测评）

1. **录入界面拥挤** — 一屏塞满字段，容易误操作（SnapDrill 对策：默认仅开启学科）
2. **付费限制录入** — 橙果免费 50 题后收费，部分 App 每天 10 题（SnapDrill 对策：永不限制）
3. **注册流程繁琐** — 要求手机号+学校+年级+位置权限（SnapDrill 对策：零注册）
4. **OCR 不准 + 强制校对** — 用户被迫修正识别错误（SnapDrill 对策：展示但不强迫校对）
5. **打印要会员** — 基础功能付费化（SnapDrill 对策：基础 PDF 导出免费）

### SnapDrill 的差异化定位

SnapDrill 不在"间隔重复"赛道竞争（那是 Anki 的领地），
也不在"搜题+练题"赛道竞争（那是作业帮/猿辅导的领地），
而是在"错题存档效率工具"赛道，以 **隐私 + 简洁 + 原生体验** 切入。

| 维度 | 喵喵机（最大竞品） | SnapDrill |
|---|---|---|
| 定位 | 搜题+练题+打印 | 存档+管理 |
| 商业模式 | App 免费 + 卖打印机硬件 | App 免费 + 订阅增值 |
| 数据 | 云端存储，收集用户信息 | 纯本地 + iCloud |
| 注册 | 手机号必须 | 无注册 |
| 平台 | Android 优先，iOS 体验一般 | iOS 原生精品 |
| 题库 | 2.5 亿题库（作业帮） | 无题库（我们是工具不是内容） |
| 技术 | 第三方 OCR + 云端匹配 | Apple Vision 原生端上识别 |
