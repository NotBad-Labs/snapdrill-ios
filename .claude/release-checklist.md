# TestFlight 发版前检查清单

> 每次 build 推送到 TestFlight 前，在真机上走完以下流程。
> 标注 ❌ 的项目必须修复后才能发版。

---

## 启动与首屏

- [ ] App 冷启动不崩溃
- [ ] 首次安装：Onboarding 正确显示
- [ ] 非首次安装：直接进入主界面
- [ ] 首页数据加载正常（进度环、题目数量不显示为 0 或 loading 卡死）

## 拍题流程（Capture）

- [ ] 相机权限弹窗正常出现（首次）
- [ ] 相机预览正常
- [ ] 拍照后 OCR 识别并进入编辑界面
- [ ] 保存后返回，题库出现新题目
- [ ] 复习界面待复习数量更新

## 题库（Library）

- [ ] 列表正常显示所有题目
- [ ] 搜索功能有效
- [ ] 科目/标签过滤有效
- [ ] 点击题目进入详情
- [ ] 详情页可以编辑并保存
- [ ] 删除题目后列表更新

## 复习（Review）

- [ ] 待复习数量显示正确
- [ ] 「开始复习」进入卡片
- [ ] 题目正面内容正常显示（文字题、图片题均测试）
- [ ] 翻转卡片显示答案
- [ ] 向右滑：记住了，下一张
- [ ] 向左滑：忘了，下一张
- [ ] 撤销按钮有效
- [ ] 所有卡片完成后显示完成界面
- [ ] 退出复习后回到首页，进度更新

## 首页（Dashboard）

- [ ] 进度环数值与实际复习进度一致
- [ ] 题库跳转按钮有效
- [ ] 科目管理跳转有效
- [ ] 「今日新增」显示正确数量（纯展示，不可点击跳转）

## 设置（Settings）

- [ ] 通知时间设置有效
- [ ] 外观设置（深色/浅色）有效
- [ ] 隐私政策页面可以打开
- [ ] 生成测试数据后：题库和复习界面均刷新
- [ ] 清空数据后：题库和复习界面均清空

## 稳定性

- [ ] 连续使用 10 分钟不崩溃
- [ ] 切换 Tab 多次不崩溃
- [ ] 后台切换后回到前台状态正确恢复

---

## 发版信息核对

- [ ] Build Number 已更新（`aa26e00` 之后的规则：每次 +1）
- [ ] 没有 Debug 专用 UI 暴露在外
- [ ] 没有硬编码的测试账号或假数据
