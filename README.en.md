# NotBad - Error Question Book

> A simple, local-first, privacy-focused K12 error question management tool

**Note**: Chinese documentation is authoritative. This English version provides minimal entry information.

## Quick Start

```bash
# Open the project
open NotBad.xcodeproj

# Run in Xcode
# ⌘+R - Run main app
# ⌘+U - Run tests
```

### Run Package Tests

```bash
cd Packages/ReviewKit && swift test
cd Packages/ProcessKit && swift test
```
