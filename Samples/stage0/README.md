# 阶段 0 样张（仅本地，勿提交 Git）

本目录存放**真实试卷/作业照片**，用于去手写与扫描验证。默认 **不进仓库**（见根目录 `.gitignore`）。

## 放哪里

```
Samples/stage0/raw/     ← 原图（你拍照或导入）
Samples/stage0/manifest.tsv   ← 可提交的元数据清单（无隐私图）
```

## 登记方式

每收到一批图，在 `Docs/STAGE0_SAMPLES.md` 里增一行，并命名为 `S###-描述.jpg` 放进 `raw/`。

**目标**：≥100 张；当前进度见 `Docs/STAGE0_SAMPLES.md`。
